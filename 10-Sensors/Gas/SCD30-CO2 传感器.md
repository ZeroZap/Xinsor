# SCD30 CO2 传感器

> **一句话描述:** Sensirion NDIR CO2/温湿度传感器，I2C/UART 接口，适合楼宇通风、温室和高可靠 CO2 监测  
> **标签:** `#sensor/gas` `#sensor/co2` `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#protocol/uart` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SCD30** 是 Sensirion 经典 NDIR CO2 传感器，集成温湿度测量和 CO2 补偿能力。相对 SCD40/SCD41，它体积更大但资料成熟，适合楼宇通风、温室和环境监测项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / UART | 二者按平台选择 |
| 测量对象 | CO2、温度、湿度 | NDIR CO2 |
| CO2 范围 | 约 400-10000 ppm | 覆盖通风/温室应用 |
| 典型应用 | 楼宇 HVAC、温室、环境记录仪 | 经典 NDIR 方案 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要真实 CO2 浓度、较成熟资料和温湿度补偿的项目 |
| 不适合场景 | 极小体积、超低功耗、电池长续航节点 |
| 主要优势 | NDIR 原理、量程宽、接口灵活、Sensirion 生态成熟 |
| 主要风险 | 体积/功耗高于 SCD4x；ASC/FRC 和安装通风设计很关键 |
| 替代型号 | SCD40、SCD41、MH-Z19B、CM1106 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | I2C 或 UART 通信确认，读取 firmware/状态 |
| 配置 | 设置测量周期、海拔/气压补偿、温度偏移 |
| 读取 | 读取 CO2、temperature、humidity 并检查数据就绪 |
| 校准 | ASC/FRC 需按使用场景谨慎启用 |
| 验证 | 通风、呼气和室外空气对比测试响应趋势 |
