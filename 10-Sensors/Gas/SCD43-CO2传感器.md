# SCD43 CO2传感器

> **一句话描述:** Sensirion SCD4x 系列 CO2 传感器候选，适合产品分档、低功耗 CO2 节点和 SCD4x 生态补齐  
> **标签:** `#sensor/gas` `#sensor/co2` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SCD43** 是 Sensirion SCD4x 系列 CO2 候选，可用于产品分档、低功耗 CO2 节点、HVAC 和室内空气质量监测。它适合作为 SCD40/SCD41/SCD42 的相邻型号补齐。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SCD4x 系列接口 |
| 测量对象 | CO2、温度、湿度 | 具体能力以 datasheet 为准 |
| 典型应用 | 室内 CO2、HVAC、低功耗 IAQ | SCD4x 候选 |
| 关键特性 | 小型 CO2、温湿度补偿、ASC/校准 | 型号差异需确认 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | SCD4x 系列选型分档、低功耗 CO2 和产品化 IAQ 设备 |
| 不适合场景 | eCO2 低成本估算、工业高浓度 CO2、安全认证报警 |
| 主要优势 | 与 SCD40/SCD41 生态相邻，便于统一驱动能力表 |
| 主要风险 | 自动校准、温度偏移、通风和安装位置影响系统精度 |
| 替代型号 | SCD40、SCD41、SCD42、SCD30 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 serial，确认 CRC 和命令响应 |
| 配置 | 设置周期测量、低功耗模式、ASC、压力/海拔补偿 |
| 读取 | 输出 CO2 ppm、温湿度和状态 |
| 校准 | 记录强制校准、自动校准启停和参考环境 |
| 结构 | 外壳通风、热源和气流死角会影响响应时间 |
