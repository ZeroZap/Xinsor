# OPC-N3 PM传感器

> **一句话描述:** Alphasense 光学颗粒计数器模块，适合高阶颗粒物趋势、粒径分布和研究型原型  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/spi` `#vendor/alphasense`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**OPC-N3** 是 Alphasense 光学颗粒计数器方向的模块候选，定位高于常见低成本 PM2.5 模块。它更适合需要粒径分布、颗粒计数和较完整颗粒物趋势的研究型空气质量原型，而不是普通低成本 IAQ 节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 部分模块也可能提供串口/USB 转接，按模块版本确认 |
| 测量对象 | 粒径分布、PM1/PM2.5/PM10 趋势 | 具体 bin 和算法以 datasheet 为准 |
| 典型应用 | 研究型颗粒物监测、校准对照、户外节点原型 | 高于入门 PM 模块定位 |
| 关键特性 | 光学颗粒计数、粒径分档、主动采样 | 体积、成本和维护要求更高 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要粒径分布、颗粒计数和更高信息量的颗粒物原型 |
| 不适合场景 | 成本敏感消费级节点、只需要 PM2.5 数值的简单设备 |
| 主要优势 | 输出信息量高，适合与 PMS/SPS 类模块做算法和校准对照 |
| 主要风险 | 成本、功耗、风道维护、湿度干扰和数据解释复杂度较高 |
| 替代型号 | SPS30、PMS7003、HPMA115S0、PMSA003 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 SPI 模式、帧格式、固件版本和模块运行状态 |
| 读取 | 解析粒径 bin、PM 估算值、采样时间和状态字段 |
| 校验 | 对帧校验、异常值和风扇/激光状态做记录 |
| 标定 | 与参考仪或同类模块并行采样，建立场景修正关系 |
| 结构 | 户外使用需防水透气、防虫、防凝露和可维护风道 |
