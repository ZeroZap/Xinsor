# SEN63C 空气质量传感器

> **一句话描述:** Sensirion SEN6x 系列带 CO2 的空气质量模块候选，适合高集成 IAQ 与新风控制原型  
> **标签:** `#sensor/gas` `#sensor/air-quality` `#sensor/co2` `#sensor/pm` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**SEN63C** 可作为 SEN6x 系列中带 CO2 能力的空气质量模块候选，用于评估单模块实现 PM、CO2、温湿度和气体指数采集的可行性。相对 SEN5x，它更适合作为新风控制和人员密度估计的高集成方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | Sensirion 模块化命令风格，细节以 datasheet 为准 |
| 测量对象 | CO2、PM、温湿度、气体指数 | 不同 SEN6x 后缀输出组合不同 |
| 典型应用 | 新风控制、教室/办公室 IAQ、空气净化器 | CO2 与颗粒物同模块采集 |
| 关键特性 | 高集成、数字输出、出厂校准 | 结构通风和污染维护是重点 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 希望用单模块完成 CO2 + PM + IAQ 趋势的中高端设备 |
| 不适合场景 | 只需要低成本 eCO2、只做颗粒物趋势、空间极小的穿戴设备 |
| 主要优势 | 集成真实 CO2 方向，减少 SCD4x 与 PM 模块拼装 |
| 主要风险 | 成本和供货需确认，CO2 校准策略、风道和温升会影响读数 |
| 替代型号 | SEN60、SEN66、SCD41 + SPS30、SCD40 + PMS7003 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认具体料号、固件版本和输出字段集合 |
| 配置 | 启动连续测量，设置 CO2 自动校准/补偿策略 |
| 读取 | 同步解析 CO2、PM 和温湿度，保留状态/错误码 |
| 校准 | 封闭空间、温室和地下场景不要盲目启用自动 CO2 校准 |
| 验证 | 与 SCD40/SCD41 和独立 PM 模块做趋势对照 |
