# MH-Z19C CO2传感器

> **一句话描述:** Winsen MH-Z19 系列 NDIR CO2 模块，UART/PWM 接口，适合低成本室内 CO2、新风和温室趋势检测  
> **标签:** `#sensor/gas` `#sensor/co2` `#protocol/uart` `#protocol/pwm` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MH-Z19C** 是 Winsen MH-Z19 系列相邻 CO2 模块，可作为 MH-Z19B 的升级/替代评估对象。它适合低成本室内 CO2 趋势、新风控制、温室和教学项目，但产品化时仍需关注校准、通风和长期漂移。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART / PWM | 常见模块化 CO2 接口 |
| 测量对象 | CO2 | NDIR 原理 |
| 测量范围 | 常见 400-5000 ppm 版本 | 具体以模块版本为准 |
| 典型应用 | 室内 IAQ、新风、温室、教学项目 | 低成本真实 CO2 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低成本真实 CO2 模块，并能接受 UART/PWM 模块形态 |
| 不适合场景 | 体积极小低功耗节点、高精度校准仪、强认证工业安全系统 |
| 主要优势 | 资料多、成本相对低、可与 MH-Z19B 驱动和结构经验复用 |
| 主要风险 | 自动校准、预热、供电和模块批次差异会影响长期一致性 |
| 替代型号 | MH-Z19B、CM1106、CM1107N、Senseair S8、SCD40 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 UART 命令、波特率、响应帧和 checksum |
| 读取 | 周期读取 CO2 ppm，同时记录状态/温度等可用字段 |
| PWM | 若使用 PWM，需处理周期测量、占空比换算和异常脉冲过滤 |
| 校准 | 明确 ABC 开关、零点校准条件和部署环境，避免密闭空间误校准 |
| 验证 | 与参考 CO2 仪比较预热时间、响应时间和长期漂移 |
