# ZE03-O2 氧气传感器

> **一句话描述:** Winsen ZE03 系列氧气电化学模块，UART/模拟输出，适合氧气浓度趋势、安全监测和环境设备原型  
> **标签:** `#sensor/gas` `#sensor/o2` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-O2** 是 Winsen ZE03 系列氧气模块候选，适合氧气浓度趋势、安全监测、密闭空间和环境设备原型。电化学氧气模块不是通用 IAQ 指标，选型时要关注量程、寿命、交叉敏感和校准条件。

| 参数 | 值 | 备注 |

| 典型应用 | 密闭空间、氧气趋势、安全监测、环境设备 | 需校准维护 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要模块化氧气浓度趋势和 UART/模拟接口的安全或环境设备 |
| 不适合场景 | 医疗级氧浓度计、无维护长期部署、复杂混合气体定量 |
| 主要优势 | 模块化接口、目标气体明确、比裸电化学传感器更易接入 |
| 主要风险 | 电化学寿命、温湿度影响、零点/跨度校准和安全认证要求 |
| 替代型号 | 其他 O2 电化学模块、工业氧气变送器 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 UART 帧格式、校验和、量程字段和模拟输出比例 |
| 读取 | 输出 O2 浓度/趋势、状态、单位和 timestamp |
| 校准 | 零点/跨度校准需可靠参考气体，校准记录应持久化 |
| 补偿 | 温湿度、压力和传感器老化会影响长期读数 |
| 安全 | 若用于安全告警，必须结合认证传感器和独立保护策略 |
