# PMS1003 PM2.5颗粒物传感器

> **一句话描述:** Plantower 小型激光散射颗粒物模块候选，适合空间受限的 PM2.5 趋势检测  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/uart` `#vendor/plantower`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**PMS1003** 是 Plantower PMS 系列中更小型化的颗粒物模块候选，可作为 PMS5003/PMS7003 的结构尺寸对照。它适合便携式空气质量仪、桌面小型节点和空间紧张的空气净化器面板，但仍属于趋势检测模块。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART | 常见 PMS 帧格式，具体字段以 datasheet 为准 |
| 测量对象 | PM1.0、PM2.5、PM10 | 激光散射估算 |
| 典型应用 | 便携 IAQ、桌面监测、低成本 PM2.5 原型 | 小型化优先 |
| 关键特性 | 主动风道、周期输出、小尺寸 | 需评估风扇寿命和积尘 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 空间受限、只需要 PM 趋势和 UART 接入的空气质量节点 |
| 不适合场景 | 法规级监测、高粉尘工业现场、长期户外免维护设备 |
| 主要优势 | PMS 生态常见，驱动可复用 PMS5003/PMS7003 思路 |
| 主要风险 | 小尺寸风道更容易受安装方向、灰尘和湿度影响 |
| 替代型号 | PMS5003、PMS7003、PMSA003、SPS30 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 监听 UART 帧头、长度和校验，确认主动/被动输出模式 |
| 读取 | 解析 PM1.0/PM2.5/PM10 标准和大气环境字段 |
| 功耗 | 支持休眠/唤醒，便携设备需控制风扇运行时间 |
| 结构 | 小腔体要避免进出风短路，预留清洁和防尘空间 |
| 验证 | 与 PMS5003/PMS7003 同环境对照，记录湿度和烟雾响应 |
