# ZE03-NH3 氨气传感器

> **一句话描述:** Winsen ZE03 系列 NH3 电化学模块，UART/模拟输出，适合农业养殖、冷链泄漏和工业环境趋势检测  
> **标签:** `#sensor/gas` `#sensor/nh3` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-NH3** 是 Winsen ZE03 系列氨气电化学模块候选，适合养殖场、冷链制冷剂泄漏、工业环境和农业空气质量趋势检测。NH3 检测受湿度、温度、通风和背景气体影响明显，适合先作为趋势输入验证。

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART / Analog | 具体协议以 datasheet 为准 |

| 典型应用 | 养殖场、冷链、工业环境、农业 IoT | 需温湿度记录 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | NH3 趋势检测和比 MQ-137 更模块化的原型 |
| 不适合场景 | 无校准维护的安全报警、法规级排放计量 |
| 主要优势 | 模块接口简单，目标气体比 MQ 系列更明确 |
| 主要风险 | 湿度、交叉敏感、漂移和校准气体获取难度较高 |
| 替代型号 | MQ-137、工业 NH3 变送器、综合农业环境模块 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 通信 | 确认 UART 帧、checksum、量程和异常状态 |
| 读取 | 输出 NH3 趋势，记录单位、状态和 timestamp |
| 补偿 | 同步温湿度和通风状态，避免将湿度变化当作气体变化 |
| 校准 | 建议用标准气体或可靠对照设备校准 |
| 维护 | 电化学寿命和污染暴露应进入维护周期 |
