# SEN66 空气质量传感器

> **一句话描述:** Sensirion SEN6x 多合一空气质量模块候选，集成颗粒物、CO2、VOC/NOx 和温湿度，适合高集成 IAQ 和新风系统  
> **标签:** `#sensor/gas` `#sensor/air-quality` `#sensor/co2` `#sensor/pm` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**SEN66** 是 Sensirion SEN6x 多合一空气质量模块候选，面向希望单模块覆盖颗粒物、CO2、VOC/NOx 指标和温湿度的产品。它适合空气净化器、新风系统、商业楼宇 IAQ 和高集成环境监测，但成本、体积、风道和维护要求也更高。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 模块化数字接口 |
| 测量对象 | PM、CO2、VOC/NOx Index、温湿度 | 具体输出以 datasheet 为准 |
| 测量范围 | 多参数空气质量趋势 | CO2/PM/VOC 指标各自定义 |
| 典型应用 | 空气净化器、新风、商业楼宇、IAQ 网关 | 高集成空气质量模块 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 单模块覆盖 PM/CO2/VOC/NOx/温湿度，减少多传感器结构集成 |
| 不适合场景 | 极低成本节点、只测 CO2 或只测 PM 的简单设备 |
| 主要优势 | 集成度高、Sensirion 生态、适合 SEN55 + SCD40 组合替代评估 |
| 主要风险 | 模块体积、风道、风扇/激光维护、CO2 校准和长期污染需系统验证 |
| 替代型号 | SEN55 + SCD40、SEN55、SPS30 + SCD40、PMS7003 + SGP41 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 product name、serial、firmware/status，确认 I2C 通信 |
| 启动 | 按模块要求启动多参数测量，等待稳定时间 |
| 读取 | 分离上报 PM、CO2、VOC/NOx Index、温湿度和质量标志 |
| 校准 | CO2 ASC/FRC、温湿度补偿和 VOC/NOx 算法状态需要配置策略 |
| 维护 | 记录风道、防尘、风扇/激光污染和清洁/异常状态 |
