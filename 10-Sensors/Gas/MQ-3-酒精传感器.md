# MQ-3 酒精传感器

> **一句话描述:** 汉威低成本酒精气体半导体传感器，模拟输出，适合教学、酒精检测原型和挥发性酒精趋势检测  
> **标签:** `#sensor/gas` `#sensor/alcohol` `#protocol/analog` `#vendor/winsen`  
> **状态:** 已建档，索引标记为已验证  
> **最后更新:** 2026-05-23

---

## 概述

**MQ-3** 是常见酒精检测 MQ 传感器，对酒精蒸气敏感，常用于教学和酒精检测原型。它成本低，但定量精度、选择性和长期稳定性有限。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | Analog / 数字阈值模块 | 需要 ADC 或比较器 |
| 检测对象 | 酒精蒸气 | 对其他 VOC 也可能有响应 |
| 典型应用 | 酒精检测原型、教学、VOC 响应实验 | 非执法级酒精仪 |
| 关键特性 | 加热丝、Rs/R0 比值 | 需预热和校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 教学、酒精蒸气趋势检测、简单阈值报警 |
| 不适合场景 | 执法/医疗级酒精检测、低功耗设备、精准定量 |
| 主要优势 | 成本低、模块常见、模拟输出简单 |
| 主要风险 | 交叉敏感、漂移大、预热久、环境影响明显 |
| 替代型号 | 专用电化学酒精传感器、SGP40、BME688 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 预热 | 上电后等待加热稳定 |
| 采样 | ADC 采样并做滑动平均 |
| 校准 | 用已知酒精环境建立相对阈值，不建议伪精确 ppm |
| 阈值 | 报警阈值需按实际结构和空气流动调试 |
| 安全 | 不用于法律或医疗判定 |
