# ZE03-O3 臭氧传感器

> **一句话描述:** Winsen ZE03 系列臭氧电化学模块，UART/模拟输出，适合室外空气质量、臭氧消毒设备和工业环境趋势检测  
> **标签:** `#sensor/gas` `#sensor/o3` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-O3** 是 Winsen ZE03 系列臭氧电化学模块候选，适合室外空气质量趋势、臭氧发生/消毒设备监测和工业环境记录。O3 与 NO2 等氧化性气体存在交叉敏感风险，必须结合应用环境做对照验证。

| 参数 | 值 | 备注 |

| 接口 | UART / Analog | 具体协议和量程以 datasheet 为准 |
| 检测对象 | O3 | 电化学趋势检测 |
| 测量范围 | 臭氧浓度趋势 | 以模块版本为准 |
| 典型应用 | 室外空气质量、臭氧消毒、工业环境、算法对照 | 需交叉敏感评估 |

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 O3 趋势、模块化 UART/模拟接口和环境对照的项目 |
| 不适合场景 | 法规级臭氧监测站、无校准维护、安全联锁唯一依据 |
| 主要优势 | 目标气体明确、模块接口易接入、适合 ZMOD4510 对照评估 |
| 主要风险 | NO2/氧化性气体交叉敏感、零点漂移、传感器寿命和校准气源 |
| 替代型号 | ZMOD4510、工业 O3 变送器、综合空气质量模块 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 UART 帧格式、checksum、量程和状态字段 |
| 读取 | 输出 O3 浓度/趋势，异常状态应进入质量标志 |
| 补偿 | 记录温湿度、NO2 相关读数和通风条件以评估交叉敏感 |
| 校准 | 需要标准气体或可信参考仪器，不能只做空气零点假设 |
| 安全 | 臭氧消毒设备需独立安全联锁和认证策略 |
