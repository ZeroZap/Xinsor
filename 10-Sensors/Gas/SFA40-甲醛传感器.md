# SFA40 甲醛传感器

> **一句话描述:** Sensirion 数字甲醛传感器候选，适合室内装修污染、空气净化器和 SFA30 替代评估  
> **标签:** `#sensor/gas` `#sensor/hcho` `#sensor/air-quality` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SFA40** 是 Sensirion 甲醛检测方向候选，可用于装修污染趋势、空气净化器联动和室内空气质量设备。它适合作为 SFA30 与 ZE08-CH2O 的相邻型号对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 具体接口以资料为准 |
| 测量对象 | 甲醛 HCHO/CH2O 趋势 | 非安全认证报警器 |
| 典型应用 | 装修污染、空气净化器、室内 IAQ | 甲醛专用候选 |
| 关键特性 | 数字输出、温湿度补偿思路、模块化集成 | 需交叉敏感性验证 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要数字甲醛趋势监测和 Sensirion 生态集成的设备 |
| 不适合场景 | 工业安全报警、法规计量、只做通用 VOC 指标的项目 |
| 主要优势 | 面向 HCHO，适合与 SEN5x/SGP 系列组合成 IAQ 方案 |
| 主要风险 | 甲醛检测受温湿度、交叉气体、老化和通风条件影响 |
| 替代型号 | SFA30、ZE08-CH2O、SGP41、BME688 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 serial/status，确认通信和传感器状态 |
| 配置 | 设置测量周期和温湿度补偿输入 |
| 读取 | 输出 HCHO 趋势/浓度字段、状态位和有效性 |
| 校准 | 与参考仪器或已知浓度场景做趋势对照 |
| 长期 | 记录老化、污染、高湿和通风变化造成的漂移 |
