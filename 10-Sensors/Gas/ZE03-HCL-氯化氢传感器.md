## 概述

**ZE03-HCL** 是 Winsen ZE03 系列氯化氢电化学模块候选，适合工业腐蚀性气体、实验室环境和安全趋势检测原型。HCL 对材料、结构和传感器寿命影响明显，需要防腐设计和维护策略。

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | HCL 趋势检测、腐蚀性气体环境原型和工业安全辅助监测 |
| 不适合场景 | 法规级检测、安全联锁唯一依据、无维护长期部署 |
| 主要优势 | 目标气体明确，模块化接口降低驱动门槛 |
| 主要风险 | 腐蚀环境、交叉敏感、漂移、校准和结构材料兼容性 |
| 替代型号 | 工业 HCL 变送器、认证腐蚀性气体报警器 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 通信 | 确认 UART 帧格式、checksum、量程和状态字 |
| 读取 | 输出 HCL 趋势，记录异常状态和 timestamp |
| 补偿 | 温湿度、腐蚀暴露和交叉气体需要进入质量评估 |
| 校准 | 标准气体或可信参考设备是跨度验证前提 |
| 维护 | 传感器污染、寿命和更换周期需明确记录 |
