# ZE03-CL2 氯气传感器

> **一句话描述:** Winsen ZE03 系列 CL2 电化学模块，UART/模拟输出，适合消毒、工业安全和水处理周边氯气趋势检测  
> **标签:** `#sensor/gas` `#sensor/cl2` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-CL2** 是 Winsen ZE03 系列氯气电化学模块候选，适合水处理、消毒设备、工业安全和环境趋势记录。氯气有毒且腐蚀性强，安全控制必须依赖认证设备和独立联锁。

| 参数 | 值 | 备注 |

| 测量范围 | 氯气浓度趋势 | 以模块版本为准 |
| 典型应用 | 水处理、消毒设备、工业安全、环境记录 | 需防腐设计 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | CL2 趋势检测、消毒设备周边监测和工业安全原型 |
| 不适合场景 | 安全联锁唯一依据、法规级检测、无维护部署 |
| 主要优势 | 目标气体明确，模块接口利于快速接入 |
| 主要风险 | 腐蚀、交叉敏感、寿命、零点漂移和安全认证要求高 |
| 替代型号 | 工业 CL2 变送器、认证安全报警器 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 通信 | 确认 UART/模拟输出格式、校验和量程 |
| 读取 | 输出 CL2 趋势和质量状态，异常状态要显式上报 |
| 补偿 | 温湿度、腐蚀性环境和气流状态影响读数稳定性 |
| 校准 | 使用标准气体或可信参考设备进行零点/跨度验证 |
| 安全 | 消毒/工业场景需独立联锁和故障安全策略 |
