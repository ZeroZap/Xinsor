# ENS160 空气质量传感器

> **一句话描述:** ams OSRAM 多气体空气质量传感器，I2C/SPI 接口，适合低成本 eCO2、TVOC 和 IAQ 趋势监测  
> **标签:** `#sensor/gas` `#sensor/air-quality` `#protocol/i2c` `#protocol/spi` `#vendor/ams-osram`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**ENS160** 是面向室内空气质量的多气体传感器，可输出 IAQ 相关指标，例如 eCO2、TVOC 和 AQI 类结果。它适合低成本空气质量节点，但 eCO2 仍是估算值，不能替代 NDIR CO2。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 模组多用 I2C |
| 测量对象 | eCO2、TVOC、AQI/IAQ | 估算/指数类输出 |
| 典型应用 | 智能家居、空气质量节点、新风联动 | 低成本 IAQ 候选 |
| 补偿 | 温湿度补偿 | 建议外接温湿度传感器 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本 IAQ 趋势监测、智能家居、新风/净化联动 |
| 不适合场景 | 真实 CO2 浓度测量、工业安全、法规级 VOC 检测 |
| 主要优势 | 输出指标丰富、接口灵活、成本低于 NDIR 方案 |
| 主要风险 | eCO2/TVOC 是算法估算，预热、补偿和长期漂移需要验证 |
| 替代型号 | SGP30、SGP40、BME688、CCS811、SCD40 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 part id，确认 I2C/SPI 通信 |
| 模式 | 设置 operating mode 并等待 warm-up |
| 补偿 | 写入温湿度补偿数据 |
| 读取 | 读取 AQI、TVOC、eCO2 和状态寄存器 |
| 验证 | 区分 startup/valid data 状态，避免把未稳定数据当结果 |
