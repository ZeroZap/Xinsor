# SDS011 PM2.5颗粒物传感器

> **一句话描述:** Nova Fitness 激光散射颗粒物模块，UART 接口，适合低成本 PM2.5/PM10 空气质量监测和 PMS/SPS 对照  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/uart` `#vendor/nova-fitness`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SDS011** 是常见低成本激光散射颗粒物模块，经常作为 PMS5003/PMS7003/SPS30 的替代候选。它适合空气质量趋势、教育项目和室内 PM2.5 原型，不适合作为标准参考级监测仪。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART | 模块化输出帧 |
| 测量对象 | PM2.5、PM10 | 激光散射估算 |
| 典型应用 | 空气质量监测、教育、净化器联动 | 低成本颗粒物模块 |
| 关键特性 | 风扇/激光、周期输出、休眠控制 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本 PM2.5 趋势检测、室内空气质量原型、教学项目 |
| 不适合场景 | 法规级监测、长期户外无维护、高粉尘工业安全 |
| 主要优势 | 模块常见、协议简单、可与 PMS/SPS 系列做横向对比 |
| 主要风险 | 风扇寿命、湿度干扰、积尘和校准误差明显 |
| 替代型号 | PMS5003、PMS7003、SPS30、HPMA115S0 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 监听 UART 帧，确认帧头、长度和校验和 |
| 读取 | 解析 PM2.5/PM10 浓度，保留 timestamp |
| 模式 | 支持连续输出、查询模式和休眠控制 |
| 结构 | 进出风道、积尘、防虫和风扇噪声影响长期表现 |
| 验证 | 与 PMS5003/SPS30 同环境对比湿度响应和漂移 |
