# CM1109 CO2传感器

> **一句话描述:** Cubic NDIR CO2 模块候选，适合新风、温室和室内空气质量 CO2 趋势测量  
> **标签:** `#sensor/gas` `#sensor/co2` `#protocol/uart` `#protocol/i2c` `#vendor/cubic`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**CM1109** 是 Cubic NDIR CO2 模块方向的候选，可作为 CM1106/CM1107N 和 MH-Z19 系列的相邻对照。它适合新风控制、温室、教室/办公室 IAQ 和工业环境趋势采集，重点是确认具体模块版本、接口和校准策略。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART/I2C/PWM | 不同版本接口可能不同，以采购料号为准 |
| 测量对象 | CO2 | NDIR 原理 |
| 典型应用 | 新风控制、温室、办公室/教室 IAQ | 真实 CO2 浓度趋势 |
| 关键特性 | 模块化、数字输出、工业/楼宇常见方向 | 需要校准和通风结构设计 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要模块化 NDIR CO2，并希望与 CM1106/MH-Z19/SCD4x 对照的项目 |
| 不适合场景 | 极低功耗纽扣电池节点、只需要 VOC/eCO2 趋势的低成本设备 |
| 主要优势 | NDIR 直接测 CO2，模块形态适合新风和温室原型 |
| 主要风险 | 不同版本协议和校准默认值可能不同，采购前必须确认规格 |
| 替代型号 | CM1106、CM1107N、MH-Z19C、SCD40、Senseair S8 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认接口模式、协议帧、量程和固件版本 |
| 读取 | UART 帧或 I2C 读取要校验 checksum/CRC，记录温度补偿字段 |
| 校准 | 明确 ABC/ASC 自动校准是否启用，温室和封闭空间需谨慎 |
| 结构 | 保证空气交换，避免靠近热源、电源模块和封闭腔体 |
| 验证 | 与 SCD40、CM1106 或参考 CO2 仪并行记录通风响应 |
