# SGP41 VOC-NOx传感器

> **一句话描述:** Sensirion I2C VOC/NOx Index 传感器候选，适合室内空气质量、空气净化器和新风控制  
> **标签:** `#sensor/gas` `#sensor/voc` `#sensor/nox` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SGP41** 是 Sensirion 面向 VOC Index 与 NOx Index 的数字气体传感器候选，可用于室内空气质量、空气净化器、新风系统和车内空气质量趋势判断。它适合作为 SGP40 的增强型号，补齐 NOx 指标。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | Sensirion SGP 系列常见接口 |
| 测量对象 | VOC Index、NOx Index | 指数输出依赖算法和补偿 |
| 典型应用 | IAQ、新风、空气净化器、车内空气 | 非单气体计量 |
| 关键特性 | VOC/NOx 双指数、温湿度补偿、低功耗周期测量 | 需算法库/基线管理 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 VOC 与 NOx 趋势、且已有温湿度补偿输入的空气质量设备 |
| 不适合场景 | 真实 CO2 浓度、工业毒气报警、单一气体绝对浓度测量 |
| 主要优势 | 在 SGP40 基础上补齐 NOx 指数，适合 IAQ 趋势判断 |
| 主要风险 | MOX 类传感器受温湿度、基线、污染和算法版本影响明显 |
| 替代型号 | SGP40、ENS160、ZMOD4410、BME688 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 serial/feature set，确认 I2C 和 CRC |
| 配置 | 输入温湿度补偿，管理 VOC/NOx 算法状态 |
| 读取 | 输出 raw ticks、VOC Index、NOx Index 和有效性标志 |
| 校准 | 记录预热、基线保存/恢复和洁净空气参考 |
| 集成 | 算法库版本、采样周期和补偿来源必须可追踪 |
