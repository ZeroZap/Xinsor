# SPS30 PM2.5颗粒物传感器

> **一句话描述:** Sensirion 数字颗粒物传感器模块，I2C/UART 接口，适合空气质量产品、长期 PM2.5 趋势和 Plantower 模块对照  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/i2c` `#protocol/uart` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SPS30** 是 Sensirion 的数字颗粒物传感器模块，可输出多粒径 PM 质量浓度和颗粒数信息。相对 PMS5003/PMS7003，它更偏产品化和长期稳定方向，适合需要更好资料、接口和可靠性评估的空气质量设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / UART | 具体模块固件支持以 datasheet 为准 |
| 测量对象 | PM1.0、PM2.5、PM4、PM10 等颗粒物 | 激光散射估算 |
| 典型应用 | 空气质量监测、新风/净化器、环境 IoT | 产品化颗粒物候选 |
| 关键特性 | 多粒径输出、数字协议、风扇/风道模块 | 需要长期维护策略 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 预算较高、需要较完整资料和长期 PM2.5 趋势的空气质量产品 |
| 不适合场景 | 极低成本教育项目、法规级参考站、无维护高粉尘场景 |
| 主要优势 | Sensirion 生态、数字接口、字段完整、适合产品化评估 |
| 主要风险 | 成本、风道结构、积尘维护和湿度/气溶胶差异校准 |
| 替代型号 | PMS5003、PMS7003、SDS011、HPMA115S0 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认使用 I2C 还是 UART，读取产品信息或启动测量响应 |
| 读取 | 解析质量浓度、颗粒数和典型粒径字段 |
| 控制 | 支持启动/停止测量、清洁/维护命令和错误状态读取 |
| 结构 | 风道入口、滤网、安装方向和防虫防尘设计影响长期稳定性 |
| 验证 | 与 PMS 系列、参考仪和不同湿度环境做长期趋势对比 |
