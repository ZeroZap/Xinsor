# SEN60 空气质量传感器

> **一句话描述:** Sensirion SEN6x 系列多合一空气质量模块候选，面向 PM、VOC/NOx、温湿度和 CO2 集成采集  
> **标签:** `#sensor/gas` `#sensor/air-quality` `#sensor/pm` `#sensor/co2` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**SEN60** 是 Sensirion SEN6x 多合一空气质量模块方向的候选，定位比 SEN5x 更偏高集成 IAQ 节点。它适合新风、空气净化器、室内环境网关和商业楼宇原型，用单模块减少 PM、气体指数、温湿度和 CO2 多传感器拼装成本。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 模块化数字接口，具体命令以 datasheet 为准 |
| 测量对象 | PM、VOC/NOx、温湿度、CO2 | SEN6x 系列按型号分档，输出组合需核对料号 |
| 典型应用 | 新风系统、空气净化器、室内 IAQ、楼宇监测 | 高集成空气质量模块 |
| 关键特性 | 多参数集成、出厂校准、模块化风道 | 需要结构、风道和长期维护设计 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要同时覆盖 PM、CO2、VOC/NOx 和温湿度的高集成 IAQ 设备 |
| 不适合场景 | 极低成本节点、只测单一 CO2 或只测 PM 的产品 |
| 主要优势 | 集成度高，减少多模块校准、温湿度补偿和结构装配复杂度 |
| 主要风险 | 成本、体积、风扇/激光寿命、风道污染和供货周期需要评估 |
| 替代型号 | SEN66、SEN55 + SCD40、SPS30 + SCD41 + SGP41 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 product name、serial 和固件状态，确认具体 SEN6x 分档 |
| 配置 | 启停测量、设置温湿度补偿/海拔或气压补偿策略 |
| 读取 | 按模块输出解析 PM、CO2、VOC/NOx Index、温湿度和状态字 |
| 结构 | 保证进出风顺畅，避免热源、封闭腔体和风道短路 |
| 维护 | 记录风扇、激光、积尘、清洁周期和异常状态 |
