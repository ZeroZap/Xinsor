# PMSA003 PM2.5颗粒物传感器

> **一句话描述:** Plantower 小型激光颗粒物模块候选，适合紧凑空气质量设备、净化器和 PMS5003/PMS7003 对照  
> **标签:** `#sensor/gas` `#sensor/pm` `#sensor/air-quality` `#protocol/uart` `#vendor/plantower`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**PMSA003** 是 Plantower 小型颗粒物模块候选，可用于 PM1.0/PM2.5/PM10 趋势、便携空气质量仪、空气净化器和车载空气监测。它适合作为 PMS5003/PMS7003 的紧凑型相邻型号补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART | Plantower PMS 系列常见帧协议 |
| 测量对象 | PM1.0/PM2.5/PM10 趋势 | 激光散射模块 |
| 典型应用 | 便携 IAQ、净化器、车载空气、低成本 PM 节点 | 小型 PM 模块候选 |
| 关键特性 | 小型化、主动风路、颗粒物质量浓度输出 | 需防尘维护 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 空间受限、需要低成本 PM 趋势和 PMS 系列协议复用的设备 |
| 不适合场景 | 计量级颗粒物监测、长期免维护工业环境、高湿凝露环境 |
| 主要优势 | 小型化，适合 PMS5003/PMS7003 驱动生态扩展 |
| 主要风险 | 粉尘污染、风扇寿命、高湿和烟雾场景会影响读数 |
| 替代型号 | PMS5003、PMS7003、SDS011、SPS30、SEN50 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 解析 UART 帧头、长度、校验和和工作模式 |
| 配置 | 管理主动/被动模式、睡眠和唤醒流程 |
| 读取 | 输出 PM1.0/PM2.5/PM10、颗粒数和帧状态 |
| 校验 | 必须校验 checksum，异常帧不要进入业务数据 |
| 维护 | 记录运行时长、风道污染和高湿异常场景 |
