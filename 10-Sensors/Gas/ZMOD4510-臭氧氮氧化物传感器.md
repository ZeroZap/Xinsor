# ZMOD4510 臭氧氮氧化物传感器

> **一句话描述:** Renesas/IDT 室外空气质量 MOX 传感器候选，适合 O3/NOx 趋势、户外空气质量和车载外气检测原型  
> **标签:** `#sensor/gas` `#sensor/air-quality` `#sensor/ozone` `#protocol/i2c` `#vendor/renesas`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ZMOD4510** 是 Renesas/IDT 面向室外空气质量的 MOX 传感器候选，可用于 O3/NOx 趋势、户外环境节点和车载外气质量检测。它和 ZMOD4410 分别偏室外/室内场景，可作为空气质量方案的互补型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字 MOX 传感器 |
| 测量对象 | O3/NOx 趋势、室外空气质量 | 算法输出以 datasheet/库为准 |
| 典型应用 | 户外节点、车载外气、空气质量趋势 | 室外 IAQ/OAQ 候选 |
| 关键特性 | 加热 profile、算法输出、低功耗测量 | 需防水透气结构和温湿度补偿 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 O3/NOx 趋势、室外空气质量和车载外气趋势判断的项目 |
| 不适合场景 | 法规级空气质量监测站、工业毒气报警、单气体精确定量 |
| 主要优势 | 面向室外空气质量场景，适合补齐 VOC/PM/CO2 之外的 O3/NOx 方向 |
| 主要风险 | 室外温湿度、风速、污染物交叉敏感和封装防护会显著影响结果 |
| 替代型号 | ZMOD4410、MiCS-6814、SEN55、BME688 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/status，确认 I2C 通信、传感器状态和错误位 |
| 配置 | 选择 OAQ 模式、采样周期、加热 profile 和算法配置 |
| 读取 | 输出 O3/NOx 趋势或算法指数，保留 raw/状态用于调试 |
| 结构 | 户外使用要考虑防水透气膜、冷凝、粉尘和太阳直射 |
| 校准 | 与本地空气质量数据或参考仪器做趋势对比，不直接宣称绝对精度 |
