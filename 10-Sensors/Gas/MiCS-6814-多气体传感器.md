# MiCS-6814 多气体传感器

> **一句话描述:** SGX/Amphenol MiCS 系列多通道 MOX 气体传感器，模拟输出，适合 CO/NO2/NH3 等趋势检测和低成本空气质量原型  
> **标签:** `#sensor/gas` `#sensor/mox` `#protocol/analog` `#vendor/sgx`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MiCS-6814** 是常见多通道 MOX 气体传感器，可用于 CO、NO2、NH3 等气体趋势检测。它适合作为 MQ 系列之外的多气体低成本原型，但定量浓度、交叉敏感和长期漂移都需要严格标定。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | Analog | 常见模块输出多路模拟信号 |
| 检测对象 | CO、NO2、NH3 等趋势 | 交叉敏感明显 |
| 典型应用 | 空气质量、农业/工业趋势、教学原型 | 多气体 MOX 候选 |
| 关键特性 | 多敏感层、加热、低成本 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要多气体趋势、低成本原型和与 MQ 系列对照的项目 |
| 不适合场景 | 安全联锁、法规级报警、无需标定的定量 ppm 输出 |
| 主要优势 | 多通道气体趋势能力，适合空气质量特征输入 |
| 主要风险 | 交叉敏感、预热、温湿度影响和漂移都很大 |
| 替代型号 | MQ-135、MQ-137、专用电化学传感器、ENS160 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 硬件 | 多路 ADC、加热供电、地噪声和参考电压必须稳定 |
| 预热 | 初次和每次上电都需要稳定时间，不应立即输出结论 |
| 校准 | 记录洁净空气 R0，并结合已知气体或对照设备修正 |
| 补偿 | 温湿度、风速和气体组合会影响多通道响应 |
| 输出 | 建议先输出趋势/特征值，不直接声明 ppm 精度 |
