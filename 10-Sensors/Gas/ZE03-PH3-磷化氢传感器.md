# ZE03-PH3 磷化氢传感器

> **一句话描述:** Winsen ZE03 系列 PH3 电化学模块，UART/模拟输出，适合粮仓熏蒸、工业安全和有毒气体趋势检测原型  
> **标签:** `#sensor/gas` `#sensor/ph3` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-PH3** 是 Winsen ZE03 系列磷化氢电化学模块候选，适合粮仓熏蒸、工业安全和有毒气体趋势检测原型。PH3 毒性高，实际安全监测应使用认证设备和严格校准流程。

| 参数 | 值 | 备注 |

| 测量范围 | PH3 浓度趋势 | 以模块版本为准 |
| 典型应用 | 粮仓熏蒸、工业安全、有毒气体趋势、环境记录 | 高毒性场景 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | PH3 趋势检测和有毒气体原型评估 |
| 不适合场景 | 认证安全报警唯一依据、法规级检测、无维护部署 |
| 主要优势 | 目标气体明确，模块化 UART/模拟接口便于集成 |
| 主要风险 | 高毒性、交叉敏感、漂移、标准气体和安全操作要求高 |
| 替代型号 | 工业 PH3 变送器、认证有毒气体报警器 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 通信 | 确认 UART 帧格式、校验、量程和 fault 状态 |
| 读取 | 输出 PH3 趋势，超量程/故障状态需显式上报 |
| 校准 | 必须依赖标准气体或可信参考设备，记录安全流程 |
| 告警 | 安全阈值需迟滞、持续时间和传感器故障降级策略 |
| 维护 | 电化学寿命、暴露历史和更换周期需纳入维护策略 |
