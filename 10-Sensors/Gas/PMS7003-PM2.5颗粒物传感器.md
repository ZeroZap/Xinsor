# PMS7003 PM2.5颗粒物传感器

> **一句话描述:** Plantower 小型激光散射颗粒物传感器模块，UART 接口，适合紧凑空气质量节点和 PMS5003 替代评估  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/uart` `#vendor/plantower`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**PMS7003** 是 Plantower PMS 系列颗粒物模块候选，常与 PMS5003 一起用于 PM2.5 空气质量检测。它更适合空间受限的设备，但仍需关注风道、风扇寿命和湿度干扰。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART | 常见 Plantower 帧协议 |
| 测量对象 | PM1.0、PM2.5、PM10 颗粒物 | 激光散射估算 |
| 典型应用 | 便携空气质量、车载净化、紧凑 IoT 节点 | 小型化模块候选 |
| 关键特性 | 周期输出、休眠控制、颗粒物浓度估算 | 需核对模块协议版本 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 PMS5003 更紧凑的 PM2.5 模块或同系列供应替代 |
| 不适合场景 | 标准参考监测、强粉尘工业环境、无风道结构设计的设备 |
| 主要优势 | 模块小、协议与 PMS 系列接近、适合低成本产品原型 |
| 主要风险 | 不同批次协议/字段、进风结构和风扇寿命需实测确认 |
| 替代型号 | PMS5003、SPS30、SDS011、HPMA115S0 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 校验 UART 帧头、长度、校验和和字段数量 |
| 读取 | 解析 PM 标准浓度、环境浓度和颗粒数相关字段 |
| 电源 | 休眠/唤醒后需要预热稳定时间，不宜立即采信数据 |
| 结构 | 紧凑设备要避免壳体回流、风道阻塞和外部光干扰 |
| 验证 | 与 PMS5003/SPS30 做同环境长期对比，观察漂移和噪声 |
