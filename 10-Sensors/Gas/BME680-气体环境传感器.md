# BME680 气体环境传感器

> **一句话描述:** Bosch 四合一温湿压 + VOC 气体传感器，I2C/SPI 接口，适合室内空气质量趋势和便携环境监测  
> **标签:** `#sensor/gas` `#sensor/temperature` `#sensor/humidity` `#sensor/pressure` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BME680** 是 Bosch 集成温度、湿度、气压和气体电阻测量的环境传感器。它适合室内空气质量趋势、便携环境监测和气象节点，但不能直接输出特定 VOC 浓度。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 与 BME/BMP 系列风格接近 |
| 测量对象 | 温度、湿度、气压、气体电阻 | 四合一环境传感器 |
| 典型应用 | IAQ 趋势、气象站、便携环境监测 | 需算法解释气体数据 |
| 关键特性 | heater profile、补偿算法 | 驱动复杂度高于 BME280 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 温湿压 + IAQ 趋势一体化节点、便携环境监测 |
| 不适合场景 | 真实 CO2、特定 VOC ppm、工业安全检测 |
| 主要优势 | 四合一、Bosch 生态、I2C/SPI、模组常见 |
| 主要风险 | 气体输出依赖 heater 和算法，不能当作单一气体浓度 |
| 替代型号 | BME688、SGP40、ENS160、SCD40、BME280 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id 并确认总线通信 |
| 校准 | 读取温湿压和气体补偿参数 |
| 配置 | 设置 oversampling、IIR filter、heater 温度/时间 |
| 读取 | 读取温湿压和 gas resistance，并判断 heater 有效标志 |
| 算法 | IAQ 趋势需 baseline 和长期状态，不应只看单点 gas resistance |
