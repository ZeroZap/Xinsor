# SCD40 CO2 传感器

> **一句话描述:** Sensirion 小型 NDIR CO2 传感器，I2C 接口，适合室内空气质量和新风控制  
> **标签:** `#sensor/gas` `#sensor/co2` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-20

---

## 概述

**SCD40** 是 Sensirion 的小型 NDIR CO2 传感器，和 eCO2 估算类传感器不同，它用于直接测量 CO2 浓度。适合办公室、教室、智能家居、新风系统和便携式空气质量监测。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字输出 |
| 测量对象 | CO2 | NDIR 原理 |
| 典型范围 | 400-5000 ppm | 以 datasheet 为准 |
| 输出 | CO2、温度、湿度 | 温湿度多用于补偿参考 |
| 典型应用 | 新风控制、教室/办公室 IAQ、温室 | 精准 CO2 首选候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要真实 CO2 浓度的 IAQ、新风、温室和人员密度估计 |
| 不适合场景 | 极低成本空气质量趋势、只需要 VOC 指标的应用 |
| 主要优势 | NDIR 直接测 CO2、小型化、I2C 简单、品牌可靠 |
| 主要风险 | 成本高于 eCO2 传感器，结构通风和自动校准策略需认真设计 |
| 替代型号 | SCD41、SCD30、MH-Z19B、CM1106、SGP30 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 启动 | 按命令开始 periodic measurement |
| 读取 | 检查 data ready，再读取 CO2/温度/湿度和 CRC |
| 校准 | 根据场景选择自动自校准 ASC 或强制校准 FRC |
| 结构 | 保证空气流通，避免靠近热源和封闭腔体 |
| 功耗 | 便携设备需评估测量周期和休眠策略 |

## XinYi 气体类对照计划

**SCD40** 用于作为 SGP30 的对照样例：SGP30 输出 eCO2/TVOC 趋势，SCD40 直接测量真实 CO2。进入 XinYi 驱动时，SCD40 的重点不在 baseline 保存，而在周期测量、CRC、ASC/FRC 校准策略和结构通风。

### 建议接口

| 接口 | 作用 | 备注 |
|------|------|------|
| `scd40_init(config)` | 初始化并停止可能残留的测量状态 | 上电后先确保状态可控 |
| `scd40_start_periodic()` | 启动周期测量 | 常规 IAQ 场景首选 |
| `scd40_read(data)` | 读取 CO2/温度/湿度 | 读取前检查 data ready |
| `scd40_set_asc(enable)` | 配置自动自校准 | 封闭或特殊环境需谨慎开启 |
| `scd40_force_recalibration(co2_ppm)` | 强制校准 | 需要已知 CO2 参考环境 |
| `scd40_stop_periodic()` | 停止周期测量 | 低功耗或配置前使用 |

### Bring-up 重点

1. 确认空气流通，避免贴近热源和封闭腔体。
2. I2C 通信成功后，先停止周期测量，保证状态一致。
3. 启动 periodic measurement。
4. 轮询 data ready，再读取 CO2/温度/湿度和 CRC。
5. 在室外新鲜空气或参考仪器环境中判断 CO2 合理性。
6. 根据部署场景决定是否启用 ASC。
7. 如做 FRC，记录参考 CO2 浓度、稳定时间和环境条件。

### 最小验收标准

| 项目 | 判定 |
|------|------|
| 通信 | I2C 稳定应答 |
| 数据就绪 | data ready 状态可正常变化 |
| CRC | CO2/温湿度数据 CRC 校验通过 |
| CO2 | 室内/室外读数在合理范围，变化趋势符合通风状态 |
| 校准 | ASC/FRC 策略明确，不在未知环境中盲目校准 |
| 结构 | 外壳通风设计不会导致读数长期偏高或响应迟滞 |
