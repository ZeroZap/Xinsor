# MQ-2 烟雾传感器

> **一句话描述:** 汉威低成本半导体烟雾/可燃气体传感器，模拟输出，适合教学、报警原型和简单气体检测

> **状态:** 已建档，索引标记为已验证  
> **最后更新:** 2026-05-23

---

## 概述

**MQ-2** 是常见半导体气体传感器，可对烟雾、LPG、丁烷、氢气等可燃气体产生响应。它成本低、模块多，但选择性和一致性有限，适合教学和报警原型，不适合作为安全认证检测方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | Analog / 数字阈值模块 | 裸传感器需分压和 ADC |
| 检测对象 | 烟雾、LPG、丁烷、可燃气体 | 交叉敏感明显 |
| 典型应用 | 教学、烟雾报警原型、可燃气体趋势 | 需要预热和校准 |
| 关键特性 | 加热丝、Rs/R0 比值 | 功耗较高 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 教学、低成本报警原型、相对变化趋势检测 |
| 不适合场景 | 工业安全认证、定量 ppm 测量、低功耗电池设备 |
| 主要优势 | 成本低、模块常见、模拟输出简单 |
| 主要风险 | 选择性差、漂移大、预热久、温湿度影响明显 |
| 替代型号 | MQ-135、专用电化学传感器、NDIR/光电烟雾方案 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 预热 | 首次使用需长时间老化，常规使用也需预热 |
| 采样 | ADC 读取分压，转换为 Rs/R0 趋势 |
| 校准 | 在洁净空气中建立 R0，记录温湿度条件 |
| 阈值 | 数字模块阈值只适合粗略报警 |
| 安全 | 不应用于未认证的生命/工业安全场景 |
