# SCD42 CO2传感器

> **一句话描述:** Sensirion SCD4x 系列 CO2 传感器候选，适合 SCD40/SCD41 相邻型号评估和室内 CO2 趋势监测  
> **标签:** `#sensor/gas` `#sensor/co2` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SCD42** 是 Sensirion SCD4x 系列 CO2 候选，适合室内 CO2、需求控制通风、学校/会议室空气质量和低功耗 CO2 趋势监测。它可作为 SCD40/SCD41 相邻型号纳入能力表。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SCD4x 系列接口 |
| 测量对象 | CO2、温度、湿度 | 具体范围以 datasheet 为准 |
| 典型应用 | HVAC、室内 IAQ、低功耗 CO2 节点 | NDIR/光声 CO2 候选 |
| 关键特性 | 小型 CO2、温湿度补偿、自动校准思路 | 需确认型号差异 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已使用 SCD4x 生态，需要补齐 SCD40/SCD41 相邻型号的项目 |
| 不适合场景 | 低成本 eCO2 估算、户外污染监测、极高浓度工业 CO2 |
| 主要优势 | SCD4x 生态，驱动可与 SCD40/SCD41 复用 |
| 主要风险 | 自动基线校准、海拔补偿和外壳通风会影响准确性 |
| 替代型号 | SCD40、SCD41、SCD43、XENSIV-PAS-CO2 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 serial，确认 SCD4x 命令响应和 CRC |
| 配置 | 设置测量模式、ASC、海拔/压力补偿和温度偏移 |
| 读取 | 输出 CO2、温度、湿度、data ready 和状态 |
| 校准 | 手动校准、ASC 开关和通风场景要记录 |
| 兼容 | SCD40/SCD41/SCD42/SCD43 使用能力表区分低功耗和范围 |
