# ZE03-H2S 硫化氢传感器

> **一句话描述:** Winsen ZE03 系列 H2S 电化学模块，UART/模拟输出，适合工业安全、污水处理和环境趋势检测原型  
> **标签:** `#sensor/gas` `#sensor/h2s` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-H2S** 是 Winsen ZE03 系列硫化氢电化学模块候选，适合污水处理、下水道、工业安全和环境记录原型。H2S 有毒且腐蚀性强，实际安全场景必须使用认证设备和独立报警链路。

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | H2S 趋势检测、工业环境原型和模块化 UART/模拟接入 |
| 不适合场景 | 生命安全唯一报警、法规级检测、无维护长期部署 |
| 主要优势 | 目标气体明确，模块接口比裸电化学单元更易接入 |
| 主要风险 | 腐蚀、交叉敏感、寿命、零点漂移和校准气源要求高 |
| 替代型号 | MQ-136、工业 H2S 变送器、认证安全报警器 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 通信 | 确认 UART 帧格式、校验、量程和状态字段 |
| 读取 | 输出 H2S 浓度/趋势、状态、单位和 timestamp |
| 补偿 | 温湿度、腐蚀环境和交叉气体应进入质量标志 |
| 校准 | 零点/跨度校准需标准气体或可信参考设备 |
| 安全 | 安全应用需独立硬件告警和认证策略 |
