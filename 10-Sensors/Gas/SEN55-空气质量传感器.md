# SEN55 空气质量传感器

> **一句话描述:** Sensirion 多合一空气质量模块，集成颗粒物、VOC、NOx、温湿度，适合室内空气质量和新风系统原型  
> **标签:** `#sensor/gas` `#sensor/air-quality` `#sensor/pm` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SEN55** 是 Sensirion SEN5x 系列多合一空气质量模块候选，面向室内空气质量、空气净化器、新风控制和商业楼宇趋势监测。它把颗粒物、VOC/NOx 指标和温湿度整合到一个模块中，适合减少多传感器集成成本。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 模块化数字接口 |
| 测量对象 | PM、VOC Index、NOx Index、温湿度 | 具体输出以 datasheet 为准 |
| 典型应用 | 空气净化器、新风系统、室内 IAQ、商业楼宇 | 多合一空气质量模块 |
| 关键特性 | 激光颗粒物、气体指数、温湿度补偿 | 需要风道和防尘结构配合 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 希望用单模块覆盖 PM/VOC/NOx/温湿度的空气质量设备 |
| 不适合场景 | 极低成本 MQ/MOX 原型、只测 CO2、需要单一气体计量级浓度 |
| 主要优势 | 集成度高，减少多颗传感器的结构、补偿和驱动拼装工作 |
| 主要风险 | 模块体积、成本、风道、防尘和长期污染维护需要评估 |
| 替代型号 | SPS30 + SGP40、PMS7003 + ENS160、BME688 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 product name/serial，确认 I2C 地址和模块状态 |
| 配置 | 启动测量、设置温湿度补偿策略和清洁/维护策略 |
| 读取 | 输出 PM1.0/PM2.5/PM4/PM10、VOC/NOx Index、温湿度 |
| 结构 | 风道、进出风口、防尘网和安装方向会影响颗粒物结果 |
| 维护 | 长期运行要记录风扇/激光污染、自动清洁和异常状态 |
