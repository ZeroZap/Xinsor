# SGP40 VOC 传感器

> **一句话描述:** Sensirion VOC 指数传感器，I2C 接口，适合室内空气质量趋势监测和新风/净化联动  
> **标签:** `#sensor/gas` `#sensor/voc` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SGP40** 是 Sensirion 面向 VOC 趋势检测的 MOX 气体传感器，通常配合 Sensirion VOC Index 算法使用。相对 SGP30，它不直接输出 eCO2/TVOC 旧式指标，更适合以 VOC 指数做空气质量趋势和控制联动。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 命令式测量 |
| 测量对象 | VOC 趋势 | 需算法输出 VOC Index |
| 典型应用 | 空气净化器、新风、室内 IAQ 节点 | 关注趋势而非绝对浓度 |
| 补偿 | 温湿度补偿 | 建议接入 SHT/AHT 数据 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 室内 VOC 趋势、新风/净化联动、低功耗 IAQ 节点 |
| 不适合场景 | 需要具体气体浓度、法规级检测、CO2 真实浓度测量 |
| 主要优势 | 体积小、I2C、算法生态明确、适合 VOC Index |
| 主要风险 | 输出是趋势/指数，不是特定 VOC ppm；需预热和 baseline 稳定 |
| 替代型号 | SGP30、BME688、ENS160、CCS811 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 serial 或执行 self-test |
| 补偿 | 写入温湿度补偿参数，提高一致性 |
| 测量 | 周期触发 raw signal 读取 |
| 算法 | 接入 VOC Index 算法并保存状态 |
| 验证 | 使用酒精/清洁剂等 VOC 源观察趋势响应 |
