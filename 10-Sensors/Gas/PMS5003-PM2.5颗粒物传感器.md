# PMS5003 PM2.5颗粒物传感器

> **一句话描述:** Plantower 激光散射颗粒物传感器模块，UART 接口，适合 PM1.0/PM2.5/PM10 空气质量监测  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/uart` `#vendor/plantower`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**PMS5003** 是 Plantower 常见激光散射颗粒物模块，在收集入口中列为 PM2.5 空气质量候选。它适合室内空气质量、车载空气净化和教育/IoT 颗粒物监测，但不等同于标准参考级颗粒物仪器。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART | 常见模块输出帧 |
| 测量对象 | PM1.0、PM2.5、PM10 颗粒物 | 激光散射估算 |
| 典型应用 | 空气质量监测、空气净化器、车内 PM2.5 | 模块化方案 |
| 关键特性 | 主动风道、周期输出、颗粒物质量浓度估算 | 需要防尘和寿命评估 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 室内/车载空气质量趋势、空气净化器联动、低成本 PM2.5 原型 |
| 不适合场景 | 法规级监测、粉尘高浓度工业安全、长期免维护户外站 |
| 主要优势 | 模块常见、UART 接入简单、输出字段完整 |
| 主要风险 | 风扇寿命、积尘、湿度干扰和不同粒径/材质校准误差 |
| 替代型号 | PMS7003、SPS30、SDS011、HPMA115S0 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 监听 UART 帧，确认帧头、长度和校验和 |
| 读取 | 解析 PM1.0/PM2.5/PM10 标准/大气环境字段 |
| 模式 | 支持主动上传、被动查询和休眠/唤醒控制 |
| 结构 | 进出风道、滤网、积尘和风扇噪声会影响长期表现 |
| 验证 | 与参考仪或同类模块对比，记录湿度、烟雾和粉尘响应差异 |
