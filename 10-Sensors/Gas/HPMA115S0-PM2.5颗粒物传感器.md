# HPMA115S0 PM2.5颗粒物传感器

> **一句话描述:** Honeywell 激光颗粒物传感器模块，UART 接口，适合空气质量产品化评估和 PMS/SPS 系列对照  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/uart` `#vendor/honeywell`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**HPMA115S0** 是 Honeywell 颗粒物传感器模块候选，常作为 PMS5003、SDS011、SPS30 的品牌化替代评估。它适合空气质量产品化原型和长期趋势监测，但仍需关注风道、湿度和维护策略。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART | 模块输出帧 |
| 测量对象 | PM2.5/颗粒物 | 激光散射估算 |
| 典型应用 | 空气质量、净化器、新风、环境 IoT | 品牌化颗粒物模块 |
| 关键特性 | 激光散射、主动风道、数字输出 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比低成本模块更偏产品化来源的 PM2.5 趋势监测 |
| 不适合场景 | 法规级参考站、高粉尘工业安全、无维护户外节点 |
| 主要优势 | Honeywell 品牌资料，适合与 PMS/SPS 做可靠性对照 |
| 主要风险 | 成本、风扇寿命、积尘、湿度和气溶胶类型影响读数 |
| 替代型号 | PMS5003、PMS7003、SDS011、SPS30 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 UART 波特率、帧格式和校验方式 |
| 读取 | 输出 PM2.5/PM10 等字段时保留单位和质量标志 |
| 控制 | 支持睡眠/唤醒和预热稳定策略 |
| 结构 | 风道、滤网、防虫、防凝露和维护周期需系统设计 |
| 验证 | 与 PMS5003/SPS30/参考仪做多湿度、多粉尘源对比 |
