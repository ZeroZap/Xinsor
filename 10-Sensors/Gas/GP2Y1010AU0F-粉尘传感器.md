# GP2Y1010AU0F 粉尘传感器

> **一句话描述:** Sharp 红外光学粉尘传感器，模拟输出，适合低成本粉尘趋势检测和教学原型  
> **标签:** `#sensor/gas` `#sensor/particle` `#air-quality` `#protocol/analog` `#vendor/sharp`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**GP2Y1010AU0F** 是 Sharp 常见红外光学粉尘传感器，使用 LED 脉冲和模拟电压输出进行粉尘趋势检测。它适合教学、低成本空气质量趋势和传统方案维护，不适合直接替代激光颗粒物模块或法规级 PM 监测。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | Analog | MCU ADC 采样，需驱动 LED 脉冲 |
| 测量对象 | 粉尘/烟雾趋势 | 非标准 PM2.5 质量浓度输出 |
| 典型应用 | 教学、低成本粉尘趋势、空气净化器原型 | 模拟前端简单 |
| 关键特性 | 红外散射、模拟输出、成本低 | 需要时序、校准和机械遮光 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本粉尘趋势、烟雾响应演示、需要 ADC 接入的 MCU 原型 |
| 不适合场景 | 精准 PM2.5/PM10 浓度、产品化 IAQ、长期无人维护户外监测 |
| 主要优势 | 价格低、接口直观、适合理解光学粉尘检测原理 |
| 主要风险 | 模拟噪声、LED 时序、结构漏光、积尘和校准误差明显 |
| 替代型号 | PMS5003、SDS011、SPS30、DSM501A |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| LED 控制 | 按 datasheet 控制 LED 脉冲宽度和采样窗口 |
| 采样 | ADC 采样要避开开关噪声，建议多次平均和低通滤波 |
| 标定 | 输出只能作为趋势，浓度换算需参考具体结构和标定曲线 |
| 硬件 | LED 限流、电源滤波、模拟地和 ADC 参考电压要稳定 |
| 结构 | 需要遮光、防尘、气流路径和清洁维护设计 |
