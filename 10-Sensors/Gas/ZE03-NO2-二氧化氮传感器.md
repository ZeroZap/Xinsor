# ZE03-NO2 二氧化氮传感器

> **一句话描述:** Winsen ZE03 系列 NO2 电化学模块，UART/模拟输出，适合室外空气质量、交通污染和工业环境趋势检测  
> **标签:** `#sensor/gas` `#sensor/no2` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-NO2** 是 Winsen ZE03 系列 NO2 电化学模块候选，适合室外空气质量、交通污染、工业环境和空气质量算法对照。NO2 电化学测量容易受温湿度、O3 和其他氧化性气体影响，必须做对照和补偿验证。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | UART / Analog | 具体量程和协议以 datasheet 为准 |
| 检测对象 | NO2 | 电化学趋势检测 |
| 测量范围 | NO2 浓度趋势 | 以模块版本为准 |
| 典型应用 | 室外空气质量、交通污染、工业环境、算法对照 | 需温湿度补偿 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 NO2 趋势和模块化接口的空气质量原型或工业监测 |
| 不适合场景 | 法规级空气质量站、无校准维护、复杂混合气体精确定量 |
| 主要优势 | 目标气体明确、接口简单，可与 ZMOD4510/SGP41 做室外 NOx 对照 |
| 主要风险 | 交叉敏感、漂移、温湿度补偿和参考站对照是主要难点 |
| 替代型号 | ZMOD4510、SGP41、MiCS-6814、工业 NO2 变送器 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 通信 | 确认 UART 帧格式或模拟输出换算，记录模块量程 |
| 读取 | 输出 NO2 趋势、状态、单位和 timestamp |
| 补偿 | 同步记录温湿度、O3/NOx 相关传感器和环境条件 |
| 校准 | 建议与参考站或标准气体做零点/跨度对照 |
| 算法 | 用作趋势/告警输入时需做滤波、漂移跟踪和异常剔除 |
