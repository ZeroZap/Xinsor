# ZE03-SO2 二氧化硫传感器

> **一句话描述:** Winsen ZE03 系列 SO2 电化学模块，UART/模拟输出，适合工业排放、环境趋势和安全监测原型  
> **标签:** `#sensor/gas` `#sensor/so2` `#air-quality` `#protocol/uart` `#protocol/analog` `#vendor/winsen`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ZE03-SO2** 是 Winsen ZE03 系列二氧化硫电化学模块候选，适合工业排放趋势、环境记录和安全监测原型。SO2 测量对校准、交叉敏感、寿命和现场工况要求高，不能替代认证气体分析仪。

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 SO2 趋势检测和模块化接口的工业/环境原型 |
| 不适合场景 | 法规级排放监测、无校准维护、安全联锁唯一依据 |
| 主要优势 | 目标气体明确，UART/模拟模块比裸电化学单元更易接入 |
| 主要风险 | 交叉敏感、腐蚀环境、传感器寿命、零点漂移和校准气源 |
| 替代型号 | 工业 SO2 变送器、认证气体分析仪、综合工业气体模块 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 通信 | 确认 UART 帧格式、校验、量程和异常状态字段 |
| 读取 | 输出 SO2 浓度/趋势，并记录状态、单位和 timestamp |
| 补偿 | 温湿度、腐蚀性环境和交叉气体应进入质量标志 |
| 校准 | 零点/跨度校准需标准气体或可信参考设备 |
| 维护 | 电化学寿命、污染、存储条件和更换周期需明确记录 |
