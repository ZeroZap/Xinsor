# AFE4950 心率血氧模拟前端

> **一句话描述:** TI 高集成 PPG/生物传感模拟前端候选，适合可穿戴健康、心率血氧和多通道生理信号原型  
> **标签:** `#sensor/optical` `#sensor/ppg` `#health` `#protocol/spi` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**AFE4950** 是 TI 面向可穿戴健康和 PPG/生物传感方向的高集成模拟前端候选，可作为 AFE4404 的更高阶替代评估。它适合复杂可穿戴健康原型，但需要更完整的硬件、固件和算法配合。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 具体接口和寄存器以 datasheet 为准 |
| 测量对象 | PPG/生理光电信号 | 需外部光学器件和结构设计 |
| 典型应用 | 可穿戴健康、PPG、心率/血氧、多通道生理信号 | 高集成 AFE 候选 |
| 关键特性 | 多通道采样、LED/AFE 时序、低功耗策略 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 预算和研发能力充足、需要高集成健康传感 AFE 的可穿戴项目 |
| 不适合场景 | 快速 PPG 入门、低成本模块、无光学/算法团队的项目 |
| 主要优势 | 集成度高、适合产品化健康传感路线评估 |
| 主要风险 | datasheet 配置复杂、硬件调试和算法验证成本高 |
| 替代型号 | AFE4404、MAX30101、MAX30102、ADPD 系列 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 跑通 SPI、复位、寄存器读写和中断状态 |
| 配置 | 明确 LED/PD 通道、采样时序、平均和低功耗策略 |
| 读取 | 多通道 raw 数据需要保持通道顺序、timestamp 和质量标志 |
| 系统 | 光学结构、佩戴压力、柔性 PCB 和电源噪声共同影响结果 |
| 验证 | 用参考设备、运动场景和不同肤色/佩戴条件验证算法鲁棒性 |
