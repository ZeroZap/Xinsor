# VL53L3CX ToF测距传感器

> **一句话描述:** ST FlightSense ToF 测距传感器候选，适合多目标距离、接近检测和 VL53L0X/VL53L1X 升级评估  
> **标签:** `#sensor/optical` `#sensor/tof` `#sensor/distance` `#protocol/i2c` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VL53L3CX** 是 ST FlightSense 系列 ToF 测距候选，面向多目标测距、接近检测、液位和机器人避障。它适合作为 VL53L0X/VL53L1X 的相邻升级型号，尤其用于需要更复杂目标场景判断的应用。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | ST ToF 常见接口 |
| 测量对象 | 距离/多目标趋势 | 量程与精度以 datasheet 和目标反射率为准 |
| 典型应用 | 接近检测、液位、避障、用户存在检测 | FlightSense 候选 |
| 关键特性 | ToF 测距、多目标/直方图思路、ROI/阈值 | 需 ST API 支持 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 比 VL53L0X/L1X 更复杂的目标、反射和遮挡场景 |
| 不适合场景 | 室外强光长距雷达、毫米级工业位移、高速 3D 成像 |
| 主要优势 | ST ToF 生态成熟，适合做 VL53 系列升级评估 |
| 主要风险 | ST API 依赖、外壳开窗、串扰和多目标解释复杂度较高 |
| 替代型号 | VL53L1X、VL53L4CD、VL53L5CX、TMF8821 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取型号 ID，确认 I2C 地址和 boot 状态 |
| 配置 | 设置测距模式、timing budget、ROI、阈值和中断 |
| 读取 | 输出距离、信号强度、状态码和多目标信息 |
| 校准 | 需要 offset、crosstalk、盖板玻璃和目标反射率校准 |
| 集成 | ST API 版本和内存占用要固定记录，避免黑盒行为不可追溯 |
