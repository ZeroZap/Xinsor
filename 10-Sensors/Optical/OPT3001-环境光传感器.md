# OPT3001 环境光传感器

> **一句话描述:** TI 人眼响应曲线环境光传感器，I2C 接口，适合自动亮度调节、智能照明和低功耗光照监测  
> **标签:** `#sensor/optical` `#sensor/light` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**OPT3001** 是 TI 的环境光照度传感器，强调接近人眼视觉响应，适合显示亮度调节、智能照明和环境光监测。相对普通光敏电阻或低成本 ALS，它更适合需要稳定数字输出和光谱响应一致性的项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 支持地址配置 |
| 测量对象 | 环境光照度 | 人眼响应曲线 |
| 测量范围 | 约 0.01-83000 lux | 覆盖弱光到强光 |
| 典型应用 | 显示亮度、智能照明、低功耗光照节点 | TI 资料完整 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要接近人眼响应的自动亮度调节和智能照明 |
| 不适合场景 | 颜色识别、多光谱分析、极低成本玩具 |
| 主要优势 | 人眼响应好、低功耗、I2C、阈值中断能力 |
| 主要风险 | 结构光窗和安装角度会带来系统误差，需实机校准 |
| 替代型号 | BH1750、VEML6030、TSL2591、TSL2561 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 manufacturer/device ID 或确认 I2C ACK |
| 配置 | 设置转换时间、量程、连续/单次模式和中断阈值 |
| 读取 | 解析 exponent/mantissa 格式并换算 lux |
| 低功耗 | 电池设备优先使用单次转换和阈值中断 |
| 校准 | 根据外壳透光率做系统系数修正 |
