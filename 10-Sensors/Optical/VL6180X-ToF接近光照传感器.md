# VL6180X ToF接近光照传感器

> **一句话描述:** ST 近距离 ToF + 环境光二合一传感器，I2C 接口，适合短距接近检测和智能交互  
> **标签:** `#sensor/optical` `#sensor/tof` `#sensor/light` `#protocol/i2c` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**VL6180X** 是 ST 的短距离 ToF 接近传感器，同时集成环境光测量。相对 VL53L0X/VL53L1X，它量程更短，但适合近距离手势/接近、开盖检测和小型交互设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | ST ToF 系列风格 |
| 测量对象 | 近距离距离 + ALS | ToF + 光照二合一 |
| 测距范围 | 约 0-10 cm | 短距离接近检测 |
| 典型应用 | 接近唤醒、手势入口、开盖检测、短距避障 | 近距离优先 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 近距离接近检测、短距交互、需要 ToF + ALS 二合一 |
| 不适合场景 | 米级测距、复杂 ROI、长距离避障 |
| 主要优势 | 短距精度好、集成 ALS、I2C、ST 生态成熟 |
| 主要风险 | 光学窗口、串扰和目标反射率会影响距离稳定性 |
| 替代型号 | VL53L0X、VL53L1X、AP3216C、APDS9960 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 初始化 | 按 ST 推荐序列写入基础配置 |
| 测距 | 触发 range measurement 并读取状态和距离 |
| 光照 | 读取 ALS 通道并按增益换算 |
| 校准 | 关注 offset、crosstalk 和 cover glass 影响 |
| 中断 | 可用距离阈值做接近唤醒 |
