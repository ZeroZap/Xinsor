# VEML6035 环境光传感器

> **一句话描述:** Vishay 低功耗 I2C 环境光传感器，适合 VEML6030/VEML7700 相邻型号评估和自动亮度调节  
> **标签:** `#sensor/optical` `#sensor/als` `#protocol/i2c` `#vendor/vishay`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VEML6035** 是 Vishay VEML 系列环境光传感器候选，在收集入口中与 VEML6030、VEML6070、VEML6075 一起出现。它适合自动亮度调节、低功耗光照监测和 VEML 系列驱动抽象补齐。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | VEML 系列常见接口 |
| 测量对象 | 环境光照度 | lux 换算以 datasheet 为准 |
| 典型应用 | 自动亮度、智能家居、IoT 光照节点 | VEML ALS 候选 |
| 关键特性 | 低功耗、增益/积分时间配置 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | Vishay VEML 系列补齐、低功耗 ALS、VEML6030/VEML7700 替代评估 |
| 不适合场景 | 颜色识别、UV 指数、专业照度计替代 |
| 主要优势 | 系列生态清晰，适合共用 VEML ALS 驱动框架 |
| 主要风险 | 型号间寄存器、灵敏度和 lux 系数需要逐项确认 |
| 替代型号 | VEML6030、VEML7700、BH1750、OPT3001 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和默认配置 |
| 配置 | 设置增益、积分时间、低功耗和中断阈值 |
| 换算 | lux 公式随增益/积分时间变化，不能固定比例误用 |
| 校准 | 外壳窗口透光率和光源色温会影响读数 |
| 兼容 | 与 VEML6030/VEML7700 共用代码时保留型号能力表 |
