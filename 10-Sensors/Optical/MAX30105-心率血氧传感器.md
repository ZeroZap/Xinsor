# MAX30105 心率血氧传感器

> **一句话描述:** Maxim/ADI 多 LED 光学传感器，I2C 接口，适合 PPG、颗粒/烟雾光学实验和 MAX3010x 系列扩展评估  
> **标签:** `#sensor/optical` `#sensor/ppg` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MAX30105** 是 Maxim/ADI MAX3010x 系列光学传感器候选，常用于 PPG、光学颗粒/烟雾实验和多 LED 反射测量原型。相对 MAX30102/MAX30101，它更适合作为多用途光学采样平台而非单纯心率血氧模块。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | MAX3010x 系列常见接口 |
| 测量对象 | 多 LED 反射 PPG/光散射信号 | 具体 LED 通道以型号为准 |
| 典型应用 | PPG 实验、颗粒/烟雾原型、反射式光学采样 | 多用途光学模块 |
| 关键特性 | LED 电流、采样率、FIFO、环境光抑制思路 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 想复用 MAX3010x 驱动框架做多 LED 光学采样和 PPG 实验 |
| 不适合场景 | 医疗认证血氧、标准颗粒物仪器、强运动无结构优化的设备 |
| 主要优势 | MAX3010x 生态成熟，FIFO/LED 配置和算法资料多 |
| 主要风险 | 应用跨度大，必须按具体光学结构重新验证算法和标定 |
| 替代型号 | MAX30102、MAX30101、MAX30100、ADPD188BI |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 part ID/revision，确认 FIFO 和中断寄存器 |
| 配置 | 设置 LED 通道、电流、采样率、脉宽和平均次数 |
| 读取 | FIFO 批量读取，保留通道顺序和 timestamp |
| 算法 | PPG、烟雾/颗粒和反射检测需要完全不同的处理链路 |
| 结构 | 光学隔离、腔体、窗口和反射路径决定可用性 |
