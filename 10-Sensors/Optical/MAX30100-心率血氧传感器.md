# MAX30100 心率血氧传感器

> **一句话描述:** Maxim/ADI 早期 PPG 心率/血氧传感器，I2C 接口，适合旧项目维护、MAX30102/MAX30101 对照和健康原型学习  
> **标签:** `#sensor/optical` `#sensor/ppg` `#health` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MAX30100** 是 Maxim/ADI 早期集成 LED 与光电检测的 PPG 传感器，常见于心率/血氧入门模块和旧项目。它适合维护历史硬件和理解 PPG 驱动流程，新设计通常优先评估 MAX30102、MAX30101 或更高集成度 AFE。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见 PPG 模组接口 |
| 测量对象 | 红光/红外 PPG | 心率/血氧趋势，不等同医疗诊断 |
| 典型应用 | 健康手环原型、PPG 教学、旧项目维护 | 早期 PPG 型号 |
| 关键特性 | LED 电流、采样率、FIFO/中断 | 以 datasheet 为准 |

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已有 MAX30100 模组、PPG 教学、旧项目维护和算法原型 |
| 不适合场景 | 医疗认证设备、强运动场景准确 SpO2、新产品长期供货 |
| 主要优势 | 入门资料多、I2C 简单、适合理解 PPG 基础链路 |
| 主要风险 | 模块质量差异、环境光、佩戴结构和运动伪影影响大 |
| 替代型号 | MAX30102、MAX30101、MAX30105、AFE4404 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/版本寄存器，确认 FIFO 可读 |
| 配置 | 设置 LED 电流、采样率、脉宽和模式 |
| 读取 | 使用 FIFO 批量读取红光/红外样本，保留 timestamp |
| 算法 | 需要滤波、峰值检测、信号质量和运动伪影处理 |
| 结构 | 光学隔离、佩戴压力、防环境光比寄存器配置同样关键 |
