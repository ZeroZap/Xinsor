# VL53L1X ToF 测距传感器

> **一句话描述:** ST 长距离 ToF 测距传感器，I2C 接口，量程相对 VL53L0X 提升到约 4m 级别  
> **标签:** `#sensor/optical` `#sensor/tof` `#sensor/distance` `#protocol/i2c` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-20

---

## 概述

**VL53L1X** 是 ST 的 FlightSense ToF 测距传感器，可用于非接触距离测量、机器人避障、液位检测和人员接近检测。相比 VL53L0X，它具备更长测距能力和更灵活的 ROI 配置，适合作为 XinSor 光学/距离类的下一批重点型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见 0x29，支持软件改地址 |
| 测量对象 | 距离 | ToF 原理 |
| 典型量程 | 约 0-4m | 受目标反射率、环境光和模式影响 |
| 输出 | 距离、状态、信号质量 | 需检查 range status |
| 典型应用 | 避障、液位、接近检测、区域检测 | VL53L0X 升级候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 比 VL53L0X 更远距离的避障、人员接近、液位和区域检测 |
| 不适合场景 | 高精度工业测距、强阳光无结构遮光、透明/高吸光目标 |
| 主要优势 | 量程更长、资料丰富、模组易采购、I2C 接入简单 |
| 主要风险 | 覆盖玻璃、目标反射率、环境光会显著影响有效量程 |
| 替代型号 | VL53L0X、VL53L4CX、VL6180X、GP2Y0A21 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 启动 | 需要按 ST 推荐初始化序列配置寄存器 |
| 测距 | 选择 short/medium/long 距离模式和 timing budget |
| 多传感器 | 多个默认地址相同，需用 XSHUT 分批改地址 |
| 质量判断 | 读取距离同时检查 range status 和信号强度 |
| 标定 | 覆盖玻璃和结构件变化后需要 offset/crosstalk 校准 |

## XinYi 光学/距离类对照计划

**VL53L1X** 用于作为 VL53L0X 的升级对照样例：VL53L0X 负责基础 ToF 测距闭环，VL53L1X 负责更长距离、ROI 和更复杂的标定策略。

### 建议接口

| 接口 | 作用 | 备注 |
|------|------|------|
| `vl53l1x_init(config)` | 初始化并加载推荐配置 | 默认 I2C 地址同为 `0x29` |
| `vl53l1x_read(data)` | 读取距离和 range status | 必须带质量判断 |
| `vl53l1x_set_distance_mode(mode)` | 配置 short/medium/long | 影响量程、环境光容忍度和耗时 |
| `vl53l1x_set_timing_budget(ms)` | 配置测量时间预算 | 影响精度和速率 |
| `vl53l1x_set_roi(roi)` | 配置 ROI | 区域检测和抗干扰关键 |
| `vl53l1x_calibrate(calib)` | offset/crosstalk 校准 | 覆盖玻璃或结构变化后需要 |

### Bring-up 重点

1. 先按 VL53L0X 的基础 ToF 流程验证通信、XSHUT 和默认地址。
2. 使用 short/medium/long 距离模式分别测固定目标。
3. 记录不同目标颜色、材质、反射率下的有效量程。
4. 配置 ROI，验证区域变化是否影响测距结果。
5. 增加覆盖玻璃后做 offset/crosstalk 评估。
6. 强环境光下记录 range status、signal 和有效距离变化。

### 最小验收标准

| 项目 | 判定 |
|------|------|
| 距离模式 | short/medium/long 切换后量程和稳定性符合预期 |
| ROI | ROI 配置可影响检测区域 |
| 标定 | offset/crosstalk 参数有明确记录和应用条件 |
| 质量 | 弱反射/强环境光/覆盖玻璃下能输出可解释状态 |
| 多设备 | 与 VL53L0X 一样支持 XSHUT 地址管理 |
