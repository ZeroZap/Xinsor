# VEML7700 环境光传感器

> **一句话描述:** Vishay I2C 高分辨率环境光传感器，适合自动亮度调节、低功耗光照监测和 VEML6030 替代评估  
> **标签:** `#sensor/optical` `#sensor/als` `#protocol/i2c` `#vendor/vishay`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**VEML7700** 是 Vishay 的数字环境光传感器，常用于自动亮度调节和低功耗光照趋势监测。它可作为 BH1750、OPT3001、VEML6030 之间的替代候选，重点关注人眼响应、动态范围和低功耗配置。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 环境光传感器常见接口 |
| 测量对象 | 环境光照度 | lux 换算以 datasheet 公式为准 |
| 典型应用 | 自动亮度、户外光照监测、IoT 节点 | 低速采样即可 |
| 关键特性 | 增益/积分时间可配、低功耗 | 需避免饱和和窗口误差 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 BH1750 更灵活配置、低功耗环境光监测和屏幕亮度调节 |
| 不适合场景 | 颜色识别、距离检测、专业照度计替代 |
| 主要优势 | I2C 简单、功耗低、动态范围和积分配置灵活 |
| 主要风险 | 外壳透光率、角度响应和强光饱和需要实测校准 |
| 替代型号 | VEML6030、BH1750、OPT3001、TSL2591 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和默认配置，读取 raw ALS |
| 配置 | 设置增益、积分时间、持续/低功耗模式和中断阈值 |
| 换算 | lux 公式需随增益/积分时间调整，避免固定比例误用 |
| 校准 | 用标准照度计或对照传感器修正外壳窗口透光率 |
| 低功耗 | 根据亮度变化速度降低采样频率，减少 MCU 唤醒 |
