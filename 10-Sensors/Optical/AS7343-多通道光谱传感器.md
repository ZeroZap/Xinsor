# AS7343 多通道光谱传感器

> **一句话描述:** ams OSRAM 多通道光谱传感器候选，适合颜色识别、光源分类、材料趋势和 AS7341/AS7265x 方案对照  
> **标签:** `#sensor/optical` `#sensor/spectral` `#protocol/i2c` `#vendor/ams-osram`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**AS7343** 是 ams OSRAM 多通道光谱方向候选，可用于颜色识别、光源分类、材料趋势、水质/农业光谱特征和多通道光学采样。它适合作为 AS7341、AS7265x 之间的相邻型号补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 多通道光谱常见接口 |
| 测量对象 | 多通道可见光/近红外趋势 | 通道数和波段以 datasheet 为准 |
| 典型应用 | 光源分类、颜色识别、材料趋势、农业/水质原型 | 多通道光谱候选 |
| 关键特性 | 多光谱通道、积分/增益、闪烁/光源特征思路 | 需要光路和标定 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 RGB 更丰富的光谱特征，但不需要专业光谱仪的项目 |
| 不适合场景 | 科研级高分辨率光谱、绝对辐照度计量、高速光谱成像 |
| 主要优势 | 多通道特征比 RGB 更适合光源/材料趋势识别 |
| 主要风险 | 光路、标定、温漂、LED/光源控制和算法模型决定系统效果 |
| 替代型号 | AS7341、AS7265x、C12880MA、OPT4048 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/状态，确认 I2C 通信和通道能力 |
| 配置 | 设置积分时间、增益、通道组、LED/中断和 flicker 相关能力 |
| 读取 | 输出每通道 raw、饱和状态、积分时间和增益 |
| 校准 | 需要暗场、白板、参考光源和光学窗口校准 |
| 应用 | 驱动只提供标准化通道数据，分类/识别模型放在上层 |
