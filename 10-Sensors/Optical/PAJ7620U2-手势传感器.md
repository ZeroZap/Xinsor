# PAJ7620U2 手势传感器

> **一句话描述:** PixArt 红外手势识别传感器模块，适合近距离非接触手势交互和教育原型  
> **标签:** `#sensor/optical` `#sensor/gesture` `#protocol/i2c` `#vendor/pixart`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**PAJ7620U2** 是常见红外手势识别传感器候选，通常用于识别上下左右、靠近、远离等短距手势。它适合智能家居面板、玩具、教育和非接触控制原型，可作为 APDS9960 手势功能的对照方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见模块通过 I2C 读取手势状态 |
| 测量对象 | 短距手势/接近趋势 | 识别能力受环境光和动作速度影响 |
| 典型应用 | 非接触控制、智能面板、玩具、教育演示 | 手势功能优先 |
| 关键特性 | 内置手势识别、事件输出 | 需确认模块镜片和安装方向 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要快速实现近距离手势交互，而不是自己做光学算法的项目 |
| 不适合场景 | 精准距离、多目标手势、强阳光户外或复杂空间手势 |
| 主要优势 | 上层可直接处理手势事件，原型接入快 |
| 主要风险 | 手势误触、动作速度、安装方向和环境光干扰需要实测 |
| 替代型号 | APDS9960、TMG3992、VL53L5CX、VL53L7CX |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 初始化 | 按推荐寄存器序列配置 bank/page 和手势模式 |
| 读取 | 读取 gesture flag/status，转换为上层事件 |
| 中断 | 使用中断减少轮询功耗，事件处理要去抖 |
| 结构 | 确认模块方向、窗口透光和 IR 串扰 |
| 验证 | 分别测试不同距离、速度、手掌颜色和环境光 |
