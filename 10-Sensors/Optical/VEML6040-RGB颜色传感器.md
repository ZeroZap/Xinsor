# VEML6040 RGB颜色传感器

> **一句话描述:** Vishay I2C RGBW 颜色传感器，适合颜色趋势、色温估算、VEML 系列生态补齐和智能照明原型  
> **标签:** `#sensor/optical` `#sensor/color` `#protocol/i2c` `#vendor/vishay`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VEML6040** 是 Vishay VEML 系列 RGBW 颜色传感器候选，在收集入口中与 VEML6030/VEML6035/VEML607x 一起出现。它适合智能照明、颜色趋势、色温估算和 VEML 系列驱动生态补齐。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | VEML 系列常见接口 |
| 测量对象 | RGBW 颜色/光强趋势 | 非专业色度计 |
| 典型应用 | 智能照明、颜色分类、色温趋势 | RGBW 候选 |
| 关键特性 | 积分时间、低功耗、颜色通道输出 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 Vishay 生态、RGBW 光学采样、色温/颜色趋势的项目 |
| 不适合场景 | 专业光谱分析、严格颜色计量、高速机器视觉 |
| 主要优势 | I2C 简单，适合与 VEML ALS/UV 驱动一起抽象 |
| 主要风险 | 光源、距离、窗口和白平衡会显著影响颜色结果 |
| 替代型号 | TCS34725、BH1745、APDS9960、AS7341 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、默认配置和通道读取顺序 |
| 配置 | 设置积分时间、低功耗和中断/阈值策略 |
| 读取 | 输出 R/G/B/W raw，保留积分时间用于归一化 |
| 校准 | 固定光源、白板和外壳窗口透光率需要校准 |
| 兼容 | 与 VEML6035/VEML607x 同系列代码共用时保留能力表 |
