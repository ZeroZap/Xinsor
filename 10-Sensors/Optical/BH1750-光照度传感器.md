# BH1750 光照度传感器

> **一句话描述:** ROHM 低成本数字光照度传感器，I2C 接口，适合自动亮度调节、光照记录和智能照明  
> **标签:** `#sensor/optical` `#sensor/light` `#protocol/i2c` `#vendor/rohm`  
> **状态:** 已建档，索引标记为已验证  
> **最后更新:** 2026-05-23

---

## 概述

**BH1750** 是常见入门级环境光照度传感器，直接输出 lux 级光照数据，不需要复杂标定。它适合作为智能照明、屏幕亮度调节和光照记录项目的低成本首选。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址 `0x23/0x5C` |
| 测量对象 | 环境光照度 | 输出 lux |
| 测量范围 | 约 1-65535 lux | 覆盖室内/室外常见光照 |
| 典型应用 | 智能照明、屏幕亮度、光照记录 | 低成本易用 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本光照检测、自动亮度调节、教学项目 |
| 不适合场景 | 高精度校准照度计、多光谱分析、颜色识别 |
| 主要优势 | 便宜、资料多、I2C 简单、直接输出 lux |
| 主要风险 | 光学窗口、安装角度和外壳遮挡会显著影响读数 |
| 替代型号 | TSL2561、TSL2591、VEML6030、OPT3001 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址，BH1750 无标准 chip id |
| 配置 | 选择 continuous 或 one-time 测量模式 |
| 读取 | 读取 16-bit raw 值并换算 lux |
| 功耗 | 电池设备建议 one-time 测量后 power down |
| 结构 | 光窗透过率和遮光设计比软件更关键 |
