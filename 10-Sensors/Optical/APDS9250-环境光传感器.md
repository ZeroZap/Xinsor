# APDS9250 环境光传感器

> **一句话描述:** Broadcom I2C 多通道环境光/颜色传感器候选，适合自动亮度、色温趋势和 APDS/BH/TCS 系列对照  
> **标签:** `#sensor/optical` `#sensor/als` `#sensor/color` `#protocol/i2c` `#vendor/broadcom`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**APDS9250** 是 Broadcom APDS 系列环境光/颜色方向候选，可用于自动亮度调节、色温趋势和多通道光强采样。它适合作为 APDS9960、BH1745、TCS34725、VEML6040 之外的相邻型号补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | APDS 系列常见接口 |
| 测量对象 | 环境光/颜色趋势 | 具体通道以 datasheet 为准 |
| 典型应用 | 自动亮度、色温趋势、光源分类 | 多通道 ALS/颜色候选 |
| 关键特性 | 多通道光强、积分/增益配置、中断 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 APDS 系列生态、多通道 ALS/颜色趋势和色温估算的项目 |
| 不适合场景 | 专业色度计、完整光谱分析、高速机器视觉 |
| 主要优势 | 与 APDS9960 同厂生态，适合多通道 ALS/颜色驱动补齐 |
| 主要风险 | 光源、窗口、距离和白平衡校准会影响色温/颜色结果 |
| 替代型号 | APDS9960、BH1745、TCS34725、VEML6040 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/状态寄存器，确认 I2C 地址 |
| 配置 | 设置增益、积分时间、通道使能和中断阈值 |
| 读取 | 输出多通道 raw，保留积分时间和增益用于归一化 |
| 校准 | 固定光源、白板和外壳窗口透光率需要标定 |
| 兼容 | 与 APDS9960 驱动共用时不要假设寄存器完全一致 |
