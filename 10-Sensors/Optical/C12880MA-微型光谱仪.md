# C12880MA 微型光谱仪

> **一句话描述:** Hamamatsu 微型可见光光谱仪模块，适合科研原型、材料/光源光谱采集和高成本光谱分析  
> **标签:** `#sensor/optical` `#sensor/spectrometer` `#protocol/analog` `#vendor/hamamatsu`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**C12880MA** 是 Hamamatsu 常见微型光谱仪模块，定位高于 AS7341/AS7265x 这类多通道光谱传感器。它适合需要连续光谱形状、科研原型或光源/材料特征采集的场景，但驱动和模拟前端复杂度明显更高。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | 模拟输出 + 控制时序 | 需要 MCU/ADC 或外部采集电路 |
| 测量对象 | 可见光光谱 | 波段和分辨率以 datasheet 为准 |
| 典型应用 | 光源分析、材料识别原型、科研教学 | 高成本光谱方向 |
| 关键特性 | 微型光谱仪、连续光谱输出 | 不同于 I2C 数字光谱传感器 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要连续光谱曲线、预算充足、可接受模拟采集设计的项目 |
| 不适合场景 | 低成本颜色识别、简单环境光、普通 MCU 快速接入 |
| 主要优势 | 光谱信息量远高于普通 RGB/多通道传感器 |
| 主要风险 | 成本高，模拟前端、积分时间、暗电流和校准都需要系统设计 |
| 替代型号 | AS7265x、AS7341、专业 USB 光谱仪 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 硬件 | 需要稳定模拟采集链路、参考电压、遮光结构和光学窗口 |
| 时序 | 严格按 datasheet 控制 start、clock、积分和读出时序 |
| 采样 | ADC 分辨率、采样率、噪声和同步会决定实际光谱质量 |
| 校准 | 需要暗场扣除、波长校准、响应曲线校正和标准光源对比 |
| 数据 | 输出不是简单 lux/RGB，需要上层保存整条光谱向量 |
