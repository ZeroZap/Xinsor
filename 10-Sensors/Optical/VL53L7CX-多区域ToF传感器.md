# VL53L7CX 多区域ToF传感器

> **一句话描述:** ST 多区域 ToF 深度传感器候选，适合更高性能存在检测、手势、机器人近距感知和智能家居交互  
> **标签:** `#sensor/optical` `#sensor/tof` `#sensor/depth` `#protocol/i2c` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VL53L7CX** 是 ST 多区域 ToF 候选，面向多区域距离矩阵、存在检测、手势识别、机器人近距感知和智能家居交互。它可与 VL53L5CX 一起评估多区域 ToF 方案的性能、成本和资源占用。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 需关注带宽和初始化流程 |
| 测量对象 | 多区域距离矩阵 | 具体 zone/帧率以 datasheet 为准 |
| 典型应用 | 存在检测、手势、避障、空间占用 | 多区域 ToF 候选 |
| 关键特性 | 多 zone、目标状态、低分辨率深度图 | 依赖 ST API/ULD |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 对多区域 ToF 性能有要求的智能家居、机器人和交互设备 |
| 不适合场景 | 单点低成本接近检测、高分辨率深度相机、资源很小的 MCU |
| 主要优势 | 多区域深度信息可支撑更可靠的空间判断 |
| 主要风险 | API、RAM、带宽、热和光学结构都比单点 ToF 更复杂 |
| 替代型号 | VL53L5CX、TMF8821、VL53L3CX、摄像头方案 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 boot、固件加载/API 初始化和 ID |
| 配置 | 设置分辨率、帧率、测量模式、目标排序和中断 |
| 读取 | 需要矩阵数据结构、状态码、信号强度和 timestamp |
| 资源 | MCU RAM/Flash、I2C 带宽和帧率必须早期评估 |
| 结构 | 多 zone 对视场遮挡、盖板串扰和安装角度更敏感 |
