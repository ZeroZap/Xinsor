# OPT3002 环境光传感器

> **一句话描述:** TI 数字环境光/宽光谱响应传感器，I2C 接口，适合亮度趋势、红外/宽谱光源监测和 OPT3001 相邻评估  
> **标签:** `#sensor/optical` `#sensor/light` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**OPT3002** 是 TI OPT 系列环境光方向候选，适合需要数字光照趋势、宽光谱或非纯人眼响应场景的评估。它可与 OPT3001、OPT4001、VEML7700 和 TSL2591 对照，用于光源趋势、亮度控制和结构光窗验证。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | TI OPT 系列风格 |
| 测量对象 | 环境光/宽谱光照趋势 | 具体响应曲线以 datasheet 为准 |
| 测量范围 | 宽动态 ALS | 量程随配置变化 |
| 典型应用 | 光源趋势、亮度反馈、宽谱光监测、智能照明 | OPT3001 相邻候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 TI 数字 ALS、宽动态和非纯可见光趋势监测的设计 |
| 不适合场景 | 精密照度计、颜色识别、多通道光谱分析和 UV index |
| 主要优势 | TI 生态、I2C、可与 OPT3001/OPT4001 驱动抽象复用 |
| 主要风险 | 光谱响应与人眼 lux 不同，算法必须明确测量目标 |
| 替代型号 | OPT3001、OPT4001、TSL2591、VEML7700、LTR-303ALS |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、manufacturer/device ID 和转换状态 |
| 配置 | 设置转换时间、量程/自动量程、中断阈值和 latch 行为 |
| 读取 | 注意指数/尾数或厂商定义格式，避免直接当线性 raw 使用 |
| 校准 | 结合光窗、光源类型和响应曲线建立应用侧换算 |
| 验证 | 与 OPT3001/标准光源对比，明确差异来自光谱响应还是结构 |
