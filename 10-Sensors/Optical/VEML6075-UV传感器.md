# VEML6075 UV传感器

> **一句话描述:** Vishay I2C UVA/UVB 数字 UV 传感器，适合户外 UV index 趋势、环境监测和 VEML6070 升级评估  
> **标签:** `#sensor/optical` `#sensor/uv` `#protocol/i2c` `#vendor/vishay`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VEML6075** 是 Vishay 的数字 UV 传感器候选，可提供 UVA/UVB 相关数据，适合户外环境、可穿戴防晒提醒和 UV index 趋势检测。相对 VEML6070，它更适合需要 UVA/UVB 分量的项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字 UV 传感器接口 |
| 测量对象 | UVA、UVB 趋势 | UV index 换算以 datasheet 为准 |
| 典型应用 | 户外 UV、环境记录、防晒提醒 | UV 趋势检测 |
| 关键特性 | UVA/UVB、补偿/换算公式、低功耗 | 非专业辐照计 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 UVA/UVB 趋势、UV index 原型和户外环境记录的设备 |
| 不适合场景 | 法规/计量级 UV 辐照度、无 UV 透过窗口的封闭结构 |
| 主要优势 | I2C 接入简单，较 VEML6070 更适合 UV index 趋势 |
| 主要风险 | 光学窗口、角度响应、温度和校准会决定实际可信度 |
| 替代型号 | VEML6070、LTR390、SI1145、专业 UV 模块 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、ID/配置寄存器和默认状态 |
| 配置 | 设置积分时间、动态范围和测量模式 |
| 读取 | 分别读取 UVA/UVB raw，并按 datasheet 做补偿和 UVI 估算 |
| 结构 | 外壳窗口需 UV 透过，避免普通玻璃/塑料导致读数失真 |
| 验证 | 与参考 UV index、户外公开数据和不同窗口材料对比 |
