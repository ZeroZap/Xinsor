# AFE4404 心率血氧模拟前端

> **一句话描述:** TI PPG 模拟前端，SPI 接口，适合高性能心率/血氧原型、可穿戴健康和自定义光学结构  
> **标签:** `#sensor/optical` `#sensor/ppg` `#health` `#protocol/spi` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**AFE4404** 是 TI 面向 PPG 的模拟前端，通常需要外部 LED、光电二极管和完整光学/模拟设计。它适合比 MAX3010x 模块更高可控性的心率/血氧原型和产品化评估，但硬件和算法复杂度明显更高。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 高性能 AFE 常见接口 |
| 测量对象 | PPG 光电信号 | 需外部光学器件 |
| 典型应用 | 可穿戴健康、心率/血氧算法、定制光学结构 | 高性能 PPG AFE |
| 关键特性 | LED 驱动、TIA/ADC、时序采样、环境光抵消 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要自定义 LED/PD、信号链可控和高性能 PPG 的研发项目 |
| 不适合场景 | 快速入门、低成本模块、无模拟/光学设计能力的项目 |
| 主要优势 | 可控性强、适合产品级 PPG 信号链探索 |
| 主要风险 | 模拟前端、PCB、光学结构和算法难度高，bring-up 成本大 |
| 替代型号 | MAX30101、MAX30102、AFE4950、ADPD 系列 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 SPI 时序、寄存器读写和复位状态 |
| 时序 | LED pulse、ADC sampling、ambient cancellation 必须严格配置 |
| 读取 | 输出多相位 PPG raw 数据，保留 timestamp 和通道信息 |
| 硬件 | LED、PD、TIA、屏蔽、地分割和柔性结构共同决定信号质量 |
| 验证 | 用示波器、参考设备和不同佩戴压力评估 SNR 与伪影 |
