# BH1745 RGB颜色传感器

> **一句话描述:** ROHM I2C RGB/IR 颜色传感器，适合颜色识别、色温估算和智能照明原型  
> **标签:** `#sensor/optical` `#sensor/color` `#protocol/i2c` `#vendor/rohm`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**BH1745** 是 ROHM 的数字颜色传感器，常见于 Zephyr 支持列表。它可作为 TCS34725 的替代候选，用于 RGB 颜色识别、色温趋势和环境光特征采集。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字颜色传感器常见接口 |
| 测量对象 | RGB/IR 光强 | 具体通道定义以 datasheet 为准 |
| 典型应用 | 颜色识别、智能照明、屏幕/物体颜色检测 | 需要光学结构配合 |
| 关键特性 | 增益/积分时间可配、中断输出 | 适合低速颜色采样 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 I2C RGB 数据、TCS34725 替代、智能照明或颜色分类原型 |
| 不适合场景 | 专业光谱分析、高速机器视觉、无固定光源的精确颜色测量 |
| 主要优势 | 接口简单、可做颜色/色温趋势、生态中已有支持线索 |
| 主要风险 | 光源、距离、遮光和白平衡会显著影响颜色结果 |
| 替代型号 | TCS34725、APDS9960、AS7341 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/默认寄存器，确认 I2C 地址 |
| 配置 | 设置增益、积分时间、中断阈值和测量模式 |
| 读取 | 输出 R/G/B/IR raw 值，并保留积分时间用于换算 |
| 校准 | 使用固定光源和白板做归一化，避免直接比较 raw 值 |
| 结构 | 遮光、扩散片和目标距离会影响重复性 |
