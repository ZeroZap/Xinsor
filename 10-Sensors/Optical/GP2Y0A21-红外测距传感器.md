# GP2Y0A21 红外测距传感器

> **一句话描述:** Sharp 模拟红外三角测距传感器，适合机器人避障、近距离检测和教学项目  
> **标签:** `#sensor/optical` `#sensor/distance` `#protocol/analog` `#vendor/sharp`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**GP2Y0A21** 是经典模拟红外测距传感器，常用于 10-80 cm 级别的障碍物检测。它不需要复杂数字协议，但输出电压和距离是非线性关系。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | Analog | MCU ADC 读取 |
| 测量对象 | 近距离距离 | 红外三角测距 |
| 测量范围 | 约 10-80 cm | 近端/远端非线性明显 |
| 典型应用 | 机器人避障、液位/物体检测、教学 | 成本低、接入简单 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 简单避障、低成本模拟测距、教学项目 |
| 不适合场景 | 精密距离测量、强环境光、黑色/透明目标 |
| 主要优势 | 接线简单、响应快、资料多 |
| 主要风险 | 非线性、反射率影响大、需要 ADC 滤波和标定 |
| 替代型号 | VL53L0X、VL53L1X、VL6180X、超声波测距 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 采样 | ADC 多次采样和中值/均值滤波 |
| 换算 | 使用查表或拟合曲线从电压换算距离 |
| 校准 | 针对目标材质和安装角度做实测标定 |
| 供电 | 模拟输出对电源噪声敏感，注意去耦 |
| 边界 | 近端小于有效距离时读数可能反常 |
