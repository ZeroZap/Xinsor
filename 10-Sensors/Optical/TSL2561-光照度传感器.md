# TSL2561 光照度传感器

> **一句话描述:** ams 经典数字光照传感器，I2C 接口，适合低成本光照监测和自动亮度调节  
> **标签:** `#sensor/optical` `#sensor/light` `#protocol/i2c` `#vendor/ams`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**TSL2561** 是经典双通道数字光照传感器，可读取可见光/红外相关通道并估算 lux。它适合低成本光照监测、自动亮度调节和教学项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址可选 |
| 测量对象 | 环境光照度 | 双通道估算 lux |
| 测量范围 | 约 0.1-40000 lux | 以配置和光源为准 |
| 典型应用 | 光照记录、自动亮度、智能照明 | 经典低成本 ALS |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本数字光照、教学、室内光照监测 |
| 不适合场景 | 高动态强光、多光谱/颜色识别 |
| 主要优势 | 资料成熟、I2C、比模拟光敏电阻更稳定 |
| 主要风险 | 动态范围和新型号相比有限，lux 换算受光源影响 |
| 替代型号 | BH1750、TSL2591、VEML6030、OPT3001 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID 或确认 I2C 地址 |
| 配置 | 设置 gain、integration time 和 power state |
| 读取 | 读取两个通道并按公式估算 lux |
| 饱和 | 强光下检查通道饱和并调整增益 |
| 校准 | 结合外壳光窗做系统系数修正 |
