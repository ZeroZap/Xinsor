# VL53L4CD ToF测距传感器

> **一句话描述:** ST 短距高精度 ToF 接近/测距传感器候选，适合用户存在、近距离手势和低功耗接近检测  
> **标签:** `#sensor/optical` `#sensor/tof` `#sensor/proximity` `#protocol/i2c` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VL53L4CD** 是 ST FlightSense 系列短距 ToF 候选，适合近距离接近检测、用户存在、耳机/手机/智能家居交互和小型设备测距。它可作为 VL6180X、VL53L0X 的短距升级评估型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | ST ToF 接口 |
| 测量对象 | 短距距离/接近 | 量程以 datasheet 和结构为准 |
| 典型应用 | 接近、用户存在、手势前置判断、低功耗交互 | 短距 ToF 候选 |
| 关键特性 | 近距离测距、低功耗、阈值中断 | 需开窗和串扰校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 小型设备短距接近、用户存在和低功耗距离阈值判断 |
| 不适合场景 | 长距避障、多区域深度图、户外强光距离测量 |
| 主要优势 | 短距 ToF 定位明确，适合替代传统 IR 接近方案 |
| 主要风险 | 盖板材料、开窗、污渍和串扰对短距结果影响明显 |
| 替代型号 | VL6180X、VL53L0X、VL53L3CX、TMF8801 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/boot 状态，确认 I2C 通信和 XSHUT 控制 |
| 配置 | 设置 timing budget、低功耗周期、阈值和中断 |
| 读取 | 输出距离、状态、信号强度和环境光影响信息 |
| 校准 | offset、crosstalk、盖板玻璃和目标材质都要验证 |
| 结构 | 短距接近需重点测试手指、黑色材料、透明盖板和污渍 |
