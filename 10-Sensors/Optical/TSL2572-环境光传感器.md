# TSL2572 环境光传感器

> **一句话描述:** ams/TAOS 数字环境光传感器候选，适合低功耗背光调节和光照趋势检测  
> **标签:** `#sensor/optical` `#sensor/als` `#protocol/i2c` `#vendor/ams`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**TSL2572** 是 ams/TAOS 环境光传感器候选，适合自动背光、室内照度趋势和低功耗光照检测。它可作为 TSL2561、TSL2591 和 OPT3001 之间的补充型号，用于覆盖历史驱动和低成本数字 ALS 生态。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字 ALS 输出 |
| 测量对象 | 环境光 | 具体量程和精度以 datasheet 为准 |
| 典型应用 | 背光调节、光照趋势、低功耗设备 | ALS 单功能方向 |
| 关键特性 | 积分时间/增益配置、中断阈值 | 需要按光窗校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要数字 ALS、低功耗采样和阈值中断的设备 |
| 不适合场景 | 超高动态强光、UV/颜色/光谱分析、精准照度计 |
| 主要优势 | I2C 接入简单，适合作为 TSL2561/TSL2591 相邻候选 |
| 主要风险 | 具体封装、供货和光窗校准需结合项目确认 |
| 替代型号 | TSL2561、TSL2591、OPT3001、VEML6030 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/状态寄存器，确认 I2C 地址 |
| 配置 | 设置 gain、integration time 和中断阈值 |
| 读取 | 读取原始 ALS，再按配置换算趋势或 lux |
| 滤波 | 背光控制建议加入迟滞和变化率限制 |
| 校准 | 光窗、贴膜和外壳颜色会影响最终读数 |
