# TCS34725 RGB颜色传感器

> **一句话描述:** ams RGB + Clear 数字颜色传感器，I2C 接口，适合颜色识别、色温估算和光源检测  
> **标签:** `#sensor/optical` `#sensor/color` `#protocol/i2c` `#vendor/ams`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**TCS34725** 是常见 RGB 颜色传感器，提供红、绿、蓝和 clear 通道，常见模组带白光 LED。它适合颜色分类、色温估算、物体颜色识别和简单光源检测。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址 `0x29` |
| 测量对象 | RGB + Clear | 需配合光源/遮光结构 |
| 典型应用 | 颜色识别、色温、物料分拣、光源检测 | 模组常见 |
| 关键配置 | 增益、积分时间、LED 光源 | 决定动态范围和饱和风险 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 固定光源和距离下的颜色分类、色温估算、教育项目 |
| 不适合场景 | 专业色度计、多光谱分析、复杂环境光下精准颜色测量 |
| 主要优势 | 资料多、模组便宜、I2C、RGB/C 通道直观 |
| 主要风险 | 环境光、距离、角度和 LED 光源一致性会显著影响识别结果 |
| 替代型号 | APDS9960、AS7341、TMG3992 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID 寄存器确认器件 |
| 配置 | 设置 gain、integration time 和 enable 位 |
| 读取 | 读取 RGBC 原始值并检查饱和 |
| 归一化 | 固定光源下可用 clear 通道做归一化 |
| 结构 | 推荐固定测量距离、遮光罩和稳定 LED 电流 |
