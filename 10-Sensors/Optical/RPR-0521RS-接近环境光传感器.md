# RPR-0521RS 接近环境光传感器

> **一句话描述:** ROHM 环境光 + 接近检测数字传感器，I2C 接口，适合低功耗接近唤醒和亮度调节  
> **标签:** `#sensor/optical` `#sensor/proximity` `#sensor/light` `#protocol/i2c` `#vendor/rohm`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**RPR-0521RS** 是 ROHM 的 ALS + PS 二合一光学传感器，可用于接近唤醒、屏幕/面板亮度调节和小型交互设备。它与 AP3216C、VCNL4040、APDS9960 属于相近应用层，但功能重点是 ALS + 简单接近，而不是颜色或手势算法。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字 ALS/PS 输出 |
| 测量对象 | 环境光 + 红外接近 | 接近值用于阈值判断 |
| 测量范围 | 环境光和近距离接近趋势 | 具体范围以结构实测为准 |
| 典型应用 | 接近唤醒、屏幕亮度、面板防误触 | 消费电子常见需求 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低功耗 ALS + 简单接近检测的产品 |
| 不适合场景 | 精确测距、复杂手势、颜色识别或光谱分析 |
| 主要优势 | ROHM 光学器件生态、功能聚焦、适合阈值中断唤醒 |
| 主要风险 | 接近检测受窗口串光和目标反射率影响，需要结构联调 |
| 替代型号 | VCNL4040、AP3216C、APDS9960、VL6180X、BH1780 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、ID 寄存器和中断脚连接 |
| 配置 | 设置 ALS/PS 量程、积分时间、LED 脉冲和测量周期 |
| 读取 | 分离处理 ALS lux 趋势和 PS 接近强度，不要把 PS 当绝对距离 |
| 中断 | 用阈值和持续次数过滤瞬态遮挡与噪声 |
| 标定 | 上机后记录无目标 baseline、光窗串扰和典型目标阈值 |
