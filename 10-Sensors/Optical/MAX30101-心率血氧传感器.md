# MAX30101 心率血氧传感器

> **一句话描述:** Maxim/ADI 多 LED PPG 传感器，I2C 接口，适合心率、血氧趋势和可穿戴健康原型  
> **标签:** `#sensor/optical` `#sensor/ppg` `#health` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**MAX30101** 是 Maxim/ADI 的 PPG 传感器，常作为 MAX30102 同类候选。它适合可穿戴健康原型中的心率、血氧趋势检测，但算法、佩戴结构和运动伪影处理比普通光照传感器复杂得多。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见 PPG 模组接口 |
| 测量对象 | 红光/红外/绿光 PPG 信号 | 具体 LED 通道以型号为准 |
| 典型应用 | 心率趋势、血氧趋势、可穿戴健康设备 | 非医疗认证结论 |
| 关键特性 | LED 电流、采样率、FIFO 可配 | 需要算法和结构配合 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 健康手环、运动设备、PPG 算法验证和多 LED 采样原型 |
| 不适合场景 | 无医疗认证的诊断设备、强运动场景下直接输出准确 SpO2 |
| 主要优势 | PPG 生态成熟、FIFO/中断方便、可与 MAX30102 驱动思路复用 |
| 主要风险 | 佩戴压力、环境光、肤色、运动伪影和算法会决定最终效果 |
| 替代型号 | MAX30102、MAX30100、AFE4404、AFE4950 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 part ID/revision，确认 FIFO 可读 |
| 配置 | 设置 LED 电流、采样率、脉宽、平均次数和模式 |
| 读取 | 使用 FIFO 批量读取，保留 timestamp 和通道顺序 |
| 算法 | 原始 PPG 需滤波、峰值检测、运动伪影抑制和质量评估 |
| 结构 | 光学隔离、佩戴压力和防环境光设计比寄存器配置同样关键 |
