# MAX30102 心率血氧传感器

> **一句话描述:** Maxim 集成红光/红外 LED 与光电检测的 PPG 传感器，I2C 接口，适合心率和血氧趋势检测  
> **标签:** `#sensor/optical` `#sensor/ppg` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**MAX30102** 是常见 PPG 光学传感器，集成红光/红外 LED、光电二极管和模拟前端，常用于可穿戴心率/血氧趋势检测。它不是医疗诊断系统本身，算法、佩戴结构和运动伪影处理决定最终效果。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | FIFO 输出采样数据 |
| 测量对象 | PPG 红光/红外信号 | 心率/SpO2 需算法计算 |
| 典型应用 | 手环、指夹、健康监测原型 | 对结构和算法敏感 |
| 关键特性 | LED 电流、采样率、脉宽、FIFO | 需按功耗和信号质量配置 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 可穿戴健康原型、PPG 信号采集、心率/血氧趋势检测 |
| 不适合场景 | 未经认证的医疗诊断、强运动场景直接出准确血氧 |
| 主要优势 | 模组常见、资料多、I2C、集成 LED 和 AFE |
| 主要风险 | 算法、佩戴压力、遮光、运动伪影和肤色差异都会影响结果 |
| 替代型号 | MAX30100、MAX30105、AFE4404、ADPD 系列 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 PART ID/REV ID |
| 配置 | 设置 LED 电流、sample rate、pulse width 和 ADC range |
| 读取 | 使用 FIFO 批量读取 red/IR 数据 |
| 质量 | 检测饱和、脱落、环境光和运动伪影 |
| 功耗 | LED 电流是主要功耗来源，需按信噪比调节 |
