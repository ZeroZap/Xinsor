# TMF8801 ToF测距传感器

> **一句话描述:** ams OSRAM 单点 ToF 测距传感器候选，适合短距接近、距离阈值和 VL53L0X/VL6180X 替代评估  
> **标签:** `#sensor/optical` `#sensor/tof` `#sensor/distance` `#protocol/i2c` `#vendor/ams-osram`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**TMF8801** 是 ams OSRAM 的单点 ToF 测距候选，适合短距接近、用户存在、距离阈值和小型交互设备。它可作为 VL53L0X/VL6180X/VL53L4CD 的非 ST 替代评估。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 单点 ToF 接口 |
| 测量对象 | 距离/接近 | 量程以 datasheet 和结构为准 |
| 典型应用 | 接近、用户存在、短距测距、交互设备 | ams ToF 候选 |
| 关键特性 | ToF 测距、状态/置信度、低功耗测量 | 需盖板校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要非 ST 单点 ToF、短距接近和低功耗距离阈值的项目 |
| 不适合场景 | 多区域深度、远距避障、高速 3D 感知 |
| 主要优势 | 提供 VL53 系列之外的单点 ToF 选项 |
| 主要风险 | 光学窗口、串扰、黑色目标和强环境光需要实测 |
| 替代型号 | VL53L0X、VL53L4CD、VL6180X、TMF8821 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/状态，确认 I2C 地址和初始化流程 |
| 配置 | 设置测量周期、低功耗模式、中断和阈值 |
| 读取 | 输出距离、状态/置信度、环境光和错误码 |
| 校准 | offset、crosstalk、盖板玻璃和目标反射率要记录 |
| 兼容 | 与多区域 TMF8821 分开抽象，避免输出模型混用 |
