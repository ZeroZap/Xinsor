# OPT4048 多通道颜色传感器

> **一句话描述:** TI 多通道高精度颜色/光学传感器候选，适合色温、颜色趋势、显示亮度和工业光源监测  
> **标签:** `#sensor/optical` `#sensor/color` `#sensor/als` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**OPT4048** 是 TI 多通道颜色/光学传感器候选，可用于色温估算、显示/照明反馈、颜色趋势和光源监测。它适合作为 TCS34725、BH1745、APDS9250、VEML6040 之外的 TI 生态颜色方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | TI 光学传感器常见接口 |
| 测量对象 | 多通道颜色/环境光 | 通道定义以 datasheet 为准 |
| 典型应用 | 色温、显示亮度、智能照明、光源监测 | 多通道颜色候选 |
| 关键特性 | 多通道光强、增益/积分、阈值中断 | 需标定色温/颜色模型 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 TI 生态、多通道颜色/ALS 和较高动态表现的项目 |
| 不适合场景 | 专业光谱仪、严格色度计、高速机器视觉 |
| 主要优势 | 多通道颜色方向明确，适合智能照明和显示反馈 |
| 主要风险 | 光源、角度、窗口、距离和白平衡校准影响很大 |
| 替代型号 | TCS34725、BH1745、APDS9250、VEML6040、AS7341 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/配置寄存器，确认 I2C 地址和默认状态 |
| 配置 | 设置增益、积分时间、通道使能和阈值中断 |
| 读取 | 输出各通道 raw、增益、积分时间和饱和状态 |
| 校准 | 色温/颜色需要固定光源、白板和窗口透光率标定 |
| 应用 | 区分 raw 光学数据和上层色彩模型，不在驱动中硬编码业务算法 |
