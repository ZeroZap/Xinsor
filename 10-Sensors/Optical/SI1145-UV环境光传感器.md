# SI1145 UV环境光传感器

> **一句话描述:** Silicon Labs I2C UV/环境光/接近传感器候选，适合户外 UV 趋势、接近检测和旧项目维护  
> **标签:** `#sensor/optical` `#sensor/uv` `#sensor/als` `#sensor/proximity` `#protocol/i2c` `#vendor/silicon-labs`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SI1145** 是 Silicon Labs 的 UV/环境光/接近方向候选，常见于户外光照和 UV index 原型资料。它可作为 VEML6075、LTR390 的相邻方案补充，也适合维护旧项目中的 UV/ALS 功能。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见数字光学接口 |
| 测量对象 | UV 趋势、环境光、接近 | 具体功能以版本为准 |
| 典型应用 | 户外 UV、环境光、接近检测、旧项目维护 | 多功能光学候选 |
| 关键特性 | UV index 估算、ALS/IR/PS 思路 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 UV/ALS/接近组合、旧项目维护或 Silicon Labs 生态的项目 |
| 不适合场景 | 专业 UV 辐照测量、现代低功耗 ALS/UV 新产品首选 |
| 主要优势 | 功能组合丰富，适合作为 UV/ALS/PS 教学和旧项目入口 |
| 主要风险 | 新设计需确认供货、资料和替代型号，UV 估算需校准 |
| 替代型号 | LTR390、VEML6075、VEML6070、AP3216C |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 part ID/revision，确认 I2C 地址和 command 响应 |
| 配置 | 设置 ALS/UV/PS 通道、增益、采样周期和中断 |
| 读取 | 分别输出可见光/IR/UV/接近 raw 或估算值 |
| 校准 | UV index 和接近阈值需结合窗口材料、结构和参考数据修正 |
| 验证 | 户外 UV、室内光源、遮挡/接近三类场景都要覆盖 |
