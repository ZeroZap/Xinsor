# LTR390 UV环境光传感器

> **一句话描述:** Lite-On I2C UV/环境光传感器，适合 UV index 趋势、户外环境监测和 VEML6075 替代评估  
> **标签:** `#sensor/optical` `#sensor/uv` `#sensor/als` `#protocol/i2c` `#vendor/liteon`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**LTR390** 是 Lite-On 的 UV/环境光数字传感器候选，常用于户外 UV index 趋势、环境光记录和可穿戴防晒提醒原型。它可作为 VEML6075、VEML6070 和 SI1145 的替代评估型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字 UV/ALS 接口 |
| 测量对象 | UV、环境光趋势 | UV index 换算以 datasheet 为准 |
| 典型应用 | 户外 UV、环境记录、防晒提醒、光照趋势 | UV + ALS 候选 |
| 关键特性 | UV/ALS 模式、增益/积分配置 | 非专业 UV 辐照计 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 UV index 趋势和 ALS 同时采集的户外/可穿戴项目 |
| 不适合场景 | 计量级 UV 辐照度、无 UV 透过窗口的结构 |
| 主要优势 | I2C 简单，可同时覆盖 UV 和光照趋势 |
| 主要风险 | 窗口材料、太阳角度、温度和标定会显著影响结果 |
| 替代型号 | VEML6075、VEML6070、SI1145、VEML6035 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/状态寄存器，确认 I2C 地址 |
| 配置 | 设置 UV/ALS 模式、增益、积分时间和中断阈值 |
| 读取 | 分开输出 UV raw、ALS raw 和估算 index/lux |
| 结构 | 需要 UV 透过窗口，普通玻璃/塑料会导致严重误差 |
| 验证 | 与 VEML6075 和公开 UV index 数据做户外趋势对比 |
