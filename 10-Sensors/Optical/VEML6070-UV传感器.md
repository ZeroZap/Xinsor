# VEML6070 UV传感器

> **一句话描述:** Vishay I2C UVA 传感器，适合紫外线趋势监测、户外光照节点和 VEML UV 系列生态补齐  
> **标签:** `#sensor/optical` `#sensor/uv` `#protocol/i2c` `#vendor/vishay`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VEML6070** 是 Vishay 紫外线传感器候选，偏向 UVA 趋势检测。它适合户外 UV 趋势、环境记录和可穿戴防晒提醒原型；如果需要 UVA/UVB 或 UV index 更完整输出，可评估 VEML6075。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | UV 传感器常见接口 |
| 测量对象 | UVA 趋势 | 具体波段以 datasheet 为准 |
| 典型应用 | 户外 UV、环境记录、防晒提醒 | 紫外线趋势检测 |
| 关键特性 | 积分时间配置、低功耗 | 非专业 UV 辐照计 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本 UVA 趋势、户外环境节点、VEML UV 系列补齐 |
| 不适合场景 | 精密 UV 辐照测量、完整 UVA/UVB 分离、新产品高精度 UV index |
| 主要优势 | I2C 简单，适合做 UV 趋势检测原型 |
| 主要风险 | 窗口材料、太阳角度、温度和光谱响应会影响结果 |
| 替代型号 | VEML6075、LTR390、SI1145、专业 UV 传感器 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和积分时间配置 |
| 读取 | 输出 raw UV 趋势值，保留积分时间用于换算 |
| 校准 | 与参考 UV 表或公开 UV index 做趋势对比 |
| 结构 | 外壳窗口必须透 UV，普通透明塑料可能严重衰减 |
| 验证 | 户外不同太阳角度、云量和窗口材料下做长期记录 |
