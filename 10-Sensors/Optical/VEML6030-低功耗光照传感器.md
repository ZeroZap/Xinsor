# VEML6030 低功耗光照传感器

> **一句话描述:** Vishay 低功耗高分辨率环境光传感器，I2C 接口，适合电池设备和智能照明  
> **标签:** `#sensor/optical` `#sensor/light` `#protocol/i2c` `#vendor/vishay`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**VEML6030** 是低功耗环境光照度传感器，适合对平均功耗敏感的 IoT 节点、智能照明和屏幕亮度调节。它支持可配置增益和积分时间，便于在不同光照环境下取舍分辨率和响应速度。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 适合 MCU 直连 |
| 测量对象 | 环境光照度 | 人眼响应曲线较友好 |
| 测量范围 | 约 0-120000 lux | 室内外光照覆盖较广 |
| 典型应用 | 智能照明、低功耗光照节点、屏幕亮度 | 低功耗是核心卖点 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池供电光照监测、智能照明、需要较好动态范围的 ALS |
| 不适合场景 | 颜色识别、光谱分析、需要工业计量级照度 |
| 主要优势 | 低功耗、动态范围大、I2C、配置灵活 |
| 主要风险 | 光窗材料和结构遮挡会带来系统误差，需实机校准 |
| 替代型号 | BH1750、TSL2591、OPT3001、TSL2561 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 配置 | 设置 gain、integration time、persistence 和 interrupt |
| 读取 | 读取 ALS 数据并按配置换算 lux |
| 低功耗 | 低频采样后进入 shutdown 或降低积分频率 |
| 中断 | 可用于亮度阈值唤醒或照明联动 |
| 校准 | 结合外壳光窗做一次系统系数修正 |
