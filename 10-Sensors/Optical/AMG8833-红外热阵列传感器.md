# AMG8833 红外热阵列传感器

> **一句话描述:** Panasonic 8x8 红外热阵列传感器，适合低分辨率热源检测、人体存在和温度分布趋势  
> **标签:** `#sensor/optical` `#sensor/thermal` `#protocol/i2c` `#vendor/panasonic`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**AMG8833** 是常见 8x8 红外热阵列传感器，可输出低分辨率热图。它适合人体存在检测、热源方向判断、低成本热成像演示、设备温度分布趋势和教育原型，不适合高分辨率热像仪或精准体温筛查。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 输出像素温度矩阵 |
| 测量对象 | 红外热辐射/温度分布 | 低分辨率热阵列 |
| 典型应用 | 人体存在、热源检测、教育热成像 | 8x8 热图方向 |
| 关键特性 | 非接触、低分辨率阵列、上手简单 | 视场、距离和发射率影响读数 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 只需要粗略热源位置、存在检测和热分布趋势的设备 |
| 不适合场景 | 人脸识别、高清热图、医学测温、远距离小目标检测 |
| 主要优势 | I2C 接入简单，数据量小，适合 MCU 直接处理 |
| 主要风险 | 分辨率低、视场宽、发射率和环境温度会影响判断 |
| 替代型号 | MLX90640、MLX90641、MLX90614、VL53L5CX |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和模式配置 |
| 读取 | 周期读取像素矩阵和热敏参考值，保持统一 timestamp |
| 滤波 | 对像素做时间滤波、坏点处理和背景温度补偿 |
| 算法 | 人体存在建议用区域最大值、质心和背景差分 |
| 结构 | 外壳窗口材料必须透过长波红外，普通透明塑料通常不适合 |
