# VL53L5CX 多区域ToF传感器

> **一句话描述:** ST 多区域 ToF 深度传感器候选，适合手势、人数/存在检测、避障和低分辨率深度图  
> **标签:** `#sensor/optical` `#sensor/tof` `#sensor/depth` `#protocol/i2c` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**VL53L5CX** 是 ST 多区域 ToF 传感器候选，可输出低分辨率距离矩阵，适合存在检测、手势、人数趋势、机器人近距避障和空间占用判断。它比单点 VL53L0X/L1X 更适合需要粗略空间分布的场景。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数据量比单点 ToF 更大 |
| 测量对象 | 多区域距离矩阵 | 区域数/帧率以 datasheet 和模式为准 |
| 典型应用 | 手势、存在检测、人数趋势、避障 | 低分辨率深度候选 |
| 关键特性 | 多 zone ToF、目标状态、矩阵输出 | 依赖 ST ULD/API |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低分辨率深度图、空间占用和多区域距离判断的项目 |
| 不适合场景 | 高分辨率 3D 相机、远距户外测距、极低 MCU 资源设备 |
| 主要优势 | 多区域输出能显著提升手势/存在检测表达能力 |
| 主要风险 | API 体积、RAM、I2C 带宽、标定和外壳光学设计更复杂 |
| 替代型号 | VL53L7CX、TMF8821、VL53L3CX、摄像头深度方案 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 boot、firmware/API 初始化和 I2C 通信稳定 |
| 配置 | 设置分辨率、帧率、测距模式、目标排序和中断 |
| 读取 | 输出每 zone 距离、状态、信号强度和环境光信息 |
| 性能 | 评估 I2C 带宽、MCU RAM、帧率和功耗 |
| 校准 | crosstalk、offset、外壳窗口和视场遮挡需要实测 |
