# AS7341 多通道光谱传感器

> **一句话描述:** ams 11 通道可见光/NIR 光谱传感器，I2C 接口，适合光谱分析、颜色识别和农业/水质原型  
> **标签:** `#sensor/optical` `#sensor/spectral` `#protocol/i2c` `#vendor/ams`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**AS7341** 是多通道光谱传感器，可采集多个可见光波段和 NIR 信息。它比普通 RGB 传感器提供更多光谱维度，适合颜色分类、光源分析、农业植被趋势、水质/材料识别原型。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 需要按通道组读取 |
| 测量对象 | 多通道可见光 + NIR | 11 通道级别 |
| 典型应用 | 光谱分析、颜色分类、农业/水质原型 | 非科研级光谱仪 |
| 关键配置 | 增益、积分时间、SMUX | 驱动复杂度高于 RGB 传感器 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 RGB 更多光谱维度的材料/颜色/光源分析原型 |
| 不适合场景 | 专业科研级光谱仪、极低成本颜色识别 |
| 主要优势 | 通道多、I2C、模组可买、适合算法特征输入 |
| 主要风险 | 光源、积分时间、通道切换和校准决定数据可用性 |
| 替代型号 | TCS34725、AS7265x、TMG3992 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID，确认器件和 I2C 通信 |
| 配置 | 设置 gain、integration time 和 SMUX 通道映射 |
| 读取 | 分组读取多通道数据并检查饱和 |
| 校准 | 固定光源下做白板/暗场校准更可靠 |
| 算法 | 多通道数据更适合做分类特征而非直接物理浓度 |
