# DPS368 高精度气压传感器

> **一句话描述:** Infineon 高性能低功耗气压/温度传感器，I2C/SPI 接口，适合工业便携设备、无人机和精密高度趋势检测  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/infineon`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**DPS368** 是 Infineon DPS 系列的高性能气压传感器，定位高于常规入门气压计。它适合对噪声、功耗和高度变化分辨率有更高要求的无人机、工业便携设备和环境监测节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 与 DPS310 驱动思路接近 |
| 测量对象 | 气压、温度 | 内置补偿参数 |
| 气压范围 | 300-1200 hPa | 常规海拔/气象应用 |
| 典型精度 | 约 ±0.0015 hPa 分辨率级别 | 实际高度精度取决于系统噪声 |
| 典型应用 | 无人机、工业便携、精密高度趋势检测 | 高性能候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 对噪声、响应和分辨率要求高于 DPS310 的项目 |
| 不适合场景 | 成本敏感消费项目、水下测深、工业高压 |
| 主要优势 | 高分辨率、低功耗、I2C/SPI、适合高端气压高度计 |
| 主要风险 | 成本和供货需要提前确认；补偿和过采样配置不能简化处理 |
| 替代型号 | DPS310、MS5611、LPS22HH、BMP390、BMP388 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取产品 ID，确认总线通信和地址配置 |
| 校准 | 读取补偿系数，注意位宽和符号扩展 |
| 配置 | 设置采样率、过采样、温度源和测量模式 |
| 读取 | 获取 raw pressure/raw temperature 后做补偿换算 |
| 验证 | 静态测试重点观察噪声、漂移和高度换算稳定性 |
