# MPL115A2 气压传感器

> **一句话描述:** NXP 低成本数字气压传感器，I2C 接口，适合旧项目维护、简单气压趋势和 MPL3115A2 对照  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#vendor/nxp`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MPL115A2** 是 NXP 早期低成本气压传感器，适合简单气压趋势、旧项目维护和驱动兼容性补充。相对 MPL3115A2，它更偏基础气压采集，不适合作为高精度高度计首选。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | A2 后缀常见为 I2C 版本 |
| 测量对象 | 气压、温度 | 温度用于补偿 |
| 典型应用 | 简单气压趋势、旧项目维护、教育 | 低成本历史型号 |
| 关键特性 | 校准系数、数字输出 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 维护已有 MPL115A2 硬件、做基础气压趋势或 NXP 气压驱动对照 |
| 不适合场景 | 精密海拔、无人机定高、低噪声气象站 |
| 主要优势 | 接口简单、NXP 资料可查、适合历史兼容 |
| 主要风险 | 精度和生态不如后续 MPL3115A2/BMP/DPS 系列 |
| 替代型号 | MPL3115A2、BMP280、LPS22HB、DPS310 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和转换状态寄存器 |
| 校准 | 读取补偿系数，按 datasheet 公式计算压力 |
| 测量 | 触发转换后等待完成，再读取压力/温度 raw 值 |
| 换算 | 输出 pressure_kpa/pa，避免和 MPL3115A2 寄存器混用 |
| 验证 | 与 BMP280/MPL3115A2 对比趋势一致性和噪声 |
