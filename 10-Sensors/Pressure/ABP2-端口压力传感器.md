# ABP2 端口压力传感器

> **一句话描述:** Honeywell TruStability ABP2 数字端口压力传感器候选，适合气路、液路、泵压和医疗/工业低压测量  
> **标签:** `#sensor/pressure` `#sensor/ported-pressure` `#protocol/i2c` `#protocol/spi` `#vendor/honeywell`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ABP2** 是 Honeywell TruStability 系列端口压力传感器候选，面向气路、液路、泵压、医疗设备和工业低压测量。它适合作为 MPRLS 的更完整端口压力方案对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体版本以订货型号为准 |
| 测量对象 | 绝压/表压/差压等 | 取决于订货型号和端口结构 |
| 典型应用 | 气路、液路、泵压、医疗/工业低压 | 多量程端口压力 |
| 关键特性 | 数字补偿、多量程、多端口形式 | 需确认介质兼容 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要端口式压力、数字输出和较多量程/压力类型可选的项目 |
| 不适合场景 | 普通海拔计、极低成本气压趋势、水下深度高压测量 |
| 主要优势 | 订货选项丰富，适合管路压力和设备级产品化设计 |
| 主要风险 | 型号编码复杂，介质、端口、量程和压力类型必须严格确认 |
| 替代型号 | MPRLS、ABP、HSC、SSC |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C/SPI 版本、状态位和转换完成标志 |
| 配置 | 记录订货型号、量程、压力类型、单位和输出格式 |
| 读取 | 输出压力、温度、状态位和诊断错误 |
| 校准 | 零点、满量程和温度漂移要结合实际管路校验 |
| 结构 | 管路冷凝、堵塞、介质兼容和过压保护必须评估 |
