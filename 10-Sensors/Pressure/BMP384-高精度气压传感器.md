# BMP384 高精度气压传感器

> **一句话描述:** Bosch BMP3xx 系列高精度气压传感器，I2C/SPI 接口，适合耐环境封装需求、户外高度和运动设备候选  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**BMP384** 是 Bosch BMP3xx 系列气压传感器候选，适合需要更强环境适应性或封装取舍的户外高度检测项目。它可与 BMP388/BMP390 一起作为 Bosch 高精度气压系列的选型池。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体接口以型号配置为准 |
| 测量对象 | 气压、温度 | 温度用于补偿 |
| 典型应用 | 户外高度、运动设备、气象趋势、机器人 | BMP3xx 高精度方向 |
| 关键特性 | 高分辨率气压、低功耗模式、滤波配置 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | Bosch 生态项目、户外高度检测、需要评估 BMP3xx 封装/环境特性的设计 |
| 不适合场景 | 水下深度、高压工业过程、只需低成本海拔趋势的项目 |
| 主要优势 | 可纳入 BMP388/BMP390 同系列对比，适合高精度气压候选池 |
| 主要风险 | 具体封装、滤波和补偿流程需按 datasheet 逐项确认 |
| 替代型号 | BMP380、BMP388、BMP390、LPS22HH |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip ID，确认总线模式和软复位流程 |
| 校准 | 补偿参数格式需与具体 BMP3xx 型号匹配 |
| 配置 | 设置 ODR、oversampling、IIR filter 和功耗模式 |
| 结构 | 户外壳体需使用防水透气膜，避免气流冲击和凝露 |
| 验证 | 做静态噪声、温度漂移和快速高度变化响应测试 |
