# ICP10125 低功耗气压传感器

> **一句话描述:** TDK InvenSense 低功耗数字气压传感器，适合可穿戴、手机高度计和电池设备气压趋势检测  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#vendor/tdk`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ICP10125** 是 TDK InvenSense 的低功耗气压传感器候选，面向可穿戴、手机高度计、低功耗环境节点和室内楼层变化检测。它适合作为 BMP390、LPS22HH、DPS310 之外的低功耗气压方案对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见数字气压接口 |
| 测量对象 | 绝对气压、温度 | 量程和精度以 datasheet 为准 |
| 典型应用 | 可穿戴、高度计、楼层检测、电池节点 | 低功耗气压候选 |
| 关键特性 | 低功耗、温度补偿、多测量模式 | 需要压力孔和防风结构配合 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低功耗气压/高度趋势、楼层变化和可穿戴高度计的项目 |
| 不适合场景 | 水下压力、工业管路压力、差压流量测量 |
| 主要优势 | 低功耗定位明确，适合作为可穿戴/手机类气压方案候选 |
| 主要风险 | 结构开孔、温度梯度、风压和外壳密封会影响高度稳定性 |
| 替代型号 | BMP390、LPS22HH、DPS310、LPS28DFW |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取设备 ID/状态，确认 I2C 地址和测量命令响应 |
| 配置 | 选择低功耗/低噪声模式、采样周期和中断策略 |
| 读取 | 输出气压、温度和 timestamp，保留原始值用于滤波调试 |
| 滤波 | 楼层检测需要低通、异常点剔除和本地基准气压更新 |
| 结构 | 压力孔需要防尘、防水溅和避免直接气流冲击 |
