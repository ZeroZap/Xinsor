# MS8607 温湿压传感器

> **一句话描述:** TE Connectivity 温度、湿度、气压三合一环境传感器，I2C 接口，适合气象站、环境节点和空间受限设备  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/te`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MS8607** 是 TE Connectivity 的温湿压三合一环境传感器候选，适合需要同时采集气压、温度和湿度的节点。它可与 BME280、BME680、MS5637 + 独立湿度传感器组合做对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 可能包含多个功能地址/命令集合，需以 datasheet 为准 |
| 测量对象 | 气压、温度、湿度 | 三合一环境采集 |
| 测量范围 | 常见环境监测范围 | 以 datasheet 为准 |
| 典型应用 | 气象站、环境监测、室内舒适度、低功耗节点 | 替代 BME280 的 TE 方案 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要温湿压三合一、TE 生态和环境节点一体化采集 |
| 不适合场景 | VOC/气体识别、水下压力、极低成本单一气压计 |
| 主要优势 | 温湿压集成、I2C、适合气象站和环境监测 BOM 简化 |
| 主要风险 | 温湿度与气压采样节奏、热源隔离和湿度恢复时间需要实测 |
| 替代型号 | BME280、BME680、MS5637、HDC3020 + BMP390、SHT45 + BMP581 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、压力/湿度功能块命令和复位流程 |
| 采样 | 分别处理气压、温度、湿度转换时间，避免阻塞主循环 |
| 补偿 | 压力和湿度补偿流程可能独立，需按 datasheet 拆分实现 |
| 功耗 | 周期采样后进入低功耗状态，记录平均电流 |
| 结构 | 传感器应远离 MCU/电源热源，湿度开孔需防尘防凝露 |
