# SDP31 差压传感器

> **一句话描述:** Sensirion 数字差压传感器，适合风量、滤网堵塞、医疗呼吸流量和低压差趋势检测  
> **标签:** `#sensor/pressure` `#sensor/differential-pressure` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SDP31** 是 Sensirion SDP3x 系列数字差压传感器候选，适用于低压差、气流、滤网堵塞、HVAC 和呼吸流量趋势检测。它与绝对气压计不同，关注两个端口之间的压力差。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字差压接口 |
| 测量对象 | 差压 | 具体量程以 SDP3x 子型号为准 |
| 典型应用 | 风量、滤网、HVAC、呼吸流量、泄漏检测 | 低压差气体应用 |
| 关键特性 | 高灵敏度差压、温度补偿、连续采样 | 通道结构和介质限制需确认 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要测压差、气流趋势、滤网堵塞和低压气路状态的项目 |
| 不适合场景 | 海拔高度计、水下压力、液体高压、普通电池设备环境气压 |
| 主要优势 | 差压方向明确，适合补齐绝对气压传感器无法覆盖的风道/气路场景 |
| 主要风险 | 端口污染、冷凝、气路漏气和流量换算模型会影响结果 |
| 替代型号 | SDP810、SDP800、MPRLS、Honeywell ABP |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取序列号/状态，确认 I2C 地址和命令响应 |
| 配置 | 设置连续/单次测量、平均策略和单位换算 |
| 读取 | 同步输出差压、温度和 CRC 校验结果 |
| 校准 | 零压差校准、管路泄漏检查和安装方向要纳入 bring-up |
| 应用 | 风量换算需要孔板/管道模型，不应直接把压差等同流量 |
