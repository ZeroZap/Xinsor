# SSC 端口压力传感器

> **一句话描述:** Honeywell TruStability SSC 标准精度端口压力传感器候选，适合工业、气路和中等精度压力测量  
> **标签:** `#sensor/pressure` `#sensor/ported-pressure` `#protocol/i2c` `#protocol/spi` `#vendor/honeywell`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SSC** 是 Honeywell TruStability 标准精度端口压力系列候选，适用于工业控制、气路/液路压力、泵压和设备状态监测。它与 HSC 同属 TruStability 生态，但定位更偏标准精度和成本平衡。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI/模拟版本常见 | 订货型号决定 |
| 测量对象 | 绝压/表压/差压 | 量程以型号为准 |
| 典型应用 | 工业气路、泵压、液路、设备状态 | 标准精度端口压力 |
| 关键特性 | 数字补偿、多量程、多接口 | 需要订货编码管理 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 ABP 更完整工业生态，但不需要 HSC 高精度成本的项目 |
| 不适合场景 | 开放气压高度、极低成本压力趋势、水下高压深度计 |
| 主要优势 | TruStability 标准精度分档，适合工业端口压力常规场景 |
| 主要风险 | 量程、端口、接口、介质和温度范围必须按订货号核对 |
| 替代型号 | HSC、ABP2、ABP、MPRLS |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 解析状态位，确认数据是否 stale/fault |
| 配置 | 建立型号能力表，包含量程、压力类型和输出比例 |
| 读取 | 输出压力、温度和状态码 |
| 校准 | 管路安装后做零点和满量程趋势验证 |
| 可靠性 | 过压、冷凝、污染和长期漂移需要故障日志 |
