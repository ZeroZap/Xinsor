# LPS28DFW 防水气压传感器

> **一句话描述:** ST 防水数字气压传感器候选，适合户外设备、运动手表和需要防水封装的高度/气压趋势检测  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#sensor/waterproof` `#protocol/i2c` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**LPS28DFW** 是 ST 面向防水应用的数字气压传感器候选，适合运动手表、户外记录仪、可穿戴和需要防水透气结构的环境设备。它可作为 LPS33HW、LPS22HH 的新一代相邻型号补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/I3C | 具体接口能力以 datasheet 为准 |
| 测量对象 | 绝对气压、温度 | 防水封装气压候选 |
| 典型应用 | 运动手表、户外节点、防水设备 | 需要压力透气膜 |
| 关键特性 | 防水封装、低噪声气压、FIFO/中断思路 | 结构设计影响响应时间 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要防水气压/高度趋势的可穿戴、户外和运动设备 |
| 不适合场景 | 水下深度计、工业高压、水压直接测量 |
| 主要优势 | ST 生态延续，适合从 LPS22/LPS33 系列迁移评估 |
| 主要风险 | 防水膜、壳体腔体、冷凝和温度梯度会影响响应与稳定性 |
| 替代型号 | LPS33HW、LPS22HH、ICP10125、BMP390 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C/I3C 模式和复位状态 |
| 配置 | 设置 ODR、低噪声/低功耗模式、FIFO 和中断阈值 |
| 读取 | 输出气压/温度，并暴露 FIFO overrun、data ready 等状态 |
| 结构 | 防水透气膜会带来延迟，动态高度检测需要实测响应时间 |
| 兼容 | 与 LPS22HH/LPS33HW 驱动共用时保留寄存器能力差异 |
