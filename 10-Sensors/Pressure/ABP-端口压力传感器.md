# ABP 端口压力传感器

> **一句话描述:** Honeywell TruStability ABP 系列端口压力传感器候选，适合气路/液路低压、泵压和工业压力趋势  
> **标签:** `#sensor/pressure` `#sensor/ported-pressure` `#protocol/i2c` `#protocol/spi` `#vendor/honeywell`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ABP** 是 Honeywell TruStability 基础端口压力系列候选，常用于气路、液路、泵压、医疗设备和工业低压趋势监测。它适合与 ABP2、MPRLS、HSC/SSC 形成 Honeywell 端口压力候选池。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI/模拟版本常见 | 具体订货型号决定 |
| 测量对象 | 端口压力 | 表压/差压/绝压等以型号为准 |
| 典型应用 | 泵压、气路、液路、医疗/工业低压 | TruStability 生态 |
| 关键特性 | 多量程、多接口、多封装端口 | 型号编码需核对 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要端口式压力传感器、量程可选和成熟工业/医疗生态的项目 |
| 不适合场景 | 开放环境气压高度、水下深度、极低成本入门压力检测 |
| 主要优势 | 系列生态成熟，覆盖多种端口、量程和输出方式 |
| 主要风险 | 订货型号复杂，介质兼容、冷凝、堵塞和过压需要验证 |
| 替代型号 | ABP2、MPRLS、HSC、SSC |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认接口版本、状态位和数据长度 |
| 配置 | 固化量程、压力类型、输出比例和温度补偿参数 |
| 读取 | 输出压力、温度和诊断状态 |
| 校准 | 零压/满量程点需与实际管路做对比 |
| 维护 | 管路污染、冷凝和过压事件要记录到故障日志 |
