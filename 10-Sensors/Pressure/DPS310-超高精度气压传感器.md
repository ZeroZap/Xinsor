# DPS310 超高精度气压传感器

> **一句话描述:** Infineon 高精度数字气压/温度传感器，I2C/SPI 接口，适合无人机定高、气象站和室内高度变化检测  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/infineon`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**DPS310** 是 Infineon 的高精度数字气压传感器，可输出气压和温度数据。相对 BMP280/LPS22HB，它更偏向高分辨率高度变化检测，适合无人机、机器人、气象节点和室内楼层/高度趋势判断。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 常见模组多为 I2C |
| 测量对象 | 气压、温度 | 内置补偿参数 |
| 气压范围 | 300-1200 hPa | 覆盖常规海拔/天气应用 |
| 典型精度 | 约 ±0.002 hPa 分辨率级别 | 实际高度精度取决于噪声、滤波和校准 |
| 典型应用 | 无人机定高、气象站、室内高度变化 | 高分辨率是核心卖点 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 BMP280 更高分辨率的高度/气压趋势检测 |
| 不适合场景 | 极低成本项目、水下压力、工业高压 |
| 主要优势 | 高分辨率、I2C/SPI 双接口、温度补偿、生态资料较多 |
| 主要风险 | 驱动需正确读取补偿参数并处理过采样配置；模组货源差异较大 |
| 替代型号 | BMP280、LPS22HB、MS5611、DPS368、LPS22HH |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取产品 ID，确认 I2C 地址或 SPI 通信正常 |
| 校准 | 读取 COEF 区域补偿参数，注意有符号位扩展 |
| 配置 | 设置气压/温度采样率、过采样和测量模式 |
| 读取 | 分别读取 raw pressure/raw temperature，再套用补偿公式 |
| 滤波 | 定高应用建议使用滑动平均或卡尔曼滤波 |
