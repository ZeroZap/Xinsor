# BMP581 高精度气压传感器

> **一句话描述:** Bosch 新一代高精度低功耗气压传感器，I2C/SPI/I3C 接口，适合可穿戴、无人机定高和室内楼层检测  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#protocol/spi` `#protocol/i3c` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**BMP581** 是 Bosch BMP5xx 系列气压传感器候选，面向高精度、低噪声和低功耗气压/高度检测。它适合与 BMP390、BMP388、DPS310 做对照，用于可穿戴高度、楼层识别、无人机定高和环境气压趋势采集。

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低噪声、高分辨率和低功耗气压高度趋势的产品 |
| 不适合场景 | 水下深度、管路压力、强气流直吹且无机械隔离的场景 |
| 主要优势 | Bosch 新生态、接口选择多、适合替代 BMP390/BMP388 评估 |
| 主要风险 | 高精度高度依赖气压基准、温度补偿、结构腔体和滤波策略 |
| 替代型号 | BMP390、BMP388、BMP585、DPS310、ICP20100 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id，确认总线模式和软复位后状态 |
| 配置 | 设置 ODR、过采样、IIR 滤波和低功耗/高性能模式 |
| 补偿 | 使用厂商补偿系数计算压力和温度，不要直接使用 raw 值 |
| 滤波 | 高度应用需结合移动平均/卡尔曼和本地海平面气压基准 |
| 结构 | 避免防水膜、外壳腔体和热源造成气压延迟或温漂 |
