# LPS33HW 防水气压传感器

> **一句话描述:** ST 防水数字气压/温度传感器，I2C/SPI 接口，适合户外、运动设备和潮湿环境气压高度测量  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**LPS33HW** 是 ST 面向户外/潮湿环境的防水气压传感器。它适合需要通气但又要降低液体、水汽、汗液风险的设备，例如运动手表、户外记录仪和便携式环境节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 与 ST pressure 系列驱动结构接近 |
| 测量对象 | 气压、温度 | 数字输出 |
| 气压范围 | 260-1260 hPa | 覆盖高度/天气应用 |
| 典型精度 | 约 ±0.15 hPa | 实际高度精度依赖结构通气 |
| 典型应用 | 户外设备、运动手表、潮湿环境监测 | 防水封装是核心卖点 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 户外、防汗、防潮环境下的气压/高度测量 |
| 不适合场景 | 厘米级无人机定高、水下深度测量、工业高压 |
| 主要优势 | 防水封装、低功耗、ST 生态成熟、寄存器模型相对清晰 |
| 主要风险 | 防水不等于可水下测深；结构通气孔和防水透气膜仍需设计 |
| 替代型号 | LPS22HB、LPS22HH、BMP280、DPS310 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认器件型号 |
| 配置 | 设置 ODR、低通滤波、block data update |
| 读取 | 读取 pressure/temp 输出寄存器并换算物理量 |
| 中断 | 可按需配置数据就绪或 FIFO 相关中断 |
| 结构 | 软件滤波需结合外壳通气响应时间调整 |
