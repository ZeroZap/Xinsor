# BMP280 气压传感器

> **一句话描述:** Bosch 低成本数字气压/温度传感器，I2C/SPI 双接口，适合高度计、气象站和无人机定高  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 已建档，待补详细驱动示例  
> **最后更新:** 2026-05-20

---

## 概述

**BMP280** 是 Bosch Sensortec 的数字气压传感器，可输出气压和温度数据。它是 BME280 的简化版本，不包含湿度测量，成本更低、资料丰富，适合作为气压高度计和环境气压采集节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 供电电压 | 1.71-3.6V | 需注意 VDDIO |
| 接口 | I2C / SPI | 常见模组多用 I2C |
| I2C 地址 | 0x76 / 0x77 | 由 SDO/CSB 配置决定 |
| 测量对象 | 气压、温度 | 无湿度 |
| 气压范围 | 300-1100 hPa | 常规海拔应用足够 |
| 典型应用 | 高度计、气象站、无人机定高 | 低成本首选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本气压/海拔测量、环境监测、教学项目 |
| 不适合场景 | 需要湿度数据或更高精度定高的场景 |
| 主要优势 | 成本低、资料多、I2C/SPI 双接口、生态成熟 |
| 主要风险 | 海拔换算依赖本地海平面气压校准，气流和温度会影响结果 |
| 替代型号 | BME280、DPS310、LPS22HB、MS5611 |

---

## 硬件设计要点

- 电源侧使用就近去耦，优先参考 Bosch 推荐电容布局。
- I2C 模式需要确认上拉电阻和地址脚状态。
- 气压孔不要被结构件、胶水或涂覆层遮挡。
- 户外应用需要防水透气膜，避免直吹气流导致读数跳变。

## 驱动要点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id，典型值为 `0x58` |
| 校准 | 读取 NVM 补偿参数，气压/温度计算必须使用补偿算法 |
| 配置 | 设置 oversampling、IIR filter、standby time 和工作模式 |
| 读取 | 读取原始气压/温度，再按 datasheet 公式换算 |
| 低功耗 | 间歇采样优先使用 forced mode |

## XinYi 驱动 README 草案

> 该小节用于在 XinSor 内先固化驱动目录、接口和 bring-up 顺序；真实代码应放入 XinYi 仓库。

### 功能范围

- 初始化 BMP280 并验证 chip id。
- 读取工厂校准参数。
- 支持读取温度和气压。
- 支持配置 oversampling、IIR filter、standby time 和工作模式。
- 支持 forced mode 低功耗单次测量。

### 建议目录结构

```text
drivers/sensors/bmp280/
├── bmp280.h             # 公共接口、配置和数据结构
├── bmp280.c             # BMP280 寄存器、补偿算法和状态机
├── bmp280_port.h        # XinYi 总线适配接口声明
├── bmp280_port.c        # I2C/SPI 读写、delay、时间戳适配
└── README.md            # 从本小节转写而来
```

### 公共接口清单

| 接口 | 作用 | 备注 |
|------|------|------|
| `bmp280_init(config)` | 初始化设备、读取 chip id 和校准参数 | `config` 至少包含总线、地址、模式 |
| `bmp280_read(data)` | 读取并输出温度/气压物理量 | 输出 `temperature_c`、`pressure_pa` 或 `pressure_hpa` |
| `bmp280_configure(param, value)` | 修改 oversampling、IIR、模式等参数 | 参数应可被上层组件枚举 |
| `bmp280_self_test()` | 执行最小自检 | 至少验证 chip id、校准参数非全 0、读数范围 |
| `bmp280_deinit()` | 释放或复位状态 | 低功耗场景可切换 sleep mode |

### 数据结构建议

```c
typedef struct {
    uint8_t bus_id;
    uint8_t i2c_addr;        // 0x76 or 0x77
    uint8_t osrs_t;          // temperature oversampling
    uint8_t osrs_p;          // pressure oversampling
    uint8_t filter;          // IIR filter coefficient
    uint8_t mode;            // sleep / forced / normal
} bmp280_config_t;

typedef struct {
    uint32_t timestamp_ms;
    float temperature_c;
    float pressure_hpa;
    int32_t raw_temperature;
    int32_t raw_pressure;
    uint8_t quality;
} bmp280_data_t;
```

### Bring-up 顺序

1. 上电后延时，确认传感器电源和 I/O 电压稳定。
2. I2C 扫描确认地址为 `0x76` 或 `0x77`。
3. 读取 `chip_id`，期望值为 `0x58`。
4. 读取温度/气压校准参数，确认不是全 `0x00` 或全 `0xFF`。
5. 配置 oversampling、IIR filter 和工作模式。
6. 读取 `raw_temperature` 和 `raw_pressure`。
7. 使用 Bosch 补偿算法计算温度和气压。
8. 检查室内静态读数是否合理：温度约 `-40~85°C`，气压约 `300~1100 hPa`。
9. 切换 forced mode，验证单次测量和低功耗路径。

### 默认配置建议

| 参数 | 建议值 | 说明 |
|------|--------|------|
| I2C 地址 | `0x76` 优先，失败再试 `0x77` | 适配常见模组 |
| 温度 oversampling | x1 | 气压补偿需要温度 |
| 气压 oversampling | x4 | 平衡噪声和响应速度 |
| IIR filter | 4 | 降低气压抖动 |
| 模式 | forced mode | 便于低功耗和按需采样 |

### 最小验收标准

| 项目 | 判定 |
|------|------|
| 通信 | 能稳定读取 chip id `0x58` |
| 校准参数 | 参数非全 0/全 FF，补偿计算不溢出 |
| 数据 | 温度和气压在合理范围内，连续采样无明显跳变 |
| 配置 | oversampling 和模式配置可读回或表现符合预期 |
| 恢复 | I2C 读写失败后可重新初始化恢复 |
