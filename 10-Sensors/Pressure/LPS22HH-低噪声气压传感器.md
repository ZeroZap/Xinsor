# LPS22HH 低噪声气压传感器

> **一句话描述:** ST 低噪声低功耗数字气压/温度传感器，I2C/SPI 接口，适合可穿戴、无人机和高稳定性高度计  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**LPS22HH** 是 ST 的高性能低噪声气压传感器，面向可穿戴、无人机、工业便携设备和高度变化检测。相对 LPS22HB，它更偏向低噪声和性能提升。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 适合 MCU 直连 |
| 测量对象 | 气压、温度 | 数字输出 |
| 气压范围 | 260-1260 hPa | 覆盖常规气象/高度应用 |
| 典型精度 | 约 ±0.15 hPa | 低噪声适合高度趋势检测 |
| 典型应用 | 可穿戴、无人机定高、工业便携设备 | 性能/功耗平衡 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 LPS22HB 更低噪声和更稳高度读数的项目 |
| 不适合场景 | 极低成本入门项目、水下压力、高压工业压力 |
| 主要优势 | 低噪声、低功耗、I2C/SPI、ST 生态成熟 |
| 主要风险 | 与 LPS22HB/LPS33HW 寄存器相似但不可盲目共用所有配置位 |
| 替代型号 | LPS22HB、LPS33HW、DPS310、DPS368、BMP280 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认具体型号 |
| 配置 | 设置 ODR、低噪声模式、滤波和 BDU |
| 读取 | 读取压力/温度输出寄存器并按比例换算 |
| FIFO | 需要批量采样时再启用 FIFO，避免初始化复杂化 |
| 功耗 | 可穿戴项目优先评估 one-shot/低 ODR 模式 |
