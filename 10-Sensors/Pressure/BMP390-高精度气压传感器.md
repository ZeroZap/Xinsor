# BMP390 高精度气压传感器

> **一句话描述:** Bosch 高精度低功耗气压/温度传感器，I2C/SPI 接口，适合无人机、可穿戴和室内高度变化检测  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BMP390** 是 Bosch 新一代高精度气压传感器候选，常用于高度计、无人机定高、可穿戴和气象监测。相对 BMP280，它更适合需要更高稳定性和分辨率的项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 常见 MCU 总线 |
| 测量对象 | 气压、温度 | 数字输出 |
| 气压范围 | 300-1250 hPa | 覆盖常规高度/天气应用 |
| 典型应用 | 无人机、可穿戴、楼层检测、气象节点 | 高精度低功耗候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 Bosch 高精度气压计生态和更稳高度趋势的项目 |
| 不适合场景 | 极低成本、需要湿度/VOC、工业高压或水下应用 |
| 主要优势 | 低功耗、高分辨率、I2C/SPI、Bosch 资料和驱动生态较成熟 |
| 主要风险 | 模组版本和供货渠道需要确认；不能与 BMP280 驱动混用 |
| 替代型号 | BMP388、DPS310、DPS368、LPS22HH |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip ID 并确认总线模式 |
| 校准 | 读取补偿参数，按 Bosch 公式转换温度和气压 |
| 配置 | 设置过采样、滤波、输出数据率和功耗模式 |
| 读取 | 输出 `temperature_c` 和 `pressure_hpa` 或 `pressure_pa` |
| 滤波 | 楼层/定高应用需结合应用周期做平滑处理 |
