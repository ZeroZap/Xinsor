# BMP380 高精度气压传感器

> **一句话描述:** Bosch 高精度数字气压传感器，I2C/SPI 接口，适合无人机定高、运动设备和 BMP388/BMP390 选型对照  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**BMP380** 是 Bosch BMP3xx 系列气压传感器候选，定位高于 BMP280，适合需要较高分辨率和低噪声气压趋势的高度检测场景。它可作为 BMP388/BMP390 同系列资料对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 高采样和抗干扰优先 SPI |
| 测量对象 | 气压、温度 | 温度用于补偿 |
| 典型应用 | 无人机定高、运动手表、室内高度趋势 | BMP3xx 系列候选 |
| 关键特性 | FIFO/滤波/过采样思路、低噪声气压 | 具体特性以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 Bosch BMP3xx 生态、高精度气压趋势和高度变化检测的项目 |
| 不适合场景 | 极低成本节点、水下压力、工业高压过程测量 |
| 主要优势 | Bosch 生态成熟、适合从 BMP280 升级到更高精度方案 |
| 主要风险 | 与 BMP388/BMP390 的寄存器和补偿差异需核对，不能直接复用配置 |
| 替代型号 | BMP388、BMP390、DPS310、DPS368 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip ID，确认 I2C/SPI 模式 |
| 校准 | 读取补偿参数，按 Bosch 推荐公式计算 pressure/temperature |
| 配置 | 设置 oversampling、IIR filter、ODR 和低功耗模式 |
| 读取 | 支持单次测量和连续采样，保留 timestamp |
| 验证 | 对比 BMP388/BMP390，检查噪声、响应延迟和高度漂移 |
