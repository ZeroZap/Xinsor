# LPS27HHW 防水气压传感器

> **一句话描述:** ST 防水封装气压传感器候选，I2C/SPI 接口，适合户外、运动设备和防水高度趋势检测  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#waterproof` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**LPS27HHW** 是 ST 面向防水应用的气压传感器候选，可作为 LPS33HW、LPS28DFW、LPS22HH 的相邻评估对象。它适合户外运动、可穿戴、防水设备和需要透气防水结构的高度趋势检测。

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体地址和 SPI 模式以 datasheet 为准 |
| 测量对象 | 气压、温度 | 防水气压检测 |
| 测量范围 | 常见大气压范围 | 以 datasheet 为准 |
| 典型应用 | 户外设备、运动手表、防水节点、气压高度趋势 | 防水结构优先 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要防水气压检测、户外使用和 ST LPS 系列软件生态的产品 |
| 不适合场景 | 水下深度压力、密封腔体内绝对高度、工业端口压力 |
| 主要优势 | 防水封装方向、ST LPS 系列生态、适合 LPS33HW/LPS28DFW 对照 |
| 主要风险 | 防水透气膜会带来响应延迟、滞后和污染风险，必须结构实测 |
| 替代型号 | LPS33HW、LPS28DFW、LPS22HH、BMP581、MS5837-02BA |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHOAMI，确认 I2C/SPI 通信和 boot 状态 |
| 配置 | 设置 ODR、低通滤波、block data update 和 FIFO/中断 |
| 读取 | 按 ST LPS 系列格式读取压力和温度，处理符号扩展 |
| 防水 | 将膜材料、开孔尺寸和响应时间记录到硬件验证日志 |
| 验证 | 对比干燥、潮湿、温变和气压阶跃下的响应延迟 |
