# SPL110 气压传感器

> **一句话描述:** Goertek/SPL 系列数字气压传感器候选，I2C/SPI 接口，适合低成本高度趋势和 SPL06-001 对照评估  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#protocol/spi` `#vendor/goertek`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SPL110** 是收集入口中出现的 SPL 系列气压传感器候选，可作为 SPL06-001 的同系列/相邻型号补充。它适合低成本高度趋势、IoT 环境节点和国产/低成本供应链评估。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体接口以 datasheet 和封装为准 |
| 测量对象 | 气压、温度 | 温度用于补偿 |
| 典型应用 | 低成本高度计、环境节点、运动设备 | SPL 系列候选 |
| 关键特性 | 补偿系数、过采样/滤波配置 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低成本气压计、评估 SPL06-001 替代或国产供应链的项目 |
| 不适合场景 | 高可靠工业、明确要求 Bosch/Infineon 生态和长期资料支持的项目 |
| 主要优势 | 成本潜力、接口常见、可纳入 SPL 系列驱动复用评估 |
| 主要风险 | 资料、寄存器差异和供货一致性需实测确认 |
| 替代型号 | SPL06-001、BMP280、DPS310、LPS22HB |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/状态寄存器，确认 I2C/SPI 访问方式 |
| 校准 | 读取补偿系数，确认符号扩展和位拼接方式 |
| 配置 | 设置 oversampling、ODR、滤波和低功耗模式 |
| 读取 | 输出 pressure_pa 和 temperature_c，记录采样时间 |
| 兼容 | 不要假设与 SPL06-001 完全寄存器兼容，需逐项核对 |
