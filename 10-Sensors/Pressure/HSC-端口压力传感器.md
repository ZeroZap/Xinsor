# HSC 端口压力传感器

> **一句话描述:** Honeywell TruStability HSC 高精度端口压力传感器候选，适合医疗、工业和实验气路/液路压力测量  
> **标签:** `#sensor/pressure` `#sensor/ported-pressure` `#protocol/i2c` `#protocol/spi` `#vendor/honeywell`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**HSC** 是 Honeywell TruStability 高精度端口压力系列候选，面向医疗设备、工业控制、实验气路/液路和需要较高精度/稳定性的压力测量。它比 ABP 系列更偏高精度分档。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI/模拟版本常见 | 具体订货型号决定 |
| 测量对象 | 绝压/表压/差压 | 量程和压力类型以型号为准 |
| 典型应用 | 医疗、工业、实验气路、泵压 | 高精度端口压力 |
| 关键特性 | 数字补偿、高精度系列、多量程 | 需要介质和端口确认 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 对端口压力精度、稳定性和产品化可靠性要求更高的设备 |
| 不适合场景 | 消费级低成本压力趋势、普通气压高度计、水下深度计 |
| 主要优势 | Honeywell 高精度端口压力生态，适合严肃气路/液路测量 |
| 主要风险 | 成本、订货选型、介质兼容和生产校准流程复杂 |
| 替代型号 | SSC、ABP2、ABP、MPRLS |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认接口、状态位和诊断错误 |
| 配置 | 记录量程、压力类型、单位、输出比例和温度补偿 |
| 读取 | 输出压力、温度、状态并处理 stale/fault 数据 |
| 校准 | 零点、满量程、温漂和生产批次差异需管理 |
| 安全 | 医疗/工业场景需额外考虑冗余、故障检测和清洁介质 |
