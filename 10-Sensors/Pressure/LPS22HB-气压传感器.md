# LPS22HB 气压传感器

> **一句话描述:** ST 低功耗数字气压传感器，I2C/SPI 接口，具备防水封装特性，适合户外和可穿戴气压高度计  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-20

---

## 概述

**LPS22HB** 是 ST 的数字气压传感器，支持 I2C/SPI，常用于高度计、运动设备、户外环境监测和可穿戴设备。相对 BMP280，它的防水/户外特性更适合作为低功耗户外气压方案候选。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 灵活接入 MCU |
| 测量对象 | 气压、温度 | 数字输出 |
| 气压范围 | 260-1260 hPa | 适合高度/天气场景 |
| 典型应用 | 户外高度计、运动手表、气象节点 | 防水特性是核心差异点 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 户外设备、可穿戴、低功耗气压/高度测量 |
| 不适合场景 | 厘米级无人机定高、水下压力测量、高精度工业压力 |
| 主要优势 | 低功耗、防水特性、I2C/SPI 双接口、ST 生态成熟 |
| 主要风险 | 海拔精度仍依赖气压校准和滤波，结构通气设计不可忽略 |
| 替代型号 | BMP280、DPS310、LPS22HH、LPS33HW、MS5611 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认器件型号 |
| 配置 | 设置 ODR、低通滤波、block data update 和中断选项 |
| 读取 | 读取压力/温度原始值并转换物理量 |
| 滤波 | 高度应用建议做滑动平均或卡尔曼滤波 |
| 低功耗 | 根据应用选择 one-shot 或低 ODR 连续模式 |
