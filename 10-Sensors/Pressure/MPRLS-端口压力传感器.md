# MPRLS 端口压力传感器

> **一句话描述:** Honeywell MPRLS 数字端口压力传感器，适合气路/液路低压、泵压、微流控和软体机器人压力趋势检测  
> **标签:** `#sensor/pressure` `#sensor/ported-pressure` `#protocol/i2c` `#vendor/honeywell`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MPRLS** 是 Honeywell 的端口式压力传感器系列候选，常见于气路、液路、泵压和微流控压力测量。与板载气压计不同，它面向有导压管/端口的相对或绝对压力应用。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体版本以订货型号为准 |
| 测量对象 | 端口压力 | 量程和压力类型以型号后缀为准 |
| 典型应用 | 泵压、气路、液路、微流控、软体机器人 | 需要导压结构 |
| 关键特性 | 数字输出、端口封装、多量程可选 | 需确认介质兼容性 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要通过软管/端口测量气压或低压液路压力的设备 |
| 不适合场景 | 普通海拔计、开放式气压趋势、水下深度高压测量 |
| 主要优势 | 端口封装便于接气路/液路，比裸 MEMS 气压计更适合管路系统 |
| 主要风险 | 介质兼容、冷凝、堵塞、管路动态响应和零点漂移需要验证 |
| 替代型号 | Honeywell ABP/ABP2、MS5803、SDP31 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C/SPI 版本、状态位和转换完成标志 |
| 配置 | 记录量程、压力类型、单位和输出换算参数 |
| 读取 | 输出压力 raw/工程值和状态位，异常状态不要静默吞掉 |
| 校准 | 零点、满量程和温度漂移需要结合实际管路校准 |
| 结构 | 管径、管长、冷凝、防堵和介质兼容性会影响长期可靠性 |
