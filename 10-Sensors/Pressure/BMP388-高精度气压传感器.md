# BMP388 高精度气压传感器

> **一句话描述:** Bosch 高精度数字气压/温度传感器，I2C/SPI 接口，适合便携设备、无人机和高度变化检测  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BMP388** 是 Bosch 面向高精度高度检测的数字气压传感器，可看作 BMP280 之后更高性能的一类候选。它适合对噪声、分辨率和低功耗有要求的便携式高度计、无人机和环境监测设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | Bosch 气压计常见接口 |
| 测量对象 | 气压、温度 | 无湿度 |
| 气压范围 | 300-1250 hPa | 覆盖常规海拔/气象应用 |
| 典型应用 | 便携高度计、无人机、可穿戴 | 比 BMP280 更偏高精度 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 Bosch 生态且精度高于 BMP280 的高度/气压测量 |
| 不适合场景 | 极低成本、需要湿度/VOC、水下压力 |
| 主要优势 | Bosch 生态成熟、低功耗、高分辨率、I2C/SPI 双接口 |
| 主要风险 | 与 BMP280/BME280 补偿算法和寄存器不兼容，不能直接套驱动 |
| 替代型号 | BMP390、DPS310、LPS22HH、MS5611 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip ID，确认 I2C/SPI 通信 |
| 校准 | 读取 trimming 参数并做有符号处理 |
| 配置 | 设置 oversampling、IIR filter、ODR 和功耗模式 |
| 读取 | 读取 raw pressure/raw temperature 后做补偿换算 |
| 验证 | 静态读数关注噪声、漂移和高度换算稳定性 |
