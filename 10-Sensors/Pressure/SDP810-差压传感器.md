# SDP810 差压传感器

> **一句话描述:** Sensirion 数字差压传感器候选，适合风量、滤网堵塞、HVAC 和低压气路状态监测  
> **标签:** `#sensor/pressure` `#sensor/differential-pressure` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SDP810** 是 Sensirion SDP8xx 系列数字差压传感器候选，适用于低压差、风量趋势、滤网堵塞、HVAC 和医疗/实验气路监测。它适合作为 SDP31 的相邻系列补充，覆盖更模块化的差压应用。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字差压接口 |
| 测量对象 | 差压 | 量程以具体订货型号为准 |
| 典型应用 | 风量、滤网、HVAC、气路泄漏 | 低压差气体应用 |
| 关键特性 | 温度补偿、连续采样、CRC | 需要气路结构配合 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 风道、滤网、低压气路和需要稳定数字差压输出的项目 |
| 不适合场景 | 海拔高度计、水下深度、液体高压和普通板载气压趋势 |
| 主要优势 | SDP8xx 生态成熟，适合比 SDP31 更完整的差压方案评估 |
| 主要风险 | 冷凝、粉尘、管路漏气和流量换算模型影响长期可靠性 |
| 替代型号 | SDP31、SDP800、MPRLS、Honeywell ABP2 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取序列号/状态，确认 I2C 地址和 CRC |
| 配置 | 设置连续/单次测量、平均策略和单位换算 |
| 读取 | 输出差压、温度、scale factor 和 CRC 状态 |
| 校准 | 零差压校准和管路漏气检查必须纳入 bring-up |
| 应用 | 风量换算依赖孔板/风道模型，不应由驱动硬编码 |
