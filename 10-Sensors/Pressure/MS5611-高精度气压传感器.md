# MS5611 高精度气压传感器

> **一句话描述:** TE Connectivity 经典高分辨率气压/温度传感器，I2C/SPI 接口，常用于飞控、高度计和气象记录仪  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/te-connectivity`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**MS5611** 是经典高精度数字气压传感器，常见于飞控和高分辨率高度计项目。它的资料、开源驱动和模组生态较成熟，适合作为高精度气压基准方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 模组版本常见 |
| 测量对象 | 气压、温度 | 需读取 PROM 校准参数 |
| 气压范围 | 10-1200 hPa | 范围宽，适合高度计 |
| 典型精度 | 约 ±0.012 hPa 分辨率级别 | 高度趋势检测表现好 |
| 典型应用 | 飞控定高、气象站、高度记录仪 | 开源飞控生态常见 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要成熟资料和高分辨率高度趋势的无人机/机器人项目 |
| 不适合场景 | 极低成本、超小封装可穿戴、水下深度测量 |
| 主要优势 | 经典型号、资料多、分辨率高、飞控生态成熟 |
| 主要风险 | 需要正确处理 PROM CRC、OSR 等待时间和二阶温度补偿 |
| 替代型号 | DPS310、DPS368、BMP280、LPS22HH、MS5637 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 复位 | 上电后发送 reset 命令并等待内部初始化 |
| 校准 | 读取 PROM C1-C6，并校验 CRC |
| 转换 | 分别触发 D1 压力和 D2 温度转换 |
| 等待 | 按 OSR 等级等待转换完成，避免读到旧数据 |
| 补偿 | 实现一阶补偿；低温场景补二阶补偿 |
