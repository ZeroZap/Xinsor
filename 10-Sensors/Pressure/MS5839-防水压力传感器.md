# MS5839 防水压力传感器

> **一句话描述:** TE Connectivity MS5839 系列防水压力传感器候选，适合水下深度、液位和严苛户外水压测量  
> **标签:** `#sensor/pressure` `#sensor/water-pressure` `#protocol/i2c` `#vendor/te`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MS5839** 是 TE Connectivity 防水压力方向候选系列，可用于水下深度、液位、水文监测和严苛户外环境。它适合作为 MS5803/MS5837 系列之外的防水压力补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 具体子型号以 datasheet 为准 |
| 测量对象 | 防水压力、温度 | 压力量程按子型号区分 |
| 典型应用 | 水下深度、液位、水文、户外设备 | 防水压力候选 |
| 关键特性 | 防水封装、压力/温度补偿、校准系数 | 需确认子型号和耐压 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 防水压力系列扩展、水下/液位/户外水压应用预研 |
| 不适合场景 | 室内气压高度、低成本气压模块、未做密封的 PCB 设计 |
| 主要优势 | 扩展 TE 防水压力候选池，便于按压力范围选择 |
| 主要风险 | 子型号差异、密封、腐蚀、温度补偿和长期浸水可靠性 |
| 替代型号 | MS5837-30BA、MS5837-02BA、MS5803-14BA |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 PROM/CRC，确认 I2C 通信和校准系数 |
| 配置 | 按子型号设置量程、OSR、单位和深度换算参数 |
| 读取 | 输出压力、温度、raw 数据和补偿状态 |
| 校准 | 大气零点、水密度、温漂和压力范围要记录 |
| 结构 | 密封、膜片保护、防腐蚀和防堵塞是关键风险 |
