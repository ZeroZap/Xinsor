# SDP800 差压传感器

> **一句话描述:** Sensirion SDP8xx 数字差压传感器候选，适合 HVAC、风速/风量趋势和滤网堵塞检测  
> **标签:** `#sensor/pressure` `#sensor/differential-pressure` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SDP800** 是 Sensirion SDP8xx 系列差压传感器候选，面向低压气流、HVAC、过滤器状态和通风系统监测。它与 SDP810/SDP31 一起构成差压方向候选池。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/模拟版本常见 | 具体版本以订货型号为准 |
| 测量对象 | 差压 | 量程以子型号为准 |
| 典型应用 | HVAC、风量、滤网堵塞、气路监测 | 低压差候选 |
| 关键特性 | 温度补偿、低压差灵敏度、连续输出 | 需要防冷凝和防尘 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | HVAC、低压气路、过滤器状态和风道趋势监测 |
| 不适合场景 | 液体压力、高压工业管路、水下压力 |
| 主要优势 | SDP8xx 系列资料和应用场景成熟，适合风道类应用 |
| 主要风险 | 管路污染、冷凝、安装方向和零点漂移需长期验证 |
| 替代型号 | SDP810、SDP31、Honeywell ABP、MPRLS |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认接口版本、I2C 响应和 CRC |
| 配置 | 设置测量模式、平均窗口和单位换算 |
| 读取 | 输出差压、温度和状态，不直接输出未建模风量 |
| 校准 | 零点校准、管路泄漏和风道模型需单独记录 |
| 保护 | 防尘、防凝露和过压保护决定现场可靠性 |
