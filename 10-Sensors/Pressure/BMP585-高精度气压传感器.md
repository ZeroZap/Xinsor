# BMP585 高精度气压传感器

> **一句话描述:** Bosch BMP5xx 系列高精度气压传感器候选，适合移动设备、户外节点和低功耗高度趋势检测  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#protocol/spi` `#protocol/i3c` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**BMP585** 是 Bosch BMP5xx 系列相邻气压传感器候选，可作为 BMP581、BMP390、BMP388 的对照型号。它适合需要高分辨率气压趋势、低功耗采样和新项目供货评估的移动/户外设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI / I3C | 具体接口能力以 datasheet 为准 |
| 测量对象 | 气压、温度 | 高度需上层换算 |
| 测量范围 | 常见大气压范围 | 以 datasheet 为准 |
| 典型应用 | 户外高度、气象趋势、可穿戴楼层检测、无人机定高 | BMP5xx 候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 新项目需要 Bosch BMP5xx 系列高精度气压和低功耗能力 |
| 不适合场景 | 水压/液压测量、工业管路压力、绝对高度无基准校准 |
| 主要优势 | Bosch 生态、与 BMP581/BMP390 软件抽象可复用、适合新料评估 |
| 主要风险 | 型号间寄存器和补偿流程差异需核对，不能盲目复用 BMP280 驱动 |
| 替代型号 | BMP581、BMP390、BMP388、DPS368、MS5611 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 chip id、软复位流程和补偿参数读取 |
| 配置 | 建立 low power、normal、forced 等模式配置表 |
| 读取 | 压力和温度补偿计算建议封装为独立路径并保留 raw 调试输出 |
| 中断 | 若使用数据就绪/阈值中断，需确认 latch 和清除机制 |
| 验证 | 用同环境 BMP390/MS5611 做趋势对比，重点看噪声和响应延迟 |
