# SPL06-001 高精度气压传感器

> **一句话描述:** 高精度低成本数字气压/温度传感器，I2C/SPI 接口，适合成本敏感的高度计和气象节点  
> **标签:** `#sensor/pressure` `#sensor/temperature` `#protocol/i2c` `#protocol/spi` `#vendor/goertek`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SPL06-001** 是常见的高精度数字气压传感器候选，模组市场可见度高，适合成本敏感但又需要比 BMP280 更好分辨率的气压/高度项目。选型时需要重点确认供应商、封装和驱动资料来源。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 常见模组支持 I2C |
| 测量对象 | 气压、温度 | 需补偿换算 |
| 气压范围 | 300-1200 hPa | 常规海拔/气象应用 |
| 典型精度 | 约 ±0.005 hPa 分辨率级别 | 实际表现依赖模组和算法 |
| 典型应用 | 高度计、气象节点、低成本无人机 | 性价比候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 成本敏感但需要较高气压分辨率的项目 |
| 不适合场景 | 对长期供货、资料完整性和官方生态要求极高的项目 |
| 主要优势 | 成本和分辨率平衡较好、I2C/SPI、模组容易买到 |
| 主要风险 | 不同渠道资料和驱动质量差异大，量产前必须实测一致性 |
| 替代型号 | DPS310、BMP388、BMP390、MS5611 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 chip ID、I2C 地址和 SPI 模式 |
| 校准 | 读取补偿系数，处理有符号扩展和缩放系数 |
| 配置 | 设置 pressure/temperature rate、oversampling 和模式 |
| 读取 | 读取 raw pressure/raw temperature 后按公式补偿 |
| 验证 | 多片对比静态噪声、温漂和高度换算一致性 |
