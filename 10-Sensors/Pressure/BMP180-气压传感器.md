# BMP180 气压传感器

> **一句话描述:** Bosch 经典 I2C 气压/温度传感器，适合低成本高度计、旧项目维护和 BMP085 升级替代  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**BMP180** 是 Bosch 经典数字气压计，常见于早期高度计、气象站和教育模块。它可作为 BMP085 的升级替代，但新设计通常更推荐 BMP280、BMP388 或 BMP390。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见模块接口 |
| 测量对象 | 气压、温度 | 温度用于补偿 |
| 典型应用 | 海拔计、气象站、教育项目、旧项目维护 | 低成本历史型号 |
| 关键特性 | 校准系数、过采样模式 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本气压高度计、维护旧硬件、教学和驱动迁移 |
| 不适合场景 | 高精度无人机定高、强低功耗约束、新产品长期供货 |
| 主要优势 | 资料丰富、模块常见、补偿流程成熟 |
| 主要风险 | 新型号性能更好，库存来源和替代风险需要确认 |
| 替代型号 | BMP085、BMP280、BMP388、MPL3115A2 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip ID，确认 I2C 通信 |
| 校准 | 启动时读取校准参数并缓存，避免每次测量重复读取 |
| 测量 | 按 oversampling 等级等待转换完成 |
| 换算 | 使用整数或定点补偿公式，避免 MCU 浮点依赖过重 |
| 验证 | 对比本地气压基准，检查海拔换算和温度补偿趋势 |
