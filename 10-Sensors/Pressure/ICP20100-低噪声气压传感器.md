# ICP20100 低噪声气压传感器

> **一句话描述:** TDK InvenSense 低噪声低功耗气压传感器，I2C/I3C 接口，适合可穿戴、楼层检测和无人机高度趋势  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#protocol/i3c` `#vendor/tdk`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ICP20100** 是 TDK InvenSense 的低噪声气压传感器候选，定位与 ICP10125、DPS310、BMP390 相近。它适合低功耗高度趋势、室内楼层检测、可穿戴运动高度和无人机定高的对照评估。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / I3C | I3C 需确认主控和驱动栈支持 |
| 测量对象 | 气压、温度 | 上层换算高度 |
| 测量范围 | 常见大气压范围 | 以 datasheet 为准 |
| 典型应用 | 楼层检测、可穿戴高度、无人机定高、气象趋势 | 低噪声候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低噪声、高分辨率和低功耗气压趋势的电池设备 |
| 不适合场景 | 水下深度、端口压力、工业过程压力闭环 |
| 主要优势 | TDK 生态、I3C 候选、可与 ICP10125 形成新旧方案对照 |
| 主要风险 | 气压高度对结构腔体、温漂、风压和本地气象变化敏感 |
| 替代型号 | ICP10125、DPS310、BMP581、BMP390、LPS22HH |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 device id、I2C/I3C 模式和软复位完成状态 |
| 配置 | 根据功耗/噪声目标选择测量模式、ODR 和滤波 |
| 读取 | 压力、温度和状态位要同一测量周期读取 |
| 补偿 | 使用官方补偿流程，保留 raw 数据方便对照调试 |
| 验证 | 与 DPS310/BMP390 同环境记录静态噪声、响应时间和温漂 |
