# BMP085 气压传感器

> **一句话描述:** Bosch 早期数字气压传感器，I2C 接口，适合旧项目维护、教育和 BMP180/BMP280 迁移对照  
> **标签:** `#sensor/pressure` `#sensor/barometer` `#protocol/i2c` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**BMP085** 是 Bosch 早期常见气压传感器，已被后续 BMP180/BMP280 等型号替代。它适合旧硬件维护、历史驱动兼容和气压算法教学，不建议作为新设计优先选择。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 早期 Bosch 气压计常见接口 |
| 测量对象 | 气压、温度 | 温度用于补偿 |
| 典型应用 | 旧项目维护、气压高度计、教育 | 历史常用型号 |
| 关键特性 | 校准系数、过采样配置 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已有 BMP085 硬件维护、旧驱动移植、气压高度计教学 |
| 不适合场景 | 新产品、高精度无人机定高、低功耗长期部署 |
| 主要优势 | 历史资料多、算法链路清晰、适合兼容性验证 |
| 主要风险 | 停产/供货、性能和功耗相对新型号落后 |
| 替代型号 | BMP180、BMP280、BMP388、DPS310 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip ID，确认 I2C 地址和寄存器响应 |
| 校准 | 读取 EEPROM 校准系数，严格按 datasheet 做补偿计算 |
| 测量 | 区分温度转换和压力转换，处理 oversampling 等待时间 |
| 换算 | 输出 pressure_pa、temperature_c 和 altitude 估算 |
| 迁移 | 与 BMP180/BMP280 的寄存器和补偿算法不要混用 |
