# MAX31865 RTD温度转换器

> **一句话描述:** ADI/Maxim RTD 到数字转换器，SPI 接口，适合 PT100/PT1000 工业温度测量和中高精度接触式温度采集  
> **标签:** `#sensor/temperature` `#sensor/rtd` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MAX31865** 是 RTD 温度测量前端，将 PT100/PT1000 等铂电阻信号转换为数字数据。它适合工业接触式温度、管道/设备温度和需要比普通板级温度传感器更远端测量的位置。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | RTD 前端常见接口 |
| 测量对象 | PT100/PT1000 RTD | 2/3/4 线制需按硬件设计确认 |
| 测量范围 | 取决于 RTD 和电路配置 | 以 datasheet 和探头为准 |
| 典型应用 | 工业温度、设备/管道温度、实验仪器 | 接触式高可靠温度 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 PT100/PT1000 远端接触式温度和数字化读数的系统 |
| 不适合场景 | 低成本板温、空气温湿度、热电偶高温宽范围测量 |
| 主要优势 | RTD 生态成熟、SPI 数字输出、适合工业温度链路 |
| 主要风险 | 参考电阻、线阻、接线方式、EMI 和自热会影响精度 |
| 替代型号 | MAX31856、MAX31855、ADT7410、TMP117、MCP9808 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 SPI mode、片选时序和故障状态寄存器 |
| 配置 | 设置 2/3/4 线制、滤波频率、bias、自动/单次转换 |
| 读取 | 读取 RTD raw 值并按参考电阻和 Callendar-Van Dusen 关系换算 |
| 故障 | 处理开路、短路、过压/欠压等 fault 位并提供清除流程 |
| 硬件 | 记录参考电阻精度、布线、屏蔽和探头接线方式 |
