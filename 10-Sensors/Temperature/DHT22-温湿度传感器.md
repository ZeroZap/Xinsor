# DHT22 温湿度传感器

> **一句话描述:** Aosong 单总线温湿度传感器，适合教学、简单环境监测和低速采样场景  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/one-wire-like` `#vendor/aosong`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**DHT22** 是常见单总线类温湿度传感器，资料多、模块常见，但时序要求和采样速率限制明显。它适合教学和简单环境监测，不适合作为现代低功耗 I2C 节点的首选。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | 单总线类时序 | 非标准 1-Wire |
| 测量对象 | 温度、湿度 | 低速采样 |
| 温度范围 | -40~80°C | 以 datasheet 为准 |
| 湿度范围 | 0-100%RH | 采样间隔需受限 |
| 典型应用 | 教学、低速环境监测 | 资料多但不推荐新项目优先选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 教学、Arduino/入门项目、低速温湿度显示 |
| 不适合场景 | 多传感器总线、低功耗电池节点、高可靠性产品 |
| 主要优势 | 模组常见、资料多、成本低、无需 I2C 地址管理 |
| 主要风险 | 时序敏感、阻塞读取、采样慢、线长和中断影响大 |
| 替代型号 | AHT20、SHT30、SHTC3、HDC1080 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 时序 | 启动脉冲、响应脉冲和 bit 宽度需精确计时 |
| 中断 | 读取期间可能需要短暂关中断或使用定时器输入捕获 |
| 校验 | 使用 checksum 检测异常帧 |
| 采样 | 遵守最小采样间隔，避免读到旧数据 |
| 迁移 | RTOS 下需避免长时间阻塞关键任务 |
