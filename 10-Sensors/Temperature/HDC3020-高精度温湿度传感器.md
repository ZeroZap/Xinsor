# HDC3020 高精度温湿度传感器

> **一句话描述:** TI 高精度低功耗温湿度传感器，I2C 接口，适合工业环境监测、低功耗 IoT 和精密温湿度节点  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**HDC3020** 是 TI 的高精度温湿度传感器，适合作为 HDC1080/HDC2010 的高精度升级候选。它适合工业环境监测、低功耗 IoT 和对精度/长期稳定性要求较高的节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | TI HDC 系列 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 温度范围 | -40~125°C | 宽温度范围 |
| 湿度范围 | 0-100%RH | 高精度候选 |
| 典型应用 | 工业监测、低功耗 IoT、精密环境节点 | TI 资料完整 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 TI 生态、高精度和低功耗的温湿度项目 |
| 不适合场景 | 极低成本节点、只需普通室内温湿度显示 |
| 主要优势 | 高精度、低功耗、I2C、TI 资料完整、适合工业节点 |
| 主要风险 | 结构热源、通风和保护膜选择会影响实际精度 |
| 替代型号 | HDC2010、HDC1080、SHT40、SHT45、SHT35 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID 或确认 I2C ACK |
| 配置 | 设置采样模式、alert 阈值和低功耗策略 |
| 读取 | 读取温湿度寄存器并换算物理量 |
| 中断 | 可用阈值告警做环境异常唤醒 |
| 验证 | 长期记录温湿度漂移并和参考仪表对比 |
