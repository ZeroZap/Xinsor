# HDC2021 温湿度传感器

> **一句话描述:** TI HDC20xx 系列温湿度传感器候选，适合低功耗环境节点、紧凑型板卡和 HDC 系列驱动补齐  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**HDC2021** 是 TI HDC20xx 系列温湿度候选，可用于低功耗环境节点、紧凑型板卡和智能家居温湿度采集。它适合作为 HDC2010/HDC2080 的相邻型号纳入驱动能力表。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | HDC20xx 系列接口 |
| 测量对象 | 温度、相对湿度 | 具体封装/精度以 datasheet 为准 |
| 典型应用 | IoT 节点、环境记录、智能家居 | HDC 生态补齐 |
| 关键特性 | 低功耗测量、中断/阈值思路、小型化 | 需确认封装通风路径 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已使用 HDC20xx 生态，想补齐相邻型号和小型化温湿度方案 |
| 不适合场景 | 高精度温湿度基准、恶劣冷凝污染环境、纯温度高精度仪表 |
| 主要优势 | 与 HDC2010/HDC2080 驱动和应用场景相近 |
| 主要风险 | 封装开孔、PCB 热耦合和长期湿度漂移需要验证 |
| 替代型号 | HDC2010、HDC2080、HDC3020、SHTC3 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取设备 ID/状态，确认 HDC20xx 子型号 |
| 配置 | 设置分辨率、采样周期、阈值和中断输出 |
| 读取 | 输出温湿度 raw/工程值，并记录状态标志 |
| 兼容 | 与 HDC2010/HDC2080 共用驱动时保留能力差异 |
| 验证 | 与同板 HDC3020/SHT40 对比温湿度趋势和响应时间 |
