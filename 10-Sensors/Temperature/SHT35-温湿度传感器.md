# SHT35 温湿度传感器

> **一句话描述:** Sensirion SHT3x 系列高精度温湿度传感器，I2C 接口，适合精密环境监测和工业/医疗原型  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SHT35** 是 SHT3x 系列中更高精度的温湿度传感器候选，适合对温湿度精度和长期稳定性要求更高的设备。它适合作为 SHT30/SHT31 的高精度升级。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SHT3x 命令集风格 |
| 测量对象 | 温度、湿度 | 数字输出，带 CRC |
| 温度范围 | -40~125°C | 宽温度范围 |
| 湿度范围 | 0-100%RH | 高精度候选 |
| 典型应用 | 精密环境监测、工业/医疗原型、校准参考 | 成本高于入门方案 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 高精度温湿度、长期稳定性、工业/医疗原型 |
| 不适合场景 | 低成本消费项目、普通智能家居节点 |
| 主要优势 | 精度高、稳定性好、Sensirion 生态成熟、CRC 校验 |
| 主要风险 | 系统误差常来自结构热源和通风，而不是传感器本体 |
| 替代型号 | SHT31、SHT40、SHT45、HDC3020 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 初始化 | 确认地址和 soft reset 流程 |
| 测量 | 选择 repeatability、clock stretching 或 no-stretch 模式 |
| 读取 | 校验 CRC 后换算温湿度 |
| 周期 | 长期监测建议固定采样周期并记录 timestamp |
| 验证 | 与参考仪表对比，分离器件误差和结构误差 |
