# SHT31 温湿度传感器

> **一句话描述:** Sensirion 高精度数字温湿度传感器，I2C 接口，适合智能家居、工业环境监测和高可靠性 IoT 节点  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SHT31** 是 Sensirion SHT3x 系列高精度温湿度传感器，适合长期稳定环境监测、智能家居和工业原型。相对 SHT30，它通常定位更高精度版本。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址 `0x44/0x45` |
| 测量对象 | 温度、湿度 | 数字输出，带 CRC |
| 温度范围 | -40~125°C | 宽温度范围 |
| 湿度范围 | 0-100%RH | 需避免长期凝露 |
| 典型应用 | 智能家居、工业监测、IoT 节点 | 稳定性优先 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 高精度温湿度、长期稳定环境监测、工业/智能家居节点 |
| 不适合场景 | 极低成本消费项目、需要气压/VOC 一体化 |
| 主要优势 | 精度高、稳定性好、I2C、CRC、Sensirion 生态成熟 |
| 主要风险 | 价格高于 AHT/HDC 入门方案，结构通风和热隔离仍关键 |
| 替代型号 | SHT30、SHT35、SHT40、HDC3020、AHT20 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 测量 | 支持单次测量和周期测量命令 |
| 读取 | 读取温度/湿度 raw 和 CRC |
| 校验 | 建议启用 CRC，提高总线异常识别能力 |
| 功耗 | 电池设备用单次测量，采样后休眠 MCU |
| 结构 | 避免热源、封闭腔体和凝露影响读数 |
