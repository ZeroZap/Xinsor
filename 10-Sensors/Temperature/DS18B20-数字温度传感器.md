# DS18B20 数字温度传感器

> **一句话描述:** Maxim/ADI 1-Wire 数字温度传感器，适合低成本多点测温、防水探头和教学/农业温度采集  
> **标签:** `#sensor/temperature` `#protocol/1-wire` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**DS18B20** 是常见 1-Wire 数字温度传感器，模块和防水探头生态丰富，适合多点温度采集、农业土壤/水温、教学实验和低成本温控原型。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | 1-Wire | 单总线，多设备需 ROM 管理 |
| 测量对象 | 温度 | 常见宽温数字测温 |
| 典型应用 | 防水探头、多点测温、农业/水温、教学 | 模组资料丰富 |
| 关键特性 | 唯一 ROM、寄生供电可选、可配置分辨率 | 转换时间随分辨率变化 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本、多点、线缆较长或需要防水探头的温度采集 |
| 不适合场景 | 高速温度环路、高精度仪表、强干扰长线未做保护的工业现场 |
| 主要优势 | 生态成熟，单总线多点，防水探头常见 |
| 主要风险 | 假货/兼容件多，长线总线、上拉和寄生供电容易带来不稳定 |
| 替代型号 | TMP102、MCP9808、ADT7420、TMP117 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 搜索 ROM，记录设备唯一 ID 和总线拓扑 |
| 配置 | 设置分辨率、寄生供电策略和转换等待时间 |
| 读取 | 读取 scratchpad，校验 CRC 后再换算温度 |
| 总线 | 长线需要强上拉、ESD/浪涌保护和时序裕量 |
| 验证 | 冰水、室温、热水三点趋势对比，记录探头热响应时间 |
