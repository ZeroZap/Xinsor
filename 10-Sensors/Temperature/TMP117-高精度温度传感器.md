# TMP117 高精度温度传感器

> **一句话描述:** TI 高精度数字温度传感器，I2C 接口，适合精密温度监测、医疗/工业原型和 ADT7420 替代评估  
> **标签:** `#sensor/temperature` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**TMP117** 是 TI 高精度数字温度传感器，适合精密温度监测、工业仪表、医疗/可穿戴原型和温度参考节点。它是 ADT7420 笔记中提到的直接替代候选之一。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字温度传感器常见接口 |
| 测量对象 | 温度 | 不测湿度 |
| 典型应用 | 精密温度、工业仪表、医疗/可穿戴原型 | 高精度温度方向 |
| 关键特性 | 高精度、低功耗、告警/阈值思路 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 只需要高精度温度、要求低功耗和 TI 生态支持的系统 |
| 不适合场景 | 需要湿度/气压/VOC 一体化、极低成本环境节点 |
| 主要优势 | TI 资料和生态成熟，适合精密温度和阈值告警 |
| 主要风险 | 系统热设计、自热和贴片位置会限制实际精度 |
| 替代型号 | ADT7420、ADT7410、SHT45、HDC3020 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device ID 或默认温度寄存器，确认 I2C 地址 |
| 配置 | 设置转换周期、平均/分辨率、低功耗和告警阈值 |
| 读取 | 处理有符号温度 raw 值和单位换算 |
| 告警 | 高/低温阈值和迟滞需要和系统策略联动 |
| 验证 | 用参考温度计或恒温箱检查偏差、自热和响应时间 |
