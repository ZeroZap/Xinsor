# SHT43 温湿度传感器

> **一句话描述:** Sensirion SHT4x 系列中高精度温湿度传感器候选，适合环境监测、工业 IoT 和 SHT4x 产品分档  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SHT43** 是 SHT4x 系列中高精度温湿度候选，可用于环境监测、工业 IoT、智能家居和需要比 SHT40 更高等级的产品分档。它与 SHT41/SHT45 适合一起做 BOM 和精度评估。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SHT4x 命令式接口 |
| 测量对象 | 温度、相对湿度 | 精度等级以 datasheet 为准 |
| 典型应用 | 工业 IoT、环境监测、智能家居 | 中高精度 SHT4x 候选 |
| 关键特性 | 低功耗、CRC、加热器/重复性模式 | 与 SHT4x 驱动可复用 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | SHT4x 系列产品分档、中高精度温湿度和长期环境记录 |
| 不适合场景 | 极低成本温湿度、污染/冷凝严重且无保护的环境 |
| 主要优势 | 与 SHT40/SHT45 生态相邻，便于做同板替代评估 |
| 主要风险 | 湿度长期漂移、结构通风和污染防护仍是系统精度瓶颈 |
| 替代型号 | SHT41、SHT45、HDC3020、HTU31D |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 用命令响应和 CRC 确认通信，不假设固定 ID |
| 配置 | 暴露重复性、加热器和采样周期配置 |
| 读取 | 温湿度换算需保留 raw 和 CRC 状态用于调试 |
| 维护 | 长期高湿可周期使用加热器，但要避免影响业务数据 |
| 兼容 | SHT4x 系列共用驱动时注意型号精度和成本分档 |
