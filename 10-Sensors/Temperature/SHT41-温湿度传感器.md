# SHT41 温湿度传感器

> **一句话描述:** Sensirion SHT4x 系列 I2C 温湿度传感器候选，适合 SHT40/SHT45 之间的精度和成本折中  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SHT41** 是 Sensirion SHT4x 系列温湿度候选，适合智能家居、环境节点、可穿戴和低功耗温湿度记录。它可作为 SHT40 与 SHT45 之间的精度/成本折中评估型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SHT4x 命令式接口 |
| 测量对象 | 温度、相对湿度 | 具体精度以 datasheet 为准 |
| 典型应用 | 智能家居、环境记录、低功耗节点 | SHT4x 生态候选 |
| 关键特性 | 低功耗、CRC、可选加热器/测量模式 | 需要防凝露结构 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已选择 SHT4x 生态，想在 SHT40/SHT45 之间做成本精度折中的项目 |
| 不适合场景 | 极低成本 AHT/DHT 替代、强冷凝/污染环境未做防护的户外设备 |
| 主要优势 | SHT4x 生态，驱动可与 SHT40/SHT45 复用 |
| 主要风险 | 湿度传感器受污染、冷凝和外壳通风影响明显 |
| 替代型号 | SHT40、SHT43、SHT45、HDC3020 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | SHT4x 无传统 ID 时需通过命令响应和 CRC 验证 |
| 配置 | 选择高/中/低重复性命令和加热器策略 |
| 读取 | 校验 CRC，输出温度、湿度和测量模式 |
| 防护 | 防尘膜、通风孔和防凝露设计决定长期稳定性 |
| 兼容 | 与 SHT40/SHT45 共用驱动时用能力表区分精度等级 |
