# SHT20 温湿度传感器

> **一句话描述:** Sensirion SHT2x 系列 I2C 温湿度传感器，适合低成本 SHT2x 生态补齐、旧项目维护和 SHT21 对照  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SHT20** 是 Sensirion SHT2x 系列温湿度传感器候选，可作为 SHT21/SHT25 的相邻型号补充。它适合低成本 SHT2x 生态、旧项目维护和从 SHT1x/SHT2x 迁移到 SHT3x/SHT4x 时的对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SHT2x 命令式测量 |
| 测量对象 | 温度、湿度 | 数字输出，常带 CRC |
| 典型应用 | 室内环境、旧项目维护、SHT2x 低成本方案 | SHT2x 候选 |
| 关键特性 | CRC、分辨率配置、hold/no-hold 测量 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | SHT2x 家族兼容、旧项目维护、成本敏感的 Sensirion 温湿度方案 |
| 不适合场景 | 新一代高精度产品、严苛高湿长期部署 |
| 主要优势 | 可与 SHT21/SHT25 共享驱动框架和验证流程 |
| 主要风险 | 与 SHT21/SHT25 的精度/命令差异和供货需确认 |
| 替代型号 | SHT21、SHT25、SHT31、HTU21D |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C ACK，执行软复位和 user register 流程 |
| 测量 | 区分 hold/no-hold 模式，按分辨率等待转换完成 |
| 校验 | 温湿度 raw 后做 CRC 校验并记录质量标志 |
| 兼容 | 与 SHT21/SHT25 共用驱动时保留型号能力表 |
| 验证 | 对比 SHT21/SHT31，检查响应速度、高湿恢复和漂移 |
