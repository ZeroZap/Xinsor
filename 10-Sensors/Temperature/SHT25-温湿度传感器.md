# SHT25 温湿度传感器

> **一句话描述:** Sensirion SHT2x 高阶温湿度传感器，I2C 接口，适合 SHT21 升级替代、环境监测和旧项目维护  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SHT25** 是 Sensirion SHT2x 系列中相对高阶的温湿度传感器，可作为 SHT21 的升级候选。它适合已有 SHT2x 硬件生态或需要维护旧产品线的项目，新设计可同时评估 SHT31/SHT45。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SHT2x 命令式测量 |
| 测量对象 | 温度、湿度 | 数字输出，常带 CRC |
| 典型应用 | 环境监测、旧项目维护、SHT21 升级 | SHT2x 高阶候选 |
| 关键特性 | CRC、分辨率配置、Sensirion 生态 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | SHT2x 生态延续、旧硬件升级、需要比 SHT21 更高定位的项目 |
| 不适合场景 | 全新高精度产品、极低成本节点、需要气压/VOC 一体化 |
| 主要优势 | Sensirion 资料成熟，可复用 SHT2x 驱动结构 |
| 主要风险 | 与 SHT3x/SHT4x 相比，新设计性价比和供货需重新评估 |
| 替代型号 | SHT21、SHT31、SHT35、SHT45 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | I2C ACK、软复位和 user register 流程确认 |
| 测量 | 支持 hold/no-hold 模式和不同分辨率等待时间 |
| 校验 | CRC 校验、错误重试和质量标志必需 |
| 兼容 | 与 SHT21 共用框架时保留型号差异和精度元数据 |
| 验证 | 参考仪对比温湿度误差、高湿恢复和长期漂移 |
