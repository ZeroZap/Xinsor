# SI7013 温湿度传感器

> **一句话描述:** Silicon Labs Si70xx 系列 I2C 温湿度传感器，适合 Si70xx 生态补齐、低功耗环境监测和旧项目维护  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/silicon-labs`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SI7013** 是 Silicon Labs Si70xx 系列温湿度传感器候选，在收集入口中与 SI7005、SI7020、SI7021 一起出现。它适合 Si70xx 生态补齐、低功耗环境监测和旧项目维护。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | Si70xx 系列常见接口 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | IoT 环境节点、智能家居、旧项目维护 | Si70xx 候选 |
| 关键特性 | 低功耗、命令式测量、序列/ID 读取思路 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | Si70xx 驱动家族补齐、旧硬件维护、低功耗温湿度节点 |
| 不适合场景 | 全新高精度工业产品、极低成本国产替代 |
| 主要优势 | 可与 SI7020/SI7021 共用驱动抽象和验证方法 |
| 主要风险 | 型号间命令、精度和供货差异需要 datasheet 确认 |
| 替代型号 | SI7021、SI7020、SI7005、SHT31 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/序列号或状态命令，确认 I2C 地址 |
| 测量 | 区分温湿度命令和转换等待时间 |
| 校验 | 如果支持 CRC，统一错误处理和重试策略 |
| 兼容 | Si70xx 系列驱动需要型号能力表和命令差异表 |
| 验证 | 与 SI7021/SHT31 对比功耗、精度和高湿恢复 |
