# TH06 温湿度传感器

> **一句话描述:** 国产低成本 I2C 温湿度传感器候选，适合教育、低成本环境监测和国产替代评估  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/domestic`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**TH06** 是收集入口中出现的国产温湿度传感器候选，适合低成本环境节点、教育项目和国产供应链评估。由于公开资料和模块来源可能差异较大，选型时应优先核对具体 datasheet、I2C 地址和命令集。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 以具体模块资料为准 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | 低成本环境监测、教育、国产替代 | 候选型号 |
| 关键特性 | 成本低、接入简单 | 规格以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 成本敏感、国产替代验证、对精度要求不高的环境趋势节点 |
| 不适合场景 | 高精度工业、医疗/计量、高湿长期可靠应用 |
| 主要优势 | 成本和供应链潜力，适合补齐国产温湿度候选池 |
| 主要风险 | 资料、批次一致性、命令兼容和长期漂移都需要实测确认 |
| 替代型号 | AHT20、AHT21、SHTC3、HDC1080 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、初始化命令和状态位 |
| 测量 | 按 datasheet 等待转换完成，避免盲读 raw 数据 |
| 换算 | 温湿度公式需按具体资料实现，不要套用 AHT/SHT 公式 |
| 兼容 | 记录模块丝印、供应商、批次和寄存器行为 |
| 验证 | 与参考温湿度计长期对比，重点观察漂移和高湿恢复 |
