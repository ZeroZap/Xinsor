# TMP102 低功耗温度传感器

> **一句话描述:** TI 低功耗 I2C 数字温度传感器，适合板级温度、可穿戴和电池设备热监控  
> **标签:** `#sensor/temperature` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**TMP102** 是 TI 的低功耗数字温度传感器候选，常见于板级温度、便携设备、可穿戴和低功耗 IoT。它比 LM75 更偏低功耗小型化，比 TMP117 更偏成本和基础温度监测。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址可配置 |
| 测量对象 | 温度 | 板级/近端温度 |
| 典型应用 | 可穿戴、低功耗节点、板级热监控 | 低功耗温度候选 |
| 关键特性 | 低功耗、告警阈值、扩展模式 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池设备、板级温度监控和低功耗周期测温 |
| 不适合场景 | 高精度计量、远端探头、潮湿环境温湿度一体采集 |
| 主要优势 | 功耗低，驱动简单，TI 生态资料完整 |
| 主要风险 | 只能反映芯片附近温度，布局热源会明显影响结果 |
| 替代型号 | LM75、MCP9808、ADT7420、TMP117 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、配置寄存器和告警引脚状态 |
| 配置 | 设置转换速率、关断模式、阈值和扩展模式 |
| 读取 | 处理温度补码格式，记录采样周期和有效位数 |
| 低功耗 | 周期唤醒读数时确认转换完成时间 |
| 热设计 | 远离热源或建立板温到环境温度的校正关系 |
