# TMP112 低功耗温度传感器

> **一句话描述:** TI 低功耗数字温度传感器，I2C 接口，适合电池设备板温、热管理和 TMP102/LM75 替代评估  
> **标签:** `#sensor/temperature` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**TMP112** 是 TI 的低功耗数字温度传感器候选，适合电池设备板温监测、系统热保护和低成本 I2C 温度采集。它可作为 TMP102、LM75、MCP9808 的相邻对照型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见板级温度接口 |
| 测量对象 | 温度 | 不测湿度 |
| 测量范围 | 常见板级宽温范围 | 以 datasheet 为准 |
| 典型应用 | 电池设备板温、热保护、低功耗环境节点 | TMP102 相邻候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低功耗 I2C 板温、阈值告警和简单驱动的系统 |
| 不适合场景 | 高精度校准温度计、热电偶/RTD 高温测量、温湿度一体化 |
| 主要优势 | TI 生态、低功耗、驱动模型接近 TMP102/LM75 |
| 主要风险 | 板温读数反映的是 PCB 热环境，不能等同于空气温度 |
| 替代型号 | TMP102、LM75、MCP9808、ADT7410、TMP117 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和配置寄存器默认值 |
| 配置 | 设置转换速率、扩展模式、shutdown 和告警阈值 |
| 读取 | 处理有符号温度格式，注意分辨率和符号扩展 |
| 功耗 | 电池设备可用单次测量/关断模式降低平均电流 |
| 验证 | 对比 TMP102/参考温度计，记录不同采样周期下的自热 |
