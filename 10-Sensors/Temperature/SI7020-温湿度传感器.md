# SI7020 温湿度传感器

> **一句话描述:** Silicon Labs I2C 温湿度传感器，适合低功耗环境监测、SI7021 对照和 Si70xx 驱动补齐  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/silicon-labs`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SI7020** 是 Silicon Labs Si70xx 系列温湿度传感器候选，可作为 SI7021 的相邻型号补充。它适合低功耗环境监测、旧项目维护和 Si70xx 系列驱动抽象验证。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | Si70xx 系列常见接口 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | IoT 环境节点、智能家居、旧项目维护 | SI7021 对照候选 |
| 关键特性 | 低功耗、CRC/状态思路、命令式测量 | 具体规格以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 Si70xx 生态、低功耗温湿度和 SI7021 相邻型号评估 |
| 不适合场景 | 追求最高湿度精度、需要最新一代传感器和长期高湿可靠性 |
| 主要优势 | Silicon Labs 生态成熟，适合与 SI7021 共用驱动框架 |
| 主要风险 | 与 SI7021 的命令、精度和供货差异需确认 |
| 替代型号 | SI7021、SI7005、SHTC3、HDC2010 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址，读取 ID/序列号或状态命令 |
| 测量 | 处理 hold/no-hold 或命令式测量等待时间 |
| 校验 | 若支持 CRC，需要统一错误处理和重试策略 |
| 兼容 | 和 SI7021 驱动共用时保持命令表可配置 |
| 验证 | 对比 SI7021，检查温湿度误差、功耗和响应速度 |
