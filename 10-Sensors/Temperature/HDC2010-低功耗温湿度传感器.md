# HDC2010 低功耗温湿度传感器

> **一句话描述:** TI 低功耗数字温湿度传感器，I2C 接口，适合电池供电 IoT、冷链记录和环境监测节点  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**HDC2010** 是 TI 的低功耗温湿度传感器，适合以低占空比工作的电池设备。它支持 I2C 读取、可配置采样和中断能力，适合无线环境节点、冷链记录和智能家居传感器。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址需按模组确认 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 温度范围 | -40~85°C | 以 datasheet 为准 |
| 湿度范围 | 0-100%RH | 注意凝露和污染 |
| 典型应用 | 电池 IoT、冷链记录、环境监测 | 低平均功耗候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池供电环境节点、冷链记录、低频采样温湿度监测 |
| 不适合场景 | 极低成本、需要 125°C 高温范围、需要气压/VOC 一体化 |
| 主要优势 | 低功耗、TI 资料完整、支持阈值/中断思路、适合长周期采样 |
| 主要风险 | 模组供货和地址配置需确认；需要做好 PCB 热隔离和通风 |
| 替代型号 | HDC1080、HDC3020、SHTC3、SHT40、SI7021 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 manufacturer/device ID 或确认 I2C ACK |
| 配置 | 设置温湿度分辨率、测量模式和中断阈值 |
| 读取 | 触发测量后读取温度/湿度寄存器并换算 |
| 低功耗 | 采样后停测或降低采样频率，靠 MCU RTC 周期唤醒 |
| 验证 | 重点测试休眠后恢复、首次读数稳定性和温漂 |
