# LM75 数字温度传感器

> **一句话描述:** 经典 I2C 数字温度传感器，适合板级温度监测、过温告警和旧项目兼容  
> **标签:** `#sensor/temperature` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**LM75** 是经典板级数字温度传感器系列，广泛用于 PCB 温度监测、设备过温告警和旧项目维护。它的功能简单，适合作为 I2C 温度驱动的基础兼容目标。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 多地址版本常见 |
| 测量对象 | 板级温度 | 非探头式环境温度 |
| 典型应用 | PCB 温度、过温告警、电源/板卡监控 | 经典低成本温度计 |
| 关键特性 | 温度寄存器、阈值告警、OS/INT 引脚 | 版本差异以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 板级温度监测、过温保护、旧项目 LM75 兼容 |
| 不适合场景 | 高精度温度计、远端探头、温湿度一体环境节点 |
| 主要优势 | 驱动简单，资料多，适合作为温度子系统基线 |
| 主要风险 | 不同厂商 LM75/LM75A/兼容件寄存器细节可能不同 |
| 替代型号 | TMP102、MCP9808、ADT7420、TMP117 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | I2C 地址扫描，必要时读取配置寄存器确认响应 |
| 配置 | 设置 OS 极性、比较/中断模式、过温和滞回阈值 |
| 读取 | 正确处理补码温度格式和不同分辨率版本 |
| 告警 | 过温阈值应与系统热设计策略联动 |
| 兼容 | 兼容件较多，驱动中保留分辨率和寄存器差异配置 |
