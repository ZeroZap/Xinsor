# SHT45 温湿度传感器

> **一句话描述:** Sensirion SHT4x 系列高精度温湿度传感器，I2C 接口，适合高可靠性 IoT、工业和精密环境监测  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SHT45** 是 Sensirion SHT4x 系列中的高精度型号，可作为 SHT40 的升级候选。它适合对精度、长期稳定性和品牌生态有更高要求的温湿度节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SHT4x 命令式测量 |
| 测量对象 | 温度、湿度 | 数字输出，带 CRC |
| 温度范围 | -40~125°C | 宽温度范围 |
| 湿度范围 | 0-100%RH | 高精度候选 |
| 典型应用 | 高可靠性 IoT、工业环境、精密监测 | SHT40 高阶版本 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 SHT4x 生态和更高精度的温湿度项目 |
| 不适合场景 | 成本敏感项目、需要气压/VOC 一体化的节点 |
| 主要优势 | 高精度、低功耗、命令简单、CRC、Sensirion 生态成熟 |
| 主要风险 | 价格较高，系统结构误差可能掩盖器件精度优势 |
| 替代型号 | SHT40、SHT35、HDC3020、SHT31 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 测量 | 触发不同精度/功耗等级的单次测量 |
| 读取 | 读取温湿度 raw 和 CRC |
| 校验 | CRC 校验失败需重试并记录质量标志 |
| 功耗 | 电池设备采样后进入 MCU/传感器休眠策略 |
| 结构 | 控制自热、外壳通风和凝露风险 |
