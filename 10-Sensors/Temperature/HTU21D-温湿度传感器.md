# HTU21D 温湿度传感器

> **一句话描述:** TE/Measurement Specialties 经典 I2C 温湿度传感器，适合低功耗环境监测和旧项目替代维护  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/te`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**HTU21D** 是经典数字温湿度传感器，常见于早期 IoT、气象站和教育项目。它适合补齐温湿度生态中的历史常用型号，也便于维护旧硬件或对比 SHT/AHT/HDC 系列。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 命令式测量 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | 气象站、室内环境、低功耗节点、教育项目 | 经典温湿度型号 |
| 关键特性 | CRC、分辨率可配、低功耗测量 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 旧项目维护、低速环境监测、需要成熟资料和简单 I2C 接入的节点 |
| 不适合场景 | 最新产品高精度需求、严苛长期稳定性和高湿凝露场景 |
| 主要优势 | 社区资料多、命令简单、适合做温湿度驱动练习 |
| 主要风险 | 供货、批次和长期漂移需确认，不建议作为新项目唯一高精度方案 |
| 替代型号 | HTU31D、SHT30、SHTC3、AHT20 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C ACK，可读取 user register 或序列号类信息 |
| 测量 | 区分 hold/no-hold 模式，避免阻塞总线过久 |
| 读取 | 温度/湿度 raw 换算并校验 CRC |
| 配置 | 设置分辨率和 heater/低功耗策略 |
| 验证 | 检查高湿环境恢复、凝露保护和长时间漂移 |
