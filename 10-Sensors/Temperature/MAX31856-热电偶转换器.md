# MAX31856 热电偶转换器

> **一句话描述:** ADI/Maxim 多类型热电偶到数字转换器，SPI 接口，适合工业高温测量、实验仪器和可配置热电偶平台  
> **标签:** `#sensor/temperature` `#sensor/thermocouple` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MAX31856** 是比 MAX31855 更灵活的热电偶数字转换器，支持多种热电偶类型配置、冷端补偿和故障检测。它适合需要同一硬件平台覆盖不同热电偶探头的工业测温或实验设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 配置寄存器比 MAX31855 更丰富 |
| 测量对象 | 多类型热电偶 | 具体支持类型以 datasheet 为准 |
| 测量范围 | 取决于热电偶类型 | 高温端由探头决定 |
| 典型应用 | 工业高温、实验仪器、加热控制、可配置热电偶平台 | 产品化优先 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要多类型热电偶、可配置滤波和更完整故障诊断的系统 |
| 不适合场景 | 只需最简单 K 型热电偶读数、低成本板温、RTD 专用链路 |
| 主要优势 | 热电偶类型可配置、诊断能力更完整、适合产品化测温平台 |
| 主要风险 | 配置项多，热电偶类型、滤波、冷端和故障策略必须版本化记录 |
| 替代型号 | MAX31855、MAX31865、ADT7410、TMP117 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 初始化 | 配置热电偶类型、转换模式、滤波频率和故障检测策略 |
| 读取 | 分别解析热端温度、冷端温度、线性化数据和 fault 状态 |
| 故障 | 开路、短路、过压、欠压等 fault 要映射到上层告警 |
| 校准 | 高温链路建议做冰点/沸点或标准炉点位校验 |
| 硬件 | 关注冷端布局、热隔离、屏蔽接地和热电偶接插件材料 |
