# HDC1080 低功耗温湿度传感器

> **一句话描述:** TI 低功耗高性价比温湿度传感器，I2C 接口，适合智能家居、无线环境节点和低频采样设备  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**HDC1080** 是 TI 常见的低功耗温湿度传感器，资料和模组较容易获取，适合作为 AHT20 与 SHT30 之间的性价比候选。它适合智能家居、无线环境节点和对平均功耗敏感的采样设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址 0x40 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 温度范围 | -40~85°C | 以 datasheet 为准 |
| 湿度范围 | 0-100%RH | 注意污染和凝露 |
| 典型应用 | 智能家居、无线节点、温湿度记录仪 | 性价比低功耗候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 智能家居、低频温湿度采样、需要较好资料支持的低功耗节点 |
| 不适合场景 | 高精度工业/医疗、125°C 高温环境、极低成本玩具 |
| 主要优势 | 低功耗、价格适中、TI 资料完整、I2C 接入简单 |
| 主要风险 | 精度和长期稳定性需按实际模组验证；结构热源会明显影响温度读数 |
| 替代型号 | HDC2010、HDC3020、SHT30、SHT40、SI7021 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 manufacturer/device ID 或确认 I2C ACK |
| 配置 | 设置温湿度分辨率和一次性/连续测量策略 |
| 读取 | 按转换时间等待后读取温度/湿度寄存器 |
| 低功耗 | 电池设备建议低频触发测量，避免无意义轮询 |
| 校准 | 和参考温湿度计对比，记录封装和外壳带来的偏差 |
