# AHT21 温湿度传感器

> **一句话描述:** 奥松 AHT 系列 I2C 温湿度传感器，适合低成本环境监测、AHT20 替代评估和国产供应链补充  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/aosong`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**AHT21** 是奥松 AHT 系列温湿度传感器候选，可作为 AHT20/AHT10 的相邻型号补充。它适合低成本室内环境、教育项目和国产供应链评估，重点关注供货批次、封装兼容和驱动命令差异。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | AHT 系列常见接口 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | 室内环境、低成本 IoT、教育项目 | AHT20 替代候选 |
| 关键特性 | 低成本、命令式测量、国产供应链 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 成本敏感、国产供应链、已有 AHT20 驱动基础的温湿度节点 |
| 不适合场景 | 高精度工业、长期高湿、需要品牌级长期稳定性保证 |
| 主要优势 | 成本低、I2C 接入简单、适合和 AHT10/AHT20 对比 |
| 主要风险 | 批次一致性、命令兼容和长期漂移需要实测确认 |
| 替代型号 | AHT20、AHT10、SHTC3、HTU21D |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C ACK，读取状态位或执行初始化命令 |
| 测量 | 触发测量后等待 busy 清除，再读取温湿度 raw |
| 换算 | 按 AHT 系列公式换算温度和湿度，避免和 SHT 命令混用 |
| 兼容 | 与 AHT10/AHT20 的初始化、复位和校准状态逐项比对 |
| 验证 | 和参考温湿度计长期对比，记录高湿恢复和漂移 |
