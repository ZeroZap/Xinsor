# SI7021 低功耗温湿度传感器

> **一句话描述:** Silicon Labs 低功耗数字温湿度传感器，I2C 接口，适合智能家居、环境监测和电池供电节点  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/silicon-labs`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SI7021** 是常见低功耗温湿度传感器，模组生态成熟，常用于智能家居和环境监测节点。它适合需要稳定 I2C 数字输出、低频采样和较低平均功耗的场景。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址 0x40 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 温度范围 | -40~85°C | 以 datasheet 为准 |
| 湿度范围 | 0-100%RH | 注意凝露和污染 |
| 典型应用 | 智能家居、环境监测、低功耗无线节点 | 模组常见 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 智能家居、无线温湿度节点、需要成熟模组的低功耗项目 |
| 不适合场景 | 高精度工业/医疗、极低成本、需要气压或 VOC 一体化 |
| 主要优势 | 低功耗、模组常见、I2C 简单、生态成熟 |
| 主要风险 | 市面模组来源复杂，需确认是否原厂芯片；长期漂移需实测 |
| 替代型号 | HDC1080、HDC2010、SHT30、SHT40、AHT20 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取序列号或固件版本，确认器件响应 |
| 测量 | 可选择 hold master 或 no hold master 模式 |
| 读取 | 读取温湿度原始值并按公式换算 |
| 低功耗 | 低频采样后让 MCU 和传感器都回到休眠策略 |
| 可靠性 | 建议启用 CRC 校验，记录异常读数重试策略 |
