# AHT10 温湿度传感器

> **一句话描述:** 奥松低成本数字温湿度传感器，I2C 接口，适合消费电子、教学项目和低成本环境采集  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/aosong`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**AHT10** 是奥松低成本温湿度传感器，定位接近 AHT20 的入门方案。它适合教学、低成本环境节点和对精度要求不高的消费类项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 命令式测量 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 温度范围 | -40~85°C | 以 datasheet 为准 |
| 湿度范围 | 0-100%RH | 避免长期凝露 |
| 典型应用 | 教学、玩具、低成本 IoT | 成本优先 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 成本敏感、一般环境监测、教学和原型项目 |
| 不适合场景 | 高精度工业/医疗、长期稳定性要求高的场景 |
| 主要优势 | 价格低、I2C、使用简单、模组常见 |
| 主要风险 | 精度、批次一致性和长期漂移需要实测确认 |
| 替代型号 | AHT20、SHT30、SHTC3、HDC1080 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 初始化 | 上电后执行初始化/校准命令 |
| 测量 | 触发测量并等待 busy 位清除 |
| 读取 | 读取温湿度 raw 数据并按公式换算 |
| 超时 | 必须设置 busy 等待超时，避免总线卡死 |
| 校验 | 与参考温湿度计对比偏差，记录结构热源影响 |
