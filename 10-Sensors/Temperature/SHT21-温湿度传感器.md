# SHT21 温湿度传感器

> **一句话描述:** Sensirion SHT2x 系列 I2C 温湿度传感器，适合旧项目维护、低功耗环境监测和 SHT3x 迁移对照  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SHT21** 是 Sensirion SHT2x 系列经典温湿度传感器，适合旧硬件维护、低速环境监测和驱动生态补齐。新设计通常更推荐 SHT3x/SHT4x，但 SHT21 仍适合作为历史项目和兼容性资料入口。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | SHT2x 命令式测量 |
| 测量对象 | 温度、湿度 | 数字输出，常带 CRC |
| 典型应用 | 旧项目维护、室内环境、低功耗节点 | SHT2x 经典型号 |
| 关键特性 | CRC、分辨率配置、hold/no-hold 测量 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 维护 SHT2x 旧项目、做 Sensirion 温湿度驱动兼容层 |
| 不适合场景 | 新一代高精度产品、严苛长期稳定性、高湿凝露环境 |
| 主要优势 | Sensirion 生态成熟、命令流程清晰、资料多 |
| 主要风险 | 新项目需评估供货、成本和是否应直接用 SHT31/SHT40 |
| 替代型号 | SHT25、SHT31、SHT40、HTU21D |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C ACK，可读取 user register 或序列信息 |
| 测量 | 区分 hold/no-hold 模式，避免阻塞 I2C 总线 |
| 校验 | 读取 raw 后做 CRC 校验，失败需重试并标记质量 |
| 配置 | 分辨率、heater 和软复位命令需单独封装 |
| 验证 | 与 SHT31/SHT40 对比响应速度、漂移和高湿恢复 |
