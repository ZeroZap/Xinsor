# HTU31D 温湿度传感器

> **一句话描述:** TE Connectivity 新一代数字温湿度传感器，I2C 接口，适合 IoT、工业环境监测和 HTU21D 升级评估  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/te`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**HTU31D** 是 TE Connectivity 的数字温湿度传感器，可作为 HTU21D 的升级候选。它适合需要更现代温湿度方案、低功耗采样和工业/IoT 环境监测的项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见温湿度接口 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | IoT 节点、工业环境、气象站、智能家居 | HTU 系列升级候选 |
| 关键特性 | CRC、低功耗、宽量程温湿度采样 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 HTU 系列延续、低功耗温湿度节点和中高端环境监测 |
| 不适合场景 | 极低成本节点、需要气压/VOC 一体化的系统 |
| 主要优势 | TE 生态、接口简单、适合作为 HTU21D 升级项 |
| 主要风险 | 与 SHT/HDC 系列相比需评估价格、供货和长期漂移 |
| 替代型号 | HTU21D、SHT31、SHT45、HDC3020 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和复位/状态命令响应 |
| 测量 | 触发温湿度测量后按转换时间读取数据 |
| 校验 | 使用 CRC 过滤通信错误，失败时记录质量标志 |
| 配置 | 根据功耗和响应速度选择采样周期 |
| 验证 | 对比 HTU21D/SHT31，检查阶跃响应和高湿恢复 |
