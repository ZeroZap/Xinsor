# MCP9808 高精度温度传感器

> **一句话描述:** Microchip I2C 高精度数字温度传感器，适合板级精密温度、仪表和环境温度参考  
> **标签:** `#sensor/temperature` `#protocol/i2c` `#vendor/microchip`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MCP9808** 是 Microchip 的高精度数字温度传感器候选，常用于板级精密温度、仪表、环境温度参考和热管理。它适合作为 TMP117、ADT7420 的中高精度对照型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 多地址配置常见 |
| 测量对象 | 温度 | 板级/环境温度参考 |
| 典型应用 | 仪表、热管理、环境温度参考、设备校准 | 高精度温度候选 |
| 关键特性 | 高精度、阈值告警、分辨率配置 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 LM75/TMP102 更高精度的板级温度和环境参考 |
| 不适合场景 | 远端防水探头、温湿度一体、快速热响应探针 |
| 主要优势 | 精度定位明确，I2C 驱动复杂度低 |
| 主要风险 | PCB 热传导、封装自热和附近热源会限制系统级精度 |
| 替代型号 | TMP117、ADT7420、TMP102、LM75 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 manufacturer/device ID，确认地址和寄存器响应 |
| 配置 | 设置分辨率、关断模式、临界/上下限温度阈值 |
| 读取 | 处理符号位、分辨率和告警状态位 |
| 校准 | 与参考温度计做至少室温/高温两点趋势对比 |
| 热设计 | 需要隔离热源或用铜皮/开槽控制热路径 |
