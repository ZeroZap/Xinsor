# SHT40 温湿度传感器

> **一句话描述:** Sensirion 新一代高精度温湿度传感器，I2C 接口，适合低功耗环境监测和高可靠性 IoT 节点  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-20

---

## 概述

**SHT40** 是 Sensirion SHT4x 系列温湿度传感器，定位为 SHT3x 的后续升级方案。它适合对长期稳定性、低功耗、小封装和高精度有要求的环境监测节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址 0x44 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 温度范围 | -40~125°C | 以 datasheet 为准 |
| 湿度范围 | 0-100%RH | 需避免长期凝露 |
| 典型应用 | IoT 环境节点、智能家居、工业环境监测 | SHT30 升级候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 高精度温湿度、低功耗节点、长期稳定环境监测 |
| 不适合场景 | 极低成本消费类、需要气压或 VOC 的三合一/四合一应用 |
| 主要优势 | 精度高、功耗低、命令式测量简单、品牌可靠 |
| 主要风险 | 价格高于 AHT/SHT3x 入门方案，结构通风和热源隔离仍是关键 |
| 替代型号 | SHT30、SHT31、SHT45、HDC3020、AHT20 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 测量 | 按命令触发不同精度/功耗模式的单次测量 |
| 读取 | 读取温度、湿度原始值和 CRC |
| 校验 | 建议启用 CRC 校验，提升总线异常识别能力 |
| 功耗 | 间歇测量比连续轮询更适合电池设备 |
| 结构 | 避免 MCU、LDO、无线模块热源影响温度读数 |
