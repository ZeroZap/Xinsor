# ADT7410 高精度温度传感器

> **一句话描述:** ADI 高精度数字温度传感器，I2C 接口，适合板级精密温度、工业仪表和 ADT7420 成本/封装对照  
> **标签:** `#sensor/temperature` `#protocol/i2c` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ADT7410** 是 ADI 的数字温度传感器候选，适合板级高精度温度监测、工业仪表、医疗原型和系统热设计验证。它可与 ADT7420、TMP117、MCP9808 对比，用于纯温度测量而非温湿度一体化。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 多地址配置需查 datasheet |
| 测量对象 | 温度 | 不测湿度 |
| 测量范围 | 常见宽温板级范围 | 以 datasheet 为准 |
| 典型应用 | 板温、工业仪表、医疗原型、温度参考 | ADI 高精度温度候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 I2C 高精度板级温度、阈值告警和 ADI 生态的系统 |
| 不适合场景 | 需要湿度/气压、远端热电偶、强隔离高温测量 |
| 主要优势 | 数字输出、驱动简单、适合与 ADT7420/TMP117 做精度对照 |
| 主要风险 | 实际精度常被 PCB 热源、自热、封装位置和气流条件限制 |
| 替代型号 | ADT7420、TMP117、MCP9808、TMP112、LM75 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、ID/配置默认值和告警脚连接 |
| 配置 | 设置分辨率、转换周期、连续/单次模式和告警阈值 |
| 读取 | 处理有符号温度 raw 值和单位换算，保留原始值便于排错 |
| 告警 | 高/低温阈值、迟滞和中断极性需与系统热策略一致 |
| 验证 | 用恒温箱或参考温度计检查偏差、自热和响应时间 |
