# SI7005 温湿度传感器

> **一句话描述:** Silicon Labs 早期 I2C 温湿度传感器，适合旧项目维护、Si70xx 生态补齐和 SI7021 对照  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/silicon-labs`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SI7005** 是 Silicon Labs 早期温湿度传感器候选，在收集入口中与 SI7021 一起出现。它适合旧项目维护和 Si70xx 生态补齐，新设计通常优先评估 SI7021、SHT3x 或 HDC 系列。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | Si70xx 系列常见接口 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | 旧项目维护、室内环境、低功耗节点 | Si70xx 历史型号 |
| 关键特性 | 数字温湿度、低速环境采样 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 维护 SI7005 旧硬件、补齐 Silicon Labs 温湿度生态 |
| 不适合场景 | 新产品高精度、长期供货要求、严苛高湿环境 |
| 主要优势 | 生态资料可查，适合作为 SI7021 之前的兼容性入口 |
| 主要风险 | 新项目选型价值有限，需确认供货和封装可得性 |
| 替代型号 | SI7021、SI7020、SHT31、HDC1080 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、状态寄存器和测量命令 |
| 测量 | 温湿度转换时间和状态位需要按 datasheet 等待 |
| 换算 | 温度/湿度 raw 换算不要和 SI7021 直接混用 |
| 兼容 | Si70xx 家族驱动应保留型号差异表 |
| 验证 | 旧器件需重点检查漂移、响应速度和高湿恢复 |
