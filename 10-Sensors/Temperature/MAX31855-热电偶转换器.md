# MAX31855 热电偶转换器

> **一句话描述:** ADI/Maxim 热电偶到数字转换器，SPI 只读接口，适合 K 型等热电偶高温趋势测量和快速原型  
> **标签:** `#sensor/temperature` `#sensor/thermocouple` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MAX31855** 是常见热电偶数字转换器，集成冷端补偿和故障检测，适合用 K 型等热电偶做高温趋势检测。它驱动简单，但型号后缀和支持热电偶类型需要按实际器件确认。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI 只读 | 常见 breakout 模块使用方式简单 |
| 测量对象 | 热电偶 | 常见为 K 型，具体后缀以 datasheet 为准 |
| 测量范围 | 取决于热电偶类型 | 高温测量需确认探头和绝缘 |
| 典型应用 | 烤箱、热端、加热设备、实验高温趋势 | 快速原型优先 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要热电偶高温趋势、驱动简单和快速 bring-up 的项目 |
| 不适合场景 | 多类型热电偶统一平台、RTD 高精度低温、低成本板温 |
| 主要优势 | 集成冷端补偿、SPI 读取简单、模块资料多 |
| 主要风险 | 噪声、接地环路、热电偶类型匹配和冷端布局会影响读数 |
| 替代型号 | MAX31856、MAX31865、TMP117、ADT7410 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 无复杂 ID 时需通过 SPI 读数和故障位确认链路 |
| 读取 | 解析热端温度、冷端温度和故障位，注意符号扩展 |
| 故障 | 处理开路、短路到 VCC/GND 等 fault 标志 |
| 滤波 | 高温线缆噪声较大，建议上层做限幅和移动平均 |
| 硬件 | 热电偶接插件、冷端位置、屏蔽和接地策略比代码更关键 |
