# SHT15 温湿度传感器

> **一句话描述:** Sensirion 早期数字温湿度传感器，专用双线接口，适合旧项目维护、SHT1x 生态补齐和迁移对照  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/custom` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**SHT15** 是 Sensirion SHT1x 系列早期温湿度传感器，使用类似但不等同于标准 I2C 的双线时序。它适合旧项目维护和历史生态补齐，新设计通常优先选择 SHT3x/SHT4x 或 SHTC3。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | 专用双线时序 | 不应直接按标准 I2C 处理 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | 旧项目维护、教育、历史驱动迁移 | SHT1x 生态 |
| 关键特性 | 早期数字温湿度、命令式测量 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 维护已有 SHT15/SHT1x 硬件、整理旧驱动和迁移到新 SHT 系列 |
| 不适合场景 | 新产品设计、标准 I2C 总线复用、高精度长期部署 |
| 主要优势 | 历史资料多，可作为 Sensirion 早期数字温湿度代表 |
| 主要风险 | 接口非标准 I2C，供货和新设计价值有限 |
| 替代型号 | SHT21、SHT31、SHT40、SHTC3 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 时序 | 按 SHT1x 专用 start/ack/读写时序实现，不要套用硬件 I2C |
| 测量 | 触发温度/湿度转换后等待完成或轮询数据线 |
| 换算 | 使用对应公式和补偿系数，保留温度补偿湿度流程 |
| 迁移 | 将旧 bit-bang 驱动与 SHT2x/SHT3x I2C 驱动分开维护 |
| 验证 | 与参考仪表和新 SHT 系列对比漂移、高湿恢复和响应速度 |
