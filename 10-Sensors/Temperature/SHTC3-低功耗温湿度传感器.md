# SHTC3 低功耗温湿度传感器

> **一句话描述:** Sensirion 面向电池设备的低功耗温湿度传感器，I2C 接口，适合可穿戴、无线节点和小型 IoT 设备  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#vendor/sensirion`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**SHTC3** 是 Sensirion 面向移动和电池供电设备的低功耗温湿度传感器。它采用命令式单次测量模型，适合长时间休眠、定时唤醒采样的环境节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址 0x70 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 温度范围 | -40~125°C | 以 datasheet 为准 |
| 湿度范围 | 0-100%RH | 避免长期凝露 |
| 典型应用 | 可穿戴、无线温湿度节点、低功耗 IoT | 间歇测量友好 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池供电、采样间隔较长、需要低待机功耗的温湿度节点 |
| 不适合场景 | 极低成本玩具、需要高精度工业级温湿度、需要气压/VOC 集成 |
| 主要优势 | 低功耗、命令式测量简单、Sensirion 生态稳定、适合睡眠唤醒采样 |
| 主要风险 | I2C 地址固定性和封装/模组供货需确认；结构热隔离仍关键 |
| 替代型号 | SHT40、SHT30、HDC2010、HDC1080、SI7021 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 唤醒 | 休眠后先发送 wakeup 命令并等待器件可响应 |
| 测量 | 按需选择 clock stretching 或 no hold 模式 |
| 读取 | 读取温度/湿度 raw 值和 CRC |
| 睡眠 | 采样后立即进入 sleep，降低平均功耗 |
| 校验 | 建议启用 CRC，避免低功耗唤醒过程中的总线异常 |
