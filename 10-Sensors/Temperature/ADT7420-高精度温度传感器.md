# ADT7420 高精度温度传感器

> **一句话描述:** ADI 高精度数字温度传感器，I2C 接口，适合精密温度监测、仪表和工业节点  
> **标签:** `#sensor/temperature` `#protocol/i2c` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ADT7420** 是 ADI 的高精度数字温度传感器，现有收集入口中标记为待实现候选。它只测温度，不测湿度，适合需要比普通温湿度芯片更稳定温度读数的仪表、工业控制和校准参考节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 数字温度传感器常见接口 |
| 测量对象 | 温度 | 不包含湿度 |
| 典型应用 | 精密温度监测、工业节点、仪表 | 高精度温度方向 |
| 关键特性 | 高分辨率、阈值告警、低速稳定测温 | 具体精度以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 只需要精密温度、需要阈值告警或作为环境温度参考的系统 |
| 不适合场景 | 需要湿度/气压一体化、极低成本玩具和普通室内显示 |
| 主要优势 | 温度测量定位明确、ADI 资料完整、适合仪表类节点 |
| 主要风险 | 板上热源、封装热耦合和空气流动会限制实际精度 |
| 替代型号 | TMP117、SHT45、HDC3020、ADT7410 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址，读取 ID/配置寄存器或默认温度值 |
| 配置 | 设置分辨率、转换模式、告警阈值和极性 |
| 读取 | 处理有符号温度 raw 值和分辨率位宽 |
| 告警 | 高/低温阈值需要和系统热保护策略联动 |
| 验证 | 用恒温箱或参考温度计检查偏差、响应时间和自热 |
