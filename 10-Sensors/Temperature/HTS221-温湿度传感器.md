# HTS221 温湿度传感器

> **一句话描述:** ST 小型化数字温湿度传感器，I2C/SPI 接口，适合 IoT 节点、可穿戴和 ST 生态项目  
> **标签:** `#sensor/temperature` `#sensor/humidity` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**HTS221** 是 ST 的温湿度传感器，在 Zephyr/Linux 生态中常见。它适合 ST 平台项目、IoT 环境节点和可穿戴设备，用作 SHT3x/HDC 系列之外的生态补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体接口按封装/模组确认 |
| 测量对象 | 温度、湿度 | 数字输出 |
| 典型应用 | IoT 环境节点、可穿戴、ST 生态开发板 | 小型化温湿度方案 |
| 关键特性 | 校准系数、ODR 可配、低功耗 | 换算需读取校准数据 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | ST 生态项目、需要小型化温湿度采集或 Linux/Zephyr 迁移参考 |
| 不适合场景 | 追求最高湿度精度、需要最新一代低功耗规格的产品 |
| 主要优势 | ST 生态成熟、框架支持线索多、接口灵活 |
| 主要风险 | 校准寄存器换算较容易出错，结构通风会影响湿度响应 |
| 替代型号 | SHT31、SHTC3、HDC2010、HDC1080 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C/SPI 通信 |
| 校准 | 读取温度/湿度校准系数，并按 datasheet 做线性换算 |
| 配置 | 设置 ODR、block data update 和低功耗模式 |
| 读取 | 分别读取 humidity raw 和 temperature raw，保留质量标志 |
| 验证 | 与参考温湿度计对比阶跃响应、漂移和饱和恢复 |
