# BHI360 智能传感器Hub

> **一句话描述:** Bosch 新一代智能传感器 Hub 候选，适合低功耗多传感器融合和边缘动作识别  
> **标签:** `#sensor/imu` `#sensor/hub` `#sensor/motion` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**BHI360** 是 Bosch BHI 智能传感器 Hub 系列候选，可作为 BHI260AP 的相邻升级方向。它适合可穿戴、耳机、AR/VR 控制器、低功耗姿态/动作事件和需要传感器侧融合的产品。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 以具体封装和 datasheet 为准 |
| 类型 | 智能传感器 Hub | 输出融合/动作事件和虚拟传感器数据 |
| 典型应用 | 可穿戴、耳机、AR/VR、低功耗动作识别 | 多传感器融合方向 |
| 关键特性 | 传感器侧算法、FIFO/事件输出 | 固件与算法生态依赖较强 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要低功耗姿态、活动识别和传感器融合事件的中高端产品 |
| 不适合场景 | 简单运动采集、教学项目、只需要裸 IMU 数据的控制环 |
| 主要优势 | 能把复杂 motion pipeline 放到传感器侧，降低主控负载 |
| 主要风险 | Bring-up 不只是寄存器驱动，还涉及固件、配置和算法验证 |
| 替代型号 | BHI260AP、BNO080/BNO085、ICM20948、LSM6DSOX |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 启动 | boot 状态、固件加载、host interface 选择要先跑通 |
| 配置 | 虚拟传感器 enable、采样率、batching 和延迟参数 |
| 读取 | FIFO/事件包解析必须保留时间戳和 sensor id |
| 校准 | 关注陀螺仪/磁力计校准状态和算法置信度 |
| 调试 | 需要能 dump 固件版本、错误码和算法状态 |
