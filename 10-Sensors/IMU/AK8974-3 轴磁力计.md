# AK8974 3 轴磁力计

> **一句话描述:** AKM 3 轴磁力计候选，I2C 接口，适合旧 9 轴组合维护、电子罗盘和 AKM 磁力计生态补齐  
> **标签:** `#sensor/imu` `#sensor/magnetometer` `#protocol/i2c` `#vendor/akm`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**AK8974** 是 AKM 3 轴磁力计候选，在收集入口中与 AK8975、AK8990 一起出现。它适合旧 9 轴组合维护和 AKM 磁力计驱动兼容性补齐，新设计通常优先评估 BMM150、LIS3MDL 或更新 AKM 型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 也可能通过 IMU 辅助总线访问 |
| 轴数 | 3 轴 | 磁场 |
| 典型应用 | 电子罗盘、9 轴组合、旧项目维护 | AKM 磁力计生态 |
| 关键特性 | raw 磁场输出、状态/溢出标志 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 旧项目维护、AKM 磁力计驱动兼容、9 轴组合资料补齐 |
| 不适合场景 | 强磁干扰环境、无校准能力的新产品、靠近电机的结构 |
| 主要优势 | 可补齐 AKM 历史磁力计生态，便于维护旧硬件 |
| 主要风险 | 供货、资料可得性和校准复杂度需要确认 |
| 替代型号 | AK8975、AK8963、BMM150、LIS3MDL |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认直接 I2C 或 IMU 辅助总线访问 |
| 配置 | 设置测量模式、输出位宽和采样节奏 |
| 读取 | 检查 data-ready、overflow 和状态位后再使用 raw 值 |
| 校准 | 硬铁/软铁校准、坐标系和磁偏角配置必需 |
| 布局 | 远离磁铁、电机、大电流走线和铁磁材料 |
