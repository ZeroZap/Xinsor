# BMM150 3 轴磁力计

> **一句话描述:** Bosch 低功耗 3 轴磁力计，I2C 接口，适合电子罗盘、9 轴组合和可穿戴方向感知  
> **标签:** `#sensor/imu` `#sensor/magnetometer` `#protocol/i2c` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BMM150** 是 Bosch 常见低功耗 3 轴磁力计，可与 BMI 系列 6 轴 IMU 组成 9 轴方案。它适合电子罗盘、姿态融合和可穿戴方向感知。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常与 Bosch IMU 配套 |
| 轴数 | 3 轴磁场 | 无 accel/gyro |
| 典型应用 | 电子罗盘、9 轴融合、方向检测 | 需校准硬/软磁干扰 |
| 关键特性 | 低功耗、补偿参数 | 磁力计校准是核心 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | Bosch 9 轴组合、电子罗盘、低功耗方向感知 |
| 不适合场景 | 强磁干扰环境、无需绝对方向的运动检测 |
| 主要优势 | 低功耗、Bosch 生态、适合 BMI 系列组合 |
| 主要风险 | 硬磁/软磁校准和 PCB 磁干扰会显著影响可用性 |
| 替代型号 | LIS2MDL、LIS3MDL、QMC5883L、HMC5883L |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id |
| 校准 | 读取 trim 参数并按官方公式补偿 |
| 配置 | 设置 ODR、功耗模式和测量模式 |
| 读取 | 输出 mag_ut，并处理溢出/无效状态 |
| 融合 | 做电子罗盘前必须完成 hard/soft iron 校准 |
