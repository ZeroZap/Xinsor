# LIS2DU12 3 轴加速度计

> **一句话描述:** ST 超低功耗 3 轴加速度计候选，适合电池设备、唤醒、计步和姿态方向检测  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**LIS2DU12** 是 ST 超低功耗 3 轴加速度计候选，适合电池设备、唤醒检测、计步、方向检测和简单运动事件。它可作为 LIS2DW12、LIS3DH、BMA400 的相邻低功耗对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体能力以 datasheet 为准 |
| 轴数 | 3 轴 | 加速度计 |
| 典型应用 | 低功耗唤醒、计步、方向检测、电池节点 | ST 加速度生态候选 |
| 关键特性 | 超低功耗、FIFO/中断、活动检测 | 需确认目标封装和供货 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池设备、周期唤醒、低速运动趋势和简单姿态检测 |
| 不适合场景 | 高 g 冲击、低噪声倾角仪、需要陀螺仪的姿态估计 |
| 主要优势 | ST 新一代低功耗加速度计生态，适合替代 LIS2DW12 评估 |
| 主要风险 | 中断引擎、低功耗模式和阈值调参需要实测 |
| 替代型号 | LIS2DW12、LIS3DH、BMA400、ADXL367 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认复位和接口状态 |
| 配置 | 设置量程、ODR、低功耗模式、活动/自由落体阈值 |
| 读取 | 输出 xyz raw、温度/状态和中断源 |
| 低功耗 | 睡眠电流、唤醒延迟和中断抖动要在板上测量 |
| 兼容 | 与 LIS2DW12/LIS3DH 共用抽象时避免寄存器假设 |
