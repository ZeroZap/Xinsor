# BMA456 3 轴加速度计

> **一句话描述:** Bosch 面向可穿戴动作识别的 3 轴加速度计，I2C/SPI 接口，适合计步、手势和低功耗活动检测  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BMA456** 是 Bosch 面向可穿戴的 3 轴加速度计候选，适合计步、活动识别、手势检测和低功耗唤醒。相对 BMA400，它更偏向可穿戴功能特性。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 低功耗节点常用 I2C |
| 轴数 | 3 轴加速度 | 无陀螺仪 |
| 典型应用 | 可穿戴、计步、手势、活动识别 | 事件驱动友好 |
| 关键特性 | 中断、低功耗、可穿戴算法特性 | 需核对官方配置流程 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 可穿戴、计步、活动识别、低功耗加速度事件检测 |
| 不适合场景 | 需要角速度或姿态融合的 6 轴/9 轴项目 |
| 主要优势 | Bosch 生态、低功耗、可穿戴功能导向 |
| 主要风险 | 功能配置和算法事件需按官方流程验证 |
| 替代型号 | BMA400、LIS2DW12、LIS3DH、BMI270 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id |
| 配置 | 设置 ODR、量程、功耗模式和中断 |
| 读取 | 输出 accel_g 并确认坐标轴方向 |
| 事件 | 逐步启用 step/activity/gesture 等特性 |
| 验证 | 重点检查误触发率和低功耗唤醒链路 |
