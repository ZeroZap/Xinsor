# LSM6DSV32X 6 轴 IMU

> **一句话描述:** ST LSM6DSV 系列高量程 6 轴 IMU 候选，适合运动冲击、可穿戴和边缘动作识别评估  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#sensor/gyroscope` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**LSM6DSV32X** 是 ST LSM6DSV 系列 6 轴 IMU 候选，面向运动冲击、可穿戴、机器人和边缘动作识别。它适合作为 LSM6DSV16X 的高量程相邻型号补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI/I3C | 具体能力以 datasheet 为准 |
| 轴数 | 6 轴 | 加速度计 + 陀螺仪 |
| 典型应用 | 可穿戴、运动冲击、机器人、动作识别 | ST 新一代 IMU 候选 |
| 关键特性 | 高量程加速度、FIFO、FSM/MLC 思路、低功耗模式 | 算法能力以具体型号为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 ST 新一代 IMU、较高加速度量程和边缘动作识别的项目 |
| 不适合场景 | 极低成本 6 轴 IMU、工业导航级惯导、单芯片 9 轴融合 |
| 主要优势 | 与 LSM6DSV16X 生态相邻，适合高量程运动事件检测 |
| 主要风险 | MLC/FSM、I3C、FIFO 和低功耗能力需按目标平台验证 |
| 替代型号 | LSM6DSV16X、LSM6DSOX、BMI323、ICM45686 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认接口、复位和 boot 状态 |
| 配置 | 设置量程、ODR、滤波、FIFO、FSM/MLC 和中断路由 |
| 读取 | 输出 accel/gyro raw、温度、timestamp 和 FIFO 状态 |
| 算法 | MLC/FSM 配置需要版本化，不应硬编码未说明的配置块 |
| 兼容 | 与 LSM6DSV16X 共用驱动时用能力表区分量程和功能 |
