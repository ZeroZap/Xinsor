# ADXL375 高g加速度计

> **一句话描述:** ADI 高 g 三轴加速度计，适合冲击、跌落、碰撞和结构过载事件检测  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#sensor/high-g` `#protocol/i2c` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**ADXL375** 是 ADI 高 g 三轴加速度计候选，适合冲击、跌落、碰撞、运输记录和结构过载事件检测。它和 ADXL372 同属高动态方向，但具体量程、功耗和接口特性需按 datasheet 对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体接口能力以 datasheet 为准 |
| 轴数 | 3 轴 | 高 g 加速度 |
| 典型应用 | 冲击记录、跌落检测、碰撞事件、运输监测 | 高动态事件采集 |
| 关键特性 | 高量程、事件检测、数字输出 | 低 g 精密倾角不是主场景 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要记录高冲击、跌落或碰撞事件，而不是普通姿态 |
| 不适合场景 | 精密倾角、低噪声振动分析、可穿戴低功耗计步 |
| 主要优势 | 高 g 事件方向明确，适合补齐 ADXL 高动态产品线 |
| 主要风险 | 高量程带来低幅值分辨率取舍，机械安装会显著影响冲击波形 |
| 替代型号 | ADXL372、ADXL377、IIS2ICLX、ADXL355 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 device id、接口模式和量程配置 |
| 配置 | 设置 ODR、滤波、FIFO/中断和活动/冲击阈值 |
| 读取 | 高 g 事件建议保留原始波形和 timestamp |
| 机械 | PCB 固定、螺丝、胶水和结构共振会改变冲击结果 |
| 验证 | 用已知跌落/冲击场景建立阈值，不要只看静态读数 |
