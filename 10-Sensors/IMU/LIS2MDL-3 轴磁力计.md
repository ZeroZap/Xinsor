# LIS2MDL 3 轴磁力计

> **一句话描述:** ST 低功耗 3 轴磁力计，I2C/SPI 接口，适合电子罗盘、9 轴组合和低功耗方向感知  
> **标签:** `#sensor/imu` `#sensor/magnetometer` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**LIS2MDL** 是 ST 低功耗 3 轴磁力计，常与 LSM6 系列 6 轴 IMU 组成 9 轴方案。它适合电子罗盘、方向检测和需要磁场输入的姿态融合项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | ST 磁力计接口 |
| 轴数 | 3 轴磁场 | 无 accel/gyro |
| 典型应用 | 电子罗盘、9 轴组合、姿态融合 | 常配 LSM6 系列 |
| 关键特性 | 低功耗、温度补偿、数据就绪中断 | 校准是核心 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | ST 9 轴组合、电子罗盘、低功耗方向感知 |
| 不适合场景 | 强磁干扰环境、只需相对姿态的 IMU 项目 |
| 主要优势 | ST 生态、低功耗、可与 LSM6 系列组合、I2C/SPI |
| 主要风险 | PCB 磁干扰、硬磁/软磁校准和安装位置影响很大 |
| 替代型号 | LIS3MDL、BMM150、QMC5883L、HMC5883L |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I |
| 配置 | 设置 ODR、测量模式、温度补偿和 BDU |
| 读取 | 输出 mag_ut，并检查数据就绪和溢出状态 |
| 校准 | 必须做 hard iron/soft iron 校准和坐标系对齐 |
| 融合 | 与 accel/gyro 融合前先统一坐标轴定义 |
