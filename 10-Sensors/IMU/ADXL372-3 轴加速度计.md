# ADXL372 3 轴加速度计

> **一句话描述:** ADI 高 g 低功耗 3 轴加速度计，SPI 接口，适合冲击检测、碰撞记录和高动态事件捕获  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ADXL372** 是 ADI 面向高 g 冲击/碰撞事件检测的 3 轴加速度计，适合冲击记录、运输监测、工业振动事件和安全触发。它不是普通低速姿态传感器，选型重点在动态范围、事件捕获和功耗策略。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 高速事件采集常用 |
| 轴数 | 3 轴 | 高 g 加速度 |
| 典型应用 | 冲击检测、碰撞记录、运输/设备保护 | 高动态事件 |
| 关键特性 | 高 g、低功耗、FIFO/事件中断 | 具体量程以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 冲击/碰撞检测、运输记录、跌落事件和高动态机械保护 |
| 不适合场景 | 普通姿态检测、低成本计步、需要陀螺的姿态融合 |
| 主要优势 | 高 g 事件捕获能力强，适合和低功耗唤醒策略结合 |
| 主要风险 | 机械安装、采样带宽和触发阈值决定实际可用性 |
| 替代型号 | ADXL345、ADXL362、ADXL355、LIS2DW12 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device ID，确认 SPI 时序和软复位流程 |
| 配置 | 设置带宽、ODR、阈值、中断和 FIFO 触发 |
| 读取 | 事件发生后批量读取 FIFO，保留前后采样窗口 |
| 机械 | 固定方式、PCB 刚性和安装方向会影响冲击波形 |
| 验证 | 用可控冲击/跌落实验验证阈值、饱和和漏触发 |
