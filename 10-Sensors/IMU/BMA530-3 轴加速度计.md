# BMA530 3 轴加速度计

> **一句话描述:** Bosch BMA5xx 系列低功耗 3 轴加速度计候选，适合可穿戴、耳机、手柄和活动识别  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**BMA530** 是 Bosch BMA5xx 系列低功耗 3 轴加速度计候选，可用于可穿戴、耳机、手柄、遥控器和活动识别。它适合作为 BMA400/BMA456 的相邻新一代候选补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体能力以 datasheet 为准 |
| 轴数 | 3 轴 | 加速度计 |
| 典型应用 | 可穿戴、耳机、手柄、活动识别、低功耗唤醒 | Bosch BMA5xx 候选 |
| 关键特性 | 低功耗、事件检测、FIFO/中断、活动识别思路 | 需确认 Bosch API 支持 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | Bosch 生态、可穿戴活动识别、低功耗唤醒和小型消费电子 |
| 不适合场景 | 高 g 冲击、低噪声精密倾角、需要陀螺仪的姿态估计 |
| 主要优势 | BMA5xx 新生态，适合 BMA400/BMA456 后续评估 |
| 主要风险 | 新型号资料、供货、算法配置和驱动版本需确认 |
| 替代型号 | BMA400、BMA456、LIS2DUX12、ADXL367 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip ID，确认复位、接口和电源状态 |
| 配置 | 设置量程、ODR、功耗模式、FIFO 和中断事件 |
| 读取 | 输出 xyz raw、事件状态、timestamp 和 FIFO 水位 |
| 算法 | 活动识别/手势配置需记录 Bosch API 版本和参数 |
| 验证 | 睡眠电流、唤醒延迟、误触发和佩戴场景要单独测试 |
