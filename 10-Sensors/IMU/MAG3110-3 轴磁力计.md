# MAG3110 3 轴磁力计

> **一句话描述:** NXP 独立 3 轴磁力计，I2C 接口，适合电子罗盘、9 轴组合和磁场趋势检测  
> **标签:** `#sensor/imu` `#sensor/magnetometer` `#protocol/i2c` `#vendor/nxp`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MAG3110** 是 NXP 的独立 3 轴磁力计，在 Zephyr/RT-Thread 收集入口中出现。它适合电子罗盘、9 轴姿态融合和磁场趋势检测，可作为 HMC5883L、QMC5883L、BMM150、LIS3MDL 的补充候选。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 独立磁力计常见接口 |
| 轴数 | 3 轴 | 磁场 |
| 典型应用 | 电子罗盘、姿态融合、磁场趋势 | 需要校准和避磁设计 |
| 关键特性 | ODR 可配、raw 磁场输出 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要独立磁力计、电子罗盘或 6 轴 IMU 外挂磁力计的方案 |
| 不适合场景 | 强磁干扰环境、无校准流程的低成本产品 |
| 主要优势 | NXP 生态、独立磁力计便于组合 9 轴方案 |
| 主要风险 | 硬铁/软铁干扰、PCB 电流路径和外壳磁性材料影响大 |
| 替代型号 | HMC5883L、QMC5883L、BMM150、LIS3MDL |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I 或默认寄存器，确认 I2C 通信 |
| 配置 | 设置 ODR、量程/模式和 data-ready 中断 |
| 读取 | 输出 mag_ut 三轴数据，记录坐标系方向 |
| 校准 | 必须支持 8 字校准、硬铁偏置和软铁矩阵修正 |
| 布局 | 远离电机、磁铁、大电流线和铁磁材料 |
