# BMI160 6 轴 IMU

> **一句话描述:** Bosch 经典低功耗 6 轴 IMU，I2C/SPI 接口，适合可穿戴、手势检测和低成本运动感知  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#sensor/gyroscope` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BMI160** 是 Bosch 经典低功耗 6 轴 IMU，曾广泛用于可穿戴和移动设备。新项目可优先评估 BMI270/BMI323，但 BMI160 仍适合作为资料成熟的低功耗 IMU 学习对象。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 常见 6 轴 IMU 接口 |
| 轴数 | 6 轴 | accel + gyro |
| 典型应用 | 可穿戴、手势检测、低功耗运动感知 | 资料成熟 |
| 关键特性 | FIFO、中断、低功耗模式 | 适合学习 IMU 通用结构 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已有资料复用、低功耗运动检测、可穿戴原型 |
| 不适合场景 | 新量产项目优先选新一代 BMI270/BMI323，或高抗振飞控 |
| 主要优势 | 资料多、低功耗、Bosch 生态、I2C/SPI、FIFO/中断完善 |
| 主要风险 | 生命周期和供货需确认，寄存器不可直接套新一代 BMI |
| 替代型号 | BMI270、BMI323、LSM6DSO、ICM42688 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id |
| 配置 | 设置 accel/gyro ODR、量程、滤波和功耗模式 |
| 读取 | 支持 burst read 和 FIFO 读取 |
| 中断 | 配置 motion、tap、data ready 等中断 |
| 验证 | 检查坐标轴方向、零偏、噪声和低功耗唤醒 |
