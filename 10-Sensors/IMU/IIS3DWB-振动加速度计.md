# IIS3DWB 振动加速度计

> **一句话描述:** ST 宽带三轴振动加速度计，适合预测性维护、电机/轴承振动和工业状态监测  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#sensor/vibration` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**IIS3DWB** 是 ST 面向工业振动检测的三轴加速度计候选，适合预测性维护、电机/轴承振动、泵/风机状态监测和频域特征采集。它不是普通低功耗计步加速度计，重点在高带宽、同步采样和机械安装。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 以 datasheet 为准 |
| 轴数 | 3 轴 | 宽带振动加速度 |
| 典型应用 | 预测性维护、轴承、电机、泵/风机振动 | 工业振动方向 |
| 关键特性 | 宽带、FIFO/中断、高速采样 | 对机械耦合和数据链路要求高 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要采集振动频谱、RMS、峰值和状态趋势的工业节点 |
| 不适合场景 | 低功耗计步、普通姿态、只需低频倾角检测 |
| 主要优势 | 振动监测定位明确，适合补齐 XinSor 工业状态监测方向 |
| 主要风险 | 采样率、存储、FFT 算法、机械固定和温漂都会影响结果 |
| 替代型号 | IIS2ICLX、ADXL1002、ADXL355、ADXL372 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | WHO_AM_I、SPI 模式、复位和状态寄存器确认 |
| 配置 | 设置 ODR、带宽、量程、FIFO 和数据就绪中断 |
| 采样 | 高频数据需要 DMA/SPI 吞吐和丢样检测 |
| 算法 | 计算 RMS、峰值、峭度、频谱和特征带能量 |
| 机械 | 传感器与被测结构的固定方式比驱动本身更关键 |
