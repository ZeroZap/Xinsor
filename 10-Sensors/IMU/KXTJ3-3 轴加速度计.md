# KXTJ3 3 轴加速度计

> **一句话描述:** Kionix/Rohm 低功耗 3 轴加速度计，I2C 接口，适合手机/可穿戴方向检测和活动唤醒  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#vendor/kionix`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**KXTJ3** 是 Kionix/Rohm 低功耗 3 轴加速度计候选，常用于方向检测、活动唤醒和低速运动采样。它适合补齐 KX 系列生态，与 KX023、KX022A 做驱动复用和低功耗策略对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见低功耗设备接口 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 方向检测、活动唤醒、可穿戴、手机配件 | 低功耗 KX 系列 |
| 关键特性 | 低功耗、运动中断、ODR/量程配置 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低成本低功耗方向检测、活动唤醒和 Kionix 系列驱动补齐 |
| 不适合场景 | 高性能振动、冲击记录、工业惯性测量 |
| 主要优势 | I2C 接入简单，适合轻量级运动检测和低功耗节点 |
| 主要风险 | 具体料号和模块差异会影响 WHO_AM_I、量程和中断配置 |
| 替代型号 | KX023、KX022A、LIS2DW12、BMA400 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和 WHO_AM_I |
| 配置 | 设置 ODR、量程、低功耗模式和中断阈值 |
| 读取 | 输出 xyz raw/g，保留采样时间 |
| 中断 | 方向变化、活动和 data-ready 中断需要分开验证 |
| 验证 | 检查休眠电流、唤醒延迟和误触发率 |
