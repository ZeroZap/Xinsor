# MMA8652 3 轴加速度计

> **一句话描述:** NXP 3 轴加速度计，I2C 接口，适合低成本方向检测、活动唤醒和 MMA8451 替代评估  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#vendor/nxp`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MMA8652** 是 NXP 3 轴加速度计候选，在 RT-Thread 收集入口中与 MMA8451 一起出现。它适合低成本方向检测、活动唤醒和旧项目维护，可作为 NXP 加速度计生态补充。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 低成本节点常见 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 方向检测、活动唤醒、低速运动、旧项目维护 | NXP 加速度候选 |
| 关键特性 | 量程/ODR、中断、活动检测 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | NXP 生态项目、低成本 3 轴加速度、旧硬件维护 |
| 不适合场景 | 高性能惯性测量、超低功耗极限场景、高 g 冲击检测 |
| 主要优势 | I2C 简单、资料可查、适合和 MMA8451 做兼容评估 |
| 主要风险 | 与 MMA8451 的寄存器/功能差异需核对，不应直接复用配置 |
| 替代型号 | MMA8451、KXTJ3、LIS3DH、SC7A20 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C 地址和默认状态 |
| 配置 | 设置量程、ODR、低功耗和事件中断 |
| 读取 | 支持 xyz raw、data-ready 和状态读取 |
| 事件 | free-fall、motion、orientation 等功能需逐项验证 |
| 验证 | 与 MMA8451/LIS3DH 对比噪声、功耗和中断响应 |
