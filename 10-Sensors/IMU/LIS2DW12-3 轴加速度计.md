# LIS2DW12 3 轴加速度计

> **一句话描述:** ST 超低功耗 3 轴加速度计，I2C/SPI 接口，适合电池设备、运动唤醒、计步和姿态检测  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**LIS2DW12** 是 ST 的超低功耗 3 轴加速度计，适合电池设备的唤醒、计步、倾斜检测和低频运动感知。相对 LIS2DH12/LIS3DH，它更偏向低功耗和新一代 ST 加速度计生态。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | ST MEMS 常见接口 |
| 轴数 | 3 轴加速度 | 无陀螺仪 |
| 典型应用 | 电池设备、唤醒、计步、倾斜检测 | 低功耗优先 |
| 关键特性 | 低功耗模式、中断、FIFO | 可做事件驱动 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 长续航 IoT、运动唤醒、倾斜检测、低频姿态感知 |
| 不适合场景 | 需要陀螺仪、姿态融合、强动态运动控制 |
| 主要优势 | 超低功耗、ST 生态、寄存器模型清晰、I2C/SPI |
| 主要风险 | 只提供加速度，算法需避免把震动误判为姿态变化 |
| 替代型号 | LIS2DH12、LIS3DH、BMA400、SC7A20 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I |
| 配置 | 设置 ODR、量程、低功耗/高性能模式和 BDU |
| 读取 | 输出 accel_g，确认坐标轴方向 |
| 中断 | 配置 wake-up、free-fall、tap、activity/inactivity |
| 功耗 | 验证低 ODR 和中断唤醒下的平均功耗 |
