# L3GD20H 3 轴陀螺仪

> **一句话描述:** ST 独立 3 轴陀螺仪，I2C/SPI 接口，适合姿态融合教学、旧项目维护和独立 gyro 框架验证  
> **标签:** `#sensor/imu` `#sensor/gyroscope` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**L3GD20H** 是 ST 经典独立 3 轴陀螺仪，在收集入口中作为 L3GD20 系列出现。它适合旧项目维护、独立 gyro 驱动练习和与加速度计/磁力计组合的姿态融合教学；新设计通常优先考虑 LSM6 系列 6 轴 IMU。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | ST 运动传感器常见接口 |
| 轴数 | 3 轴 | 陀螺仪 |
| 典型应用 | 姿态融合、旧项目维护、框架验证 | 独立 gyro |
| 关键特性 | ODR/量程可配、FIFO、中断 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要独立陀螺仪、ST 生态兼容或教学验证的项目 |
| 不适合场景 | 新一代低功耗 6 轴 IMU、可穿戴 always-on、高抗振飞控 |
| 主要优势 | 经典型号、资料多、适合驱动和融合算法分层学习 |
| 主要风险 | 零偏、温漂和功耗不一定满足新产品要求 |
| 替代型号 | FXAS21002、LSM6DS3、LSM6DSO、BMI160 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C/SPI 访问 |
| 配置 | 设置 ODR、量程、低通滤波、FIFO 和中断 |
| 读取 | 输出 gyro_dps 三轴数据，保留 timestamp |
| 校准 | 静止零偏、温漂和坐标系映射必须记录 |
| 迁移 | 与 LSM6 系列寄存器不要混用，独立 gyro 需外部 accel 配合 |
