# BMA580 3 轴加速度计

> **一句话描述:** Bosch BMA5xx 系列低功耗 3 轴加速度计候选，I2C/SPI 接口，适合电池设备唤醒、活动识别和运动事件检测  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**BMA580** 是 Bosch BMA5xx 系列低功耗加速度计候选，适合电池设备的 always-on 活动检测、唤醒和简单运动事件判断。它可与 BMA400、BMA456、BMA530 做同厂生态对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体封装和地址以 datasheet 为准 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 唤醒、活动检测、计步入口、资产追踪 | 低功耗事件检测 |
| 关键特性 | 中断、FIFO、低功耗模式 | 功能集需按具体料号确认 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池设备需要低功耗运动唤醒和活动趋势检测 |
| 不适合场景 | 需要陀螺仪姿态融合、高带宽振动分析、导航级惯导 |
| 主要优势 | Bosch BMA 生态、低功耗、可与 BMA400/BMA530 驱动经验复用 |
| 主要风险 | 内置事件算法和中断阈值需要结合外壳、佩戴方式和噪声实测 |
| 替代型号 | BMA400、BMA456、BMA530、ADXL362、LIS2DU12 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id，确认 I2C/SPI 兼容性和复位状态 |
| 配置 | 设置 ODR、量程、滤波、低功耗模式和中断引脚 |
| 事件 | 活动/静止/步态类功能需记录阈值、持续时间和滤波配置 |
| 读取 | 支持 raw 加速度、FIFO 和事件状态分开上报 |
| 验证 | 测量休眠电流、唤醒延迟、误触发率和轴向安装方向 |
