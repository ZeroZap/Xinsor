# LIS3DH 3 轴加速度计

> **一句话描述:** ST 经典低功耗 3 轴加速度计，I2C/SPI 接口，适合唤醒、计步、倾斜检测和教育项目  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**LIS3DH** 是 ST 经典 3 轴加速度计，资料和模组生态成熟。它适合低功耗唤醒、倾斜检测、计步和基础运动采集，是 LIS2DH12/LIS2DW12 的重要对照型号。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 常见模组支持 |
| 轴数 | 3 轴加速度 | 无陀螺仪 |
| 典型应用 | 低功耗唤醒、倾斜检测、计步、教育项目 | 资料成熟 |
| 关键特性 | FIFO、中断、低功耗模式 | 适合入门加速度计驱动 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 入门加速度计、低功耗唤醒、倾斜检测、教学项目 |
| 不适合场景 | 需要 gyro 的姿态融合、高动态控制、最新低功耗指标 |
| 主要优势 | 资料多、模组常见、I2C/SPI、ST 生态成熟 |
| 主要风险 | 新项目可能更适合 LIS2DW12；中断阈值需实机调试 |
| 替代型号 | LIS2DH12、LIS2DW12、BMA400、SC7A20 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I |
| 配置 | 设置 ODR、量程、低功耗/高分辨率模式 |
| 读取 | 输出 accel_g，确认坐标轴方向 |
| 中断 | 配置 movement、tap、free-fall 等事件 |
| 验证 | 静止噪声、阈值误触发和功耗模式切换 |
