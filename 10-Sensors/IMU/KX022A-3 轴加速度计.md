# KX022A 3 轴加速度计

> **一句话描述:** Kionix/Rohm 3 轴加速度计，I2C/SPI 接口，适合低功耗运动检测、姿态和 KX023 对照评估  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/kionix`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**KX022A** 是 Kionix/Rohm 3 轴加速度计候选，在收集入口中与 KX023、KXTJ3 一起出现。它适合低功耗运动检测、姿态/方向识别和可穿戴活动采样。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体接口以料号和板级连接为准 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 活动检测、倾斜、方向识别、可穿戴 | Kionix 生态候选 |
| 关键特性 | 低功耗、中断、FIFO/缓冲 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | Kionix 系列驱动补齐、低功耗 3 轴加速度计替代评估 |
| 不适合场景 | 高 g 冲击、精密倾角、需要陀螺仪的姿态融合 |
| 主要优势 | 接口灵活，适合和 KX023/KXTJ3 做寄存器和驱动复用评估 |
| 主要风险 | 不同 KX 系列寄存器差异和中断语义需要逐项核对 |
| 替代型号 | KX023、KXTJ3、LIS3DH、BMA400 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C/SPI 访问方式 |
| 配置 | 设置 ODR、量程、低功耗、唤醒阈值和中断 |
| 读取 | 支持 xyz raw、data-ready 和 FIFO/缓冲读取 |
| 校准 | 六面校准和坐标系映射需要记录 |
| 验证 | 与 KX023/KXTJ3 对比功耗、噪声和中断行为 |
