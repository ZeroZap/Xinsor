# FXAS21002 3 轴陀螺仪

> **一句话描述:** NXP 独立 3 轴陀螺仪，I2C/SPI 接口，适合需要单独陀螺数据、姿态融合和框架适配验证  
> **标签:** `#sensor/imu` `#sensor/gyroscope` `#protocol/i2c` `#protocol/spi` `#vendor/nxp`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**FXAS21002** 是 NXP 的独立 3 轴陀螺仪，在 Zephyr/RT-Thread 收集入口中出现。它适合需要单独陀螺数据的姿态融合、传感器框架测试和与加速度计/磁力计组合的 9 轴方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 以具体封装和板级连接为准 |
| 轴数 | 3 轴 | 陀螺仪 |
| 典型应用 | 姿态融合、机器人、实验平台 | 独立 gyro 候选 |
| 关键特性 | ODR/量程可配、中断、FIFO 思路 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要独立陀螺仪、和外部加速度计/磁力计组合验证融合算法 |
| 不适合场景 | 极低成本 6 轴方案、可穿戴低功耗 always-on |
| 主要优势 | NXP 生态、独立 gyro 便于框架和融合算法分层验证 |
| 主要风险 | 陀螺零偏、温漂和启动稳定时间需要实测补偿 |
| 替代型号 | L3GD20H、ICM20608、BMI160、LSM6DSO |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C/SPI 模式 |
| 配置 | 设置量程、ODR、滤波、FIFO 和中断 |
| 读取 | 输出 gyro_dps 三轴数据，保留 timestamp |
| 校准 | 上电静止零偏、温漂和动态饱和都要记录 |
| 融合 | 与加速度计/磁力计组合时统一坐标系和采样率 |
