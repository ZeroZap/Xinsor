# ADXL367 3 轴加速度计

> **一句话描述:** ADI 超低功耗 3 轴加速度计，SPI 接口，适合 ADXL362 升级评估、唤醒和活动检测  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ADXL367** 是 ADI 超低功耗加速度计候选，可作为 ADXL362 的升级/替代评估对象。它适合长期电池设备、资产追踪、唤醒检测和低频活动监测。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 低功耗 MCU 节点常用 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 唤醒、活动检测、资产追踪、低功耗节点 | ADXL362 同类升级候选 |
| 关键特性 | 超低功耗、活动/静止检测、FIFO/中断 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池供电、长休眠、需要加速度触发唤醒的设备 |
| 不适合场景 | 高带宽振动、冲击记录、高精度倾角测量 |
| 主要优势 | 低功耗定位明确，适合和 ADXL362/BMA400 做功耗对比 |
| 主要风险 | 低功耗模式阈值和中断策略需要结合业务实测 |
| 替代型号 | ADXL362、BMA400、LIS2DW12、KX023 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device ID，确认 SPI 访问和复位状态 |
| 配置 | 设置 ODR、量程、活动/静止阈值和中断映射 |
| 低功耗 | 验证 standby、measurement、wake-up 模式电流 |
| 读取 | 支持 raw xyz、FIFO 和事件状态读取 |
| 验证 | 长时间记录误触发、漏触发和唤醒延迟 |
