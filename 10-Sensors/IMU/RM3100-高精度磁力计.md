# RM3100 高精度磁力计

> **一句话描述:** PNI 高精度三轴磁力计候选，适合电子罗盘、磁场趋势和高性能航向参考  
> **标签:** `#sensor/imu` `#sensor/magnetometer` `#protocol/i2c` `#protocol/spi` `#vendor/pni`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**RM3100** 是 PNI 高精度三轴磁力计方向的候选，适合电子罗盘、机器人航向、磁场趋势检测和需要高分辨率磁场数据的系统。它可作为 HMC5883L、QMC5883L、BMM150 和 MMC5983MA 的高性能对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体模式以模块和 datasheet 为准 |
| 轴数 | 3 轴 | 磁场测量 |
| 典型应用 | 电子罗盘、机器人航向、磁场趋势、导航辅助 | 高性能磁力计方向 |
| 关键特性 | 高分辨率/低噪声方向、可配置采样 | 需要硬铁/软铁校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 普通低成本磁力计噪声或稳定性不足的航向/磁场应用 |
| 不适合场景 | 成本敏感电子罗盘、强磁干扰环境且无校准条件的系统 |
| 主要优势 | 适合作为高精度磁力计基准，补齐 MEMSIC/Bosch/AKM 之外方案 |
| 主要风险 | 磁力计成败高度依赖结构远离电流环路和完整标定 |
| 替代型号 | MMC5983MA、BMM150、LIS2MDL、HMC5883L |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C/SPI 模式、周期计数配置和数据就绪状态 |
| 配置 | 设置采样周期、连续/单次模式和分辨率取舍 |
| 读取 | 输出三轴原始磁场和 timestamp，避免直接给未校准航向 |
| 校准 | 必须做硬铁/软铁校准，并记录安装位置和电流状态 |
| 结构 | 远离电机、电感、大电流线、磁铁和扬声器 |
