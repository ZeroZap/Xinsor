# ADXL355 3 轴加速度计

> **一句话描述:** ADI 低噪声低漂移 3 轴加速度计，SPI 接口，适合倾角测量、结构振动和精密低频运动采集  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ADXL355** 是 ADI 面向低噪声、低漂移测量的 3 轴加速度计，适合倾角、结构振动、平台监测和精密低频运动采集。它与 ADXL345/ADXL362 的定位不同，更偏高性能测量而非低成本或极低功耗唤醒。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 高性能采集常用 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 倾角、结构振动、平台稳定、低频运动 | 精密加速度方向 |
| 关键特性 | 低噪声、低漂移、FIFO/滤波思路 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要稳定低噪声加速度数据、倾角或结构状态趋势的系统 |
| 不适合场景 | 极低成本、普通计步、强冲击高 g 事件检测 |
| 主要优势 | 低噪声和稳定性优于普通消费级 3 轴加速度计 |
| 主要风险 | 成本、供电噪声、机械安装和温漂验证要求更高 |
| 替代型号 | ADXL345、ADXL362、ADXL372、LIS2DW12 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device ID，确认 SPI mode 和软复位流程 |
| 配置 | 设置量程、ODR、滤波、FIFO 和中断 |
| 读取 | 保留 timestamp，输出 raw/g 和温度辅助字段 |
| 校准 | 静态零偏、比例系数、温漂和安装方向必须记录 |
| 验证 | 用静态噪声、倾角重复性和温度循环评估实际性能 |
