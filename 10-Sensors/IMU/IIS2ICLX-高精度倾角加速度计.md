# IIS2ICLX 高精度倾角加速度计

> **一句话描述:** ST 高精度双轴倾角/振动加速度计，适合结构健康、倾角监测和工业低频振动  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#sensor/inclinometer` `#protocol/spi` `#vendor/st`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**IIS2ICLX** 是 ST 面向高精度倾角和工业监测的加速度计候选，适合结构健康监测、平台倾角、桥梁/塔架低频振动和工业设备状态趋势。它不是普通三轴计步器件，重点是低噪声、稳定安装和长期漂移管理。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 具体接口和模式以 datasheet 为准 |
| 轴数 | 2 轴 | 高精度倾角/低频加速度方向 |
| 典型应用 | 倾角监测、结构健康、低频振动、平台水平 | 工业精密采集 |
| 关键特性 | 低噪声、稳定性、工业定位 | 安装和温度补偿影响很大 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 长期倾角、结构变形趋势和低频振动监测 |
| 不适合场景 | 三轴姿态融合、计步、冲击事件、高频宽带振动 |
| 主要优势 | 精密倾角/低频监测定位明确，适合作为 ADXL355 对照 |
| 主要风险 | 机械安装、温漂和标定流程决定最终可用性 |
| 替代型号 | ADXL355、IIS3DWB、ADXL362、SCL3300 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | WHO_AM_I、SPI 时序和复位流程确认 |
| 配置 | 设置 ODR、滤波、量程、FIFO 和数据就绪中断 |
| 倾角 | 输出倾角需做零点、温度和安装角补偿 |
| 长期 | 记录温度、漂移、零偏和机械松动状态 |
| 验证 | 用已知角度治具和长期静态测试评估噪声/漂移 |
