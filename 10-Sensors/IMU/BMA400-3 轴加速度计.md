# BMA400 3 轴加速度计

> **一句话描述:** Bosch 超低功耗 3 轴加速度计，I2C/SPI 接口，适合唤醒、计步、活动检测和电池设备  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BMA400** 是 Bosch 面向超低功耗场景的 3 轴加速度计，适合用作系统唤醒、计步、活动/静止检测和姿态变化感知。它不含陀螺仪，功耗和成本都更适合长续航节点。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 低功耗设备常用 I2C |
| 轴数 | 3 轴加速度 | 无陀螺仪 |
| 典型应用 | 唤醒、计步、活动检测、倾斜检测 | 超低功耗是重点 |
| 关键特性 | 低功耗模式、中断、FIFO | 适合事件驱动 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池设备、运动唤醒、活动检测、低频姿态感知 |
| 不适合场景 | 需要角速度、姿态融合、无人机飞控 |
| 主要优势 | 超低功耗、Bosch 生态、I2C/SPI、中断功能丰富 |
| 主要风险 | 无 gyro，不能替代完整 IMU；阈值和滤波需按结构实测 |
| 替代型号 | LIS2DW12、LIS2DH12、LIS3DH、BMA456 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 chip id |
| 配置 | 设置量程、ODR、功耗模式和滤波 |
| 中断 | 配置 wake-up、activity、step、tap 等事件 |
| 低功耗 | 验证 sensor 中断唤醒 MCU 的完整链路 |
| 验收 | 静止噪声、方向符号、阈值误触发率都要测试 |
