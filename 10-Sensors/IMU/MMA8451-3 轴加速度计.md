# MMA8451 3 轴加速度计

> **一句话描述:** NXP 经典 3 轴加速度计，I2C 接口，适合旧项目维护、方向检测和低成本运动采集  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#vendor/nxp`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MMA8451** 是 NXP 经典 3 轴加速度计，在 RT-Thread 收集入口中出现。它适合方向检测、低速运动采样和旧项目维护，新设计可与 LIS3DH、KXTJ3、BMA400 等型号比较成本和生态。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 经典低成本接口 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 方向检测、低速运动、教育、旧项目维护 | NXP 经典型号 |
| 关键特性 | 中断、方向/运动检测、量程配置 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已有 NXP 生态、旧项目维护、简单运动/方向检测 |
| 不适合场景 | 超低功耗 always-on、高 g 冲击、高精度倾角 |
| 主要优势 | 资料多、I2C 简单、适合低成本加速度驱动补齐 |
| 主要风险 | 新项目需确认供货、功耗和封装是否仍合适 |
| 替代型号 | MMA8652、LIS3DH、KXTJ3、ADXL345 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C 地址 |
| 配置 | 设置量程、ODR、低功耗和中断路由 |
| 读取 | 输出 xyz raw/g，处理 data-ready 状态 |
| 事件 | 方向变化、tap、free-fall 等功能需分别验证 |
| 校准 | 静态零偏和坐标系方向要记录到 bring-up 文档 |
