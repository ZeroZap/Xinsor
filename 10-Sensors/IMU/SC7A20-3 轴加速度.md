# SC7A20 3 轴加速度传感器

> **一句话描述:** 国产低成本 3 轴加速度计，I2C 接口常见，适合成本敏感的运动检测和姿态唤醒  
> **标签:** `#sensor/accelerometer` `#sensor/imu` `#protocol/i2c` `#vendor/silan`  
> **状态:** 已建档，待补详细驱动示例  
> **最后更新:** 2026-05-20

---

## 概述

**SC7A20** 是士兰微常见 3 轴加速度计，常作为低成本运动检测方案使用。它适合玩具、消费电子、简单姿态检测、跌落检测和低功耗唤醒等场景。

---

| 参数 | 值 | 备注 |
|------|----|------|
| 供电电压 | 常见 1.8-3.6V 范围 | 以具体 datasheet/模组为准 |

| 测量对象 | 3 轴加速度 | 低成本运动检测 |

| 典型应用 | 玩具、姿态唤醒、跌落检测 | 国产替代优先候选 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 成本敏感、供应链本地化、简单运动检测 |
| 不适合场景 | 高精度惯导、强振动工业环境、高一致性计量场景 |
| 主要优势 | 成本低、国产供应、接口简单 |
| 主要风险 | 不同批次/模组资料差异较大，需要实测确认寄存器兼容性 |
| 替代型号 | LIS2DH12、LIS3DH、KX023、BMA400 |

---

## 硬件设计要点

- 保持电源稳定，低成本模组尤其要关注去耦和地弹噪声。
- 坐标方向在结构设计阶段确认，避免后续软件补偿复杂化。
- 中断脚如用于唤醒，需确认电平类型和 MCU 唤醒能力。

---

## 驱动要点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取芯片 ID 或关键状态寄存器，确认兼容型号 |
| 配置 | 设置 ODR、量程、功耗模式和中断模式 |
| 读取 | 读取 X/Y/Z 轴原始值并做符号扩展 |
| 校准 | 静止状态测量零偏，确认坐标轴方向 |
| 验证 | 摆放六面方向，检查每轴 ±1g 响应 |
