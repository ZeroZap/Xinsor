# ADXL345 3 轴加速度计

> **一句话描述:** ADI 经典 3 轴加速度计，I2C/SPI 接口，适合教育、倾斜检测、低速运动采集和旧项目维护  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ADXL345** 是 ADI 经典 3 轴加速度计，在 RT-Thread/Linux 等收集入口中常见。它适合教育项目、倾斜/方向检测、低速运动采集和旧硬件维护；新设计若强调超低功耗，可优先评估 ADXL362、BMA400 或 LIS2DW12。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 模块常见，接口灵活 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 倾斜检测、教育、简单运动采集、旧项目维护 | 经典型号 |
| 关键特性 | 量程可配、中断、FIFO/活动检测思路 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 教学、低速姿态/倾斜检测、需要成熟资料的 3 轴加速度项目 |
| 不适合场景 | 超低功耗 always-on、强冲击高 g 采样、高精度惯导 |
| 主要优势 | 资料多、社区成熟、I2C/SPI 都易接入 |
| 主要风险 | 经典型号功耗/噪声不一定适合新产品低功耗目标 |
| 替代型号 | ADXL362、LIS3DH、LIS2DW12、BMA400 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device ID，确认 I2C 地址或 SPI 模式 |
| 配置 | 设置量程、数据率、分辨率、中断映射和 FIFO |
| 读取 | 输出 xyz raw/g 值，记录 axis mapping |
| 中断 | activity、tap、free-fall 等功能需逐项实测阈值 |
| 验证 | 六面静态校准、噪声、带宽和中断误触发 |
