# KX023 3 轴加速度计

> **一句话描述:** Kionix/Rohm 3 轴加速度计，I2C 接口，适合待实现低功耗运动检测、姿态和唤醒候选  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#vendor/kionix`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**KX023** 是收集入口中标记待实现的 3 轴加速度计候选，适合低功耗运动检测、倾斜/方向识别和可穿戴活动监测。它可作为 LIS3DH、BMA400、ADXL362 的同类对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 具体型号也需核对是否支持 SPI |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 姿态检测、运动唤醒、活动分类 | 低功耗加速度候选 |
| 关键特性 | 中断、FIFO/缓冲、低功耗模式 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 待实现驱动补齐、低功耗运动节点、Kionix 生态项目 |
| 不适合场景 | 需要陀螺仪、强振动高带宽采样或工业惯导 |
| 主要优势 | 低功耗加速度计定位清晰，适合与 LIS/BMA/ADXL 系列对比 |
| 主要风险 | WHO_AM_I、寄存器版本和中断默认极性需按具体料号确认 |
| 替代型号 | LIS3DH、LIS2DW12、BMA400、ADXL362 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I 或默认寄存器，确认 I2C 地址 |
| 配置 | 设置 ODR、量程、低功耗模式和中断阈值 |
| 读取 | 支持 raw xyz、FIFO 和 data-ready 中断 |
| 校准 | 静态六面校准和轴向映射需要记录 |
| 验证 | 重点验证唤醒阈值、功耗和低频噪声 |
