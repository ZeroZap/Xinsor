# ADXL362 3 轴加速度计

> **一句话描述:** ADI 超低功耗 3 轴加速度计，SPI 接口，适合电池设备唤醒、活动检测和低功耗运动节点  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/spi` `#vendor/adi`  
> **状态:** 已验证  
> **最后更新:** 2026-06-06

---

## 概述

**ADXL362** 是 ADI 的超低功耗 3 轴加速度计，现有收集入口标记为 XinYi 已实现驱动。它适合长期电池设备、震动/活动唤醒和低频运动趋势检测，可作为 BMA400、LIS2DW12 之外的低功耗加速度方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 适合低功耗 MCU 节点 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 唤醒、活动检测、低功耗运动节点 | always-on 场景 |
| 关键特性 | 低功耗、FIFO、中断、活动/静止检测 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 电池设备低功耗唤醒、资产追踪、震动/倾斜检测 |
| 不适合场景 | 高带宽振动分析、需要陀螺仪的姿态估计 |
| 主要优势 | 功耗低、SPI、ADI 生态、适合中断唤醒架构 |
| 主要风险 | SPI 时序、低功耗模式切换和阈值调参需要实测 |
| 替代型号 | BMA400、LIS2DW12、LIS3DH、KX023 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device ID，确认 SPI mode 和片选时序 |
| 配置 | 设置 ODR、量程、低功耗模式、活动/静止阈值 |
| 中断 | 区分 data-ready、activity、inactivity 和 FIFO watermark |
| 读取 | 支持 burst read/FIFO，保留 timestamp |
| 验证 | 测量 sleep/wakeup 电流、阈值误触发和轴向映射 |
