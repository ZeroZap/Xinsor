# AK8990 3 轴磁力计

> **一句话描述:** AKM 3 轴磁力计候选，I2C 接口，适合 AKM 磁力计生态补齐、电子罗盘和 9 轴组合对照  
> **标签:** `#sensor/imu` `#sensor/magnetometer` `#protocol/i2c` `#vendor/akm`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**AK8990** 是收集入口中出现的 AKM 3 轴磁力计候选，可作为 AK8963/AK8975 的相邻型号补充。它适合电子罗盘、航向辅助和 AKM 磁力计驱动兼容层整理。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 以具体资料和板级连接为准 |
| 轴数 | 3 轴 | 磁场 |
| 典型应用 | 电子罗盘、9 轴融合、磁场趋势检测 | AKM 生态补充 |
| 关键特性 | raw 磁场输出、状态位、校准需求 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | AKM 磁力计生态补齐、旧项目维护、9 轴组合对照验证 |
| 不适合场景 | 无校准流程的新产品、强磁干扰环境、供货不明项目 |
| 主要优势 | 可和 AK8963/AK8975 形成同族驱动兼容表 |
| 主要风险 | 资料、供货和寄存器差异需要逐项确认 |
| 替代型号 | AK8963、AK8975、BMM150、LIS3MDL |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，确认 I2C 地址和状态寄存器 |
| 配置 | 设置测量模式、采样率和输出位宽 |
| 读取 | 检查 data-ready/overflow 后读取 xyz raw |
| 校准 | 支持硬铁/软铁校准和坐标系统一 |
| 兼容 | 和 AK8963/AK8975 共用框架时保留型号差异表 |
