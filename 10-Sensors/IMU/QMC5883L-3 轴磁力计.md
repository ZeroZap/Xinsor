# QMC5883L 3 轴磁力计

> **一句话描述:** 国产常见 3 轴磁力计，I2C 接口，常作为 HMC5883L 替代用于电子罗盘和航向估计  
> **标签:** `#sensor/magnetometer` `#sensor/imu` `#protocol/i2c` `#vendor/qst`  
> **状态:** 已建档，待补详细驱动示例  
> **最后更新:** 2026-05-20

---

## 概述

**QMC5883L** 是常见低成本 3 轴磁力计，市场上大量电子罗盘模块使用该型号或兼容型号。它经常被用作 HMC5883L 的替代，但寄存器和初始化流程并不完全兼容，驱动时需要区分。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见地址为 0x0D |
| 测量对象 | 3 轴磁场 | 用于航向估计 |
| 输出 | X/Y/Z 磁场原始值 | 需校准后使用 |
| 典型应用 | 电子罗盘、机器人航向、姿态融合 | 低成本方案 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 成本敏感电子罗盘、教学、机器人航向辅助 |
| 不适合场景 | 强磁干扰环境、高精度导航、未经校准的量产方案 |
| 主要优势 | 价格低、模块常见、I2C 简单 |
| 主要风险 | 与 HMC5883L 不完全兼容，磁力计必须做硬铁/软铁校准 |
| 替代型号 | HMC5883L、BMM150、LIS3MDL、AK8963 |

---

## 硬件设计要点

- 远离电机、电感、大电流走线、磁铁和铁磁结构件。
- PCB 上不要在传感器附近铺设高变化电流回路。
- 整机装配后再做磁校准，裸板校准意义有限。

---

## 驱动要点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址和 ID/状态寄存器，不要直接套用 HMC5883L 驱动 |
| 配置 | 设置 ODR、量程、连续测量模式 |
| 读取 | 读取 X/Y/Z 原始值，注意字节序和溢出标志 |
| 校准 | 做 8 字运动，拟合硬铁偏移和软铁比例 |
| 融合 | 与加速度计/陀螺仪融合前先完成坐标轴对齐 |
