# ADXL346 3 轴加速度计

> **一句话描述:** ADI 经典 3 轴加速度计，I2C/SPI 接口，适合 ADXL345 相邻型号评估、旧项目维护和低速运动采集  
> **标签:** `#sensor/imu` `#sensor/accelerometer` `#protocol/i2c` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**ADXL346** 是 ADI 经典 3 轴加速度计候选，在收集入口中与 ADXL345、ADXL355、ADXL362、ADXL372 一起出现。它适合旧项目维护、低速运动采集和 ADXL345 相邻型号兼容性评估。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体接口能力以 datasheet 为准 |
| 轴数 | 3 轴 | 加速度 |
| 典型应用 | 倾斜检测、低速运动、旧项目维护 | ADXL345 相邻候选 |
| 关键特性 | 量程/ODR 可配、中断、活动检测 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 维护 ADXL34x 旧项目、做经典 3 轴加速度计驱动兼容层 |
| 不适合场景 | 超低功耗 always-on、高 g 冲击、低噪声精密倾角 |
| 主要优势 | ADI 生态成熟，可与 ADXL345 驱动结构对照 |
| 主要风险 | 与 ADXL345 的寄存器/功能差异需要逐项核对 |
| 替代型号 | ADXL345、ADXL362、LIS3DH、BMA400 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device ID，确认 I2C/SPI 模式和默认寄存器 |
| 配置 | 设置量程、ODR、分辨率、中断映射和 FIFO/事件功能 |
| 读取 | 输出 xyz raw/g，记录坐标系和采样时间 |
| 兼容 | 与 ADXL345 共用驱动时保留型号能力表 |
| 验证 | 六面校准、噪声、功耗和事件中断误触发 |
