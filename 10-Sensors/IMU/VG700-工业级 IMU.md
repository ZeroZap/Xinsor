# VG700 工业级 IMU

> **一句话描述:** VectorNav 工业级 6 轴 IMU/AHRS 候选，SPI/UART 接口，适合高成本导航辅助、平台稳定和工业运动测量  
> **标签:** `#sensor/imu` `#sensor/industrial` `#protocol/spi` `#protocol/uart` `#vendor/vectornav`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**VG700** 是 VectorNav 工业级惯性传感器候选，定位明显高于消费级 IMU。它适合预算充足、需要稳定运动测量、姿态输出或导航辅助的系统；在 XinSor 当前阶段更适合作为工业/导航级对照型号建档。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI / UART | 以具体型号和固件配置为准 |
| 轴数 | 6 轴 | accel + gyro，部分系统输出会包含融合姿态 |
| 典型应用 | 平台稳定、导航辅助、工业运动测量 | 高成本高稳定候选 |
| 关键特性 | 工业级标定、温度补偿、稳定输出 | 不按消费级 IMU 成本评估 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 高预算工业项目、导航辅助、运动平台和需要稳定标定输出的系统 |
| 不适合场景 | 教育项目、可穿戴、低成本机器人、只需简单姿态输入的 MCU 板卡 |
| 主要优势 | 工业级定位、系统级输出能力强、可作为高端 IMU 对照 |
| 主要风险 | 成本高、接口协议和配置流程复杂，机械安装和供电质量要求高 |
| 替代型号 | ADIS16470、ADIS16475、VectorNav 其他系列、BMI088 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 明确使用 SPI 还是 UART，先跑通设备识别和基础输出帧 |
| 配置 | 固化输出速率、坐标系、滤波、时间同步和保存参数流程 |
| 读取 | 严格校验帧格式、校验和、时间戳和单位换算 |
| 系统 | 机械安装刚性、供电噪声、接地和线缆屏蔽会直接影响表现 |
| 验证 | 用静态 Allan/零偏趋势、转台或标准姿态源做分层验证 |
