# MMC5983MA 3 轴磁力计

> **一句话描述:** MEMSIC 高精度 3 轴磁力计，I2C/SPI 接口，适合电子罗盘、9 轴组合和低噪声磁场趋势检测  
> **标签:** `#sensor/imu` `#sensor/magnetometer` `#protocol/i2c` `#protocol/spi` `#vendor/memsic`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MMC5983MA** 是 MEMSIC 的 3 轴磁力计候选，常用于电子罗盘、9 轴姿态融合和磁场趋势检测。相对 HMC5883L、QMC5883L 这类常见低成本磁力计，它更适合需要更好噪声表现和新项目供货评估的场景。

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要新项目磁力计、电子罗盘和 9 轴组合方案评估 |
| 不适合场景 | 强磁环境绝对测量、无需校准的即插即用航向、成本极低项目 |
| 主要优势 | I2C/SPI、磁力计生态补齐、适合替代老 HMC/QMC 方案评估 |
| 主要风险 | 软硬铁校准、PCB 电流环路、扬声器/磁铁和外壳结构影响很大 |
| 替代型号 | QMC5883L、HMC5883L、BMM150、LIS2MDL、LIS3MDL |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取产品 ID，确认 I2C/SPI 模式和 data-ready 行为 |
| 配置 | 设置 ODR、带宽、连续/单次测量和 set/reset 策略 |
| 读取 | 处理 3 轴原始值、温度和状态位，保留溢出/饱和标志 |
| 校准 | 必须支持软硬铁校准和坐标系安装矩阵 |
| 验证 | 用 8 字运动、旋转台或已知航向对比 offset、尺度和倾斜补偿 |
