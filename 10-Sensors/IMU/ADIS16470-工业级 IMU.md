# ADIS16470 工业级 IMU

> **一句话描述:** ADI 工业/战术级 6 轴 IMU，SPI 接口，适合高稳定姿态测量、导航辅助和工业运动平台  
> **标签:** `#sensor/imu` `#sensor/industrial` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**ADIS16470** 是 ADI 工业/战术级 IMU 候选，面向高稳定性、低漂移和工业环境。它与消费级 IMU 定位不同，适合导航辅助、平台稳定和高可靠工业设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 工业 IMU 常见接口 |
| 轴数 | 6 轴 | accel + gyro |
| 典型应用 | 工业平台、导航辅助、稳定控制 | 高成本高可靠 |
| 关键特性 | 温度补偿、校准参数、稳定性 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 高稳定性姿态测量、工业/导航辅助、预算充足项目 |
| 不适合场景 | 消费电子、可穿戴、低成本机器人 |
| 主要优势 | 稳定性高、工业级、ADI 资料完整 |
| 主要风险 | 成本高、封装/供电/机械安装要求高，驱动需严格按时序实现 |
| 替代型号 | ADIS16475、VectorNav 系列、BMI088 高性能消费级方案 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| SPI | 确认 SPI 模式、帧格式和读写时序 |
| 读取 | burst read 输出 gyro/accel/temp/状态 |
| 校准 | 使用出厂校准并记录安装误差和零偏 |
| 状态 | 监控诊断寄存器、供电和传感器健康状态 |
| 机械 | 安装刚性、振动隔离和坐标系定义同等重要 |
