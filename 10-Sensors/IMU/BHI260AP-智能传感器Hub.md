# BHI260AP 智能传感器Hub

> **一句话描述:** Bosch 低功耗智能传感器 Hub，适合可穿戴、耳机和 always-on 动作识别  
> **标签:** `#sensor/imu` `#sensor/hub` `#sensor/motion` `#protocol/i2c` `#protocol/spi` `#vendor/bosch`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-28

---

## 概述

**BHI260AP** 是 Bosch 智能传感器 Hub 候选，面向低功耗动作识别、传感器融合和 always-on 场景。它适合可穿戴、TWS 耳机、手势/活动检测和需要把运动算法下沉到传感器侧的设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体接口和 boot 流程以 datasheet 为准 |
| 类型 | 智能传感器 Hub | 可连接/管理运动传感器和算法输出 |
| 典型应用 | 可穿戴、耳机、活动识别、低功耗手势 | always-on 运动智能 |
| 关键特性 | 内置 MCU/算法、低功耗事件输出 | 固件加载和算法授权需确认 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 主控希望休眠，由传感器侧完成动作识别和融合的产品 |
| 不适合场景 | 只需要原始加速度/陀螺仪、算法完全自研或极低 BOM 项目 |
| 主要优势 | 降低主控功耗，减少运动算法开发和实时调度压力 |
| 主要风险 | 固件、算法版本、调试工具链和产线配置复杂度较高 |
| 替代型号 | BHI360、BNO080/BNO085、BMI270、LSM6DSOX |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 启动 | 确认 boot/firmware loading 流程和复位时序 |
| 配置 | 配置虚拟传感器、采样率、延迟和 FIFO |
| 读取 | 解析事件帧、时间戳和算法输出状态 |
| 功耗 | 区分 always-on 模式和主控唤醒策略 |
| 量产 | 固件版本、校准数据和算法配置需可追溯 |
