# LIS2DH12 3 轴加速度传感器

> **一句话描述:** ST 低功耗 3 轴加速度计，I2C/SPI 双接口，适合姿态唤醒、跌落检测和可穿戴设备  
> **标签:** `#sensor/accelerometer` `#sensor/imu` `#protocol/i2c` `#protocol/spi` `#vendor/st`  
> **状态:** 已建档，待补详细驱动示例  
> **最后更新:** 2026-05-20

---

## 概述

**LIS2DH12** 是 STMicroelectronics 的超低功耗 3 轴加速度计，支持多种量程、输出数据率和中断事件，常用于运动检测、屏幕方向识别、跌落检测和低功耗唤醒。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 供电电压 | 1.71-3.6V | 适合低功耗系统 |
| 接口 | I2C / SPI | SPI 可用于更高采样率场景 |
| I2C 地址 | 0x18 / 0x19 | 由 SA0 决定 |
| 量程 | ±2g / ±4g / ±8g / ±16g | 可配置 |
| 输出 | 3 轴加速度 | 支持中断事件 |
| 典型应用 | 可穿戴、低功耗唤醒、姿态检测 | 成本和功耗平衡好 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 低功耗运动检测、方向识别、跌落/敲击检测 |
| 不适合场景 | 需要陀螺仪或高精度姿态解算的场景 |
| 主要优势 | 功耗低、接口灵活、中断功能成熟、资料多 |
| 主要风险 | 需要做好机械安装和零偏校准，低成本模组差异较大 |
| 替代型号 | LIS3DH、KX023、SC7A20、BMA400、ADXL362 |

---

## 硬件设计要点

- 传感器布局远离强振动源、马达和高电流走线。
- I2C 模式注意上拉电阻，SPI 模式注意片选和总线复用。
- 若使用中断唤醒，INT 引脚需接 MCU 可唤醒 GPIO。
- 机械安装方向要和软件坐标系保持一致。

---

## 驱动要点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 WHO_AM_I，典型值为 `0x33` |
| 配置 | 设置 ODR、量程、低功耗/高分辨率模式 |
| 读取 | 连续读取 X/Y/Z 轴输出寄存器 |
| 中断 | 配置运动、自由落体、点击、方向变化等事件 |
| 校准 | 静止状态下记录零偏，应用层做偏移补偿 |
