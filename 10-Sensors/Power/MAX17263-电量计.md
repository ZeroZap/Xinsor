# MAX17263 电量计

> **一句话描述:** Maxim/ADI MAX1726x 系列电量计候选，适合产品分档、单节电池 SOC 和容量状态估算  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MAX17263** 是 Maxim/ADI MAX1726x 系列电量计候选，适合单节锂电池电量显示、容量估算、低电告警和产品分档。它与 MAX17260/MAX17262 接近，适合统一纳入电量计驱动能力表。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | MAX1726x 系列接口 |
| 测量对象 | 电压、SOC、容量、状态 | 具体能力以 datasheet 为准 |
| 典型应用 | 便携设备、可穿戴、电池 IoT | 单节电量计候选 |
| 关键特性 | ModelGauge、告警、低功耗状态 | 需确认电池配置流程 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | MAX1726x 系列产品分档、单节电池设备和低功耗 SOC 显示 |
| 不适合场景 | 多串 BMS、大电流功耗统计、只需粗略低电检测 |
| 主要优势 | 可与 MAX17260/MAX17262 形成同族候选池 |
| 主要风险 | 不同子型号寄存器、封装、供货和配置要求需要核对 |
| 替代型号 | MAX17260、MAX17262、MAX17055、LC709203F |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取版本/状态，识别 MAX1726x 子型号 |
| 配置 | 写入容量、终止电压、告警阈值和电池参数 |
| 读取 | 输出 SOC、电压、容量、状态、告警和温度相关字段 |
| 低功耗 | 睡眠期间 SOC 连续性和告警唤醒需验证 |
| 维护 | 电池老化、温度和自放电对 SOC 的影响要长期记录 |
