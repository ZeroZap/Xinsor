# BQ27220 电量计

> **一句话描述:** TI 单节锂电池电量计候选，适合低功耗便携设备、可穿戴和 BQ27421/BQ27441 对照  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**BQ27220** 是 TI 单节锂电池电量计候选，可用于便携设备、可穿戴、无线节点和低功耗电池状态显示。它适合与 BQ27421/BQ27441、MAX17055 做单节 gauge 对照。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | TI gauge 常见接口 |
| 测量对象 | 电压、SOC、容量、状态 | 单节锂电池方向 |
| 典型应用 | 可穿戴、便携设备、低功耗节点 | 单节 gauge 候选 |
| 关键特性 | SOC/容量估算、低功耗、告警 | 需要参数配置 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 TI 生态、单节电池 SOC 和低功耗状态管理的项目 |
| 不适合场景 | 多串电池、大电流功耗统计、无需电池模型的简单应用 |
| 主要优势 | TI gauge 生态，适合与 BQ27421/BQ27441 做分档评估 |
| 主要风险 | 设计容量、终止电压、校准和 sealed/config 状态机复杂 |
| 替代型号 | BQ27421、BQ27441、MAX17055、LC709203F |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device type/control status，确认 gauge 状态 |
| 配置 | 设置 design capacity、terminate voltage、taper rate 和告警 |
| 读取 | 输出 voltage、soc、remaining capacity、full charge capacity 和 flags |
| 状态 | 处理 sealed/unsealed、config update 和复位流程 |
| 验证 | 完整充放电循环对比 SOC、容量和低电告警 |
