# LTC2947 功率能量监测传感器

> **一句话描述:** ADI/Linear Technology 高精度功率/能量监测器候选，适合电源测试、工业电源和高压高精度遥测  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#protocol/spi` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**LTC2947** 是 ADI/Linear Technology 的高精度功率/能量监测候选，可用于电源测试、工业电源、服务器电源轨和较高要求的功率遥测。它适合作为 INA228/INA229 之外的 ADI 高精度能量统计方案。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SPI | 具体模式以 datasheet 为准 |
| 测量对象 | 电压、电流、功率、能量、电荷 | 依赖分流和量程配置 |
| 典型应用 | 工业电源、服务器、电源测试、能源统计 | 高精度功率监测候选 |
| 关键特性 | 功率/能量累计、宽动态、告警 | 需严格校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 ADI 生态、高精度功率/能量统计和工业电源遥测的项目 |
| 不适合场景 | 低成本单路电流表、单节电池 SOC、多通道低精度板卡遥测 |
| 主要优势 | 面向高精度功率和能量累计，适合测试/工业系统 |
| 主要风险 | 校准、分流热设计、寄存器配置和接口模式复杂度较高 |
| 替代型号 | INA228、INA229、LTC2945、PAC1934 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C/SPI 模式、设备状态和告警寄存器 |
| 配置 | 设置量程、采样、累计模式、告警和分流参数 |
| 读取 | 输出电压、电流、功率、能量、电荷和溢出状态 |
| 校准 | 分流阻值、公差、温漂、offset 和满量程都要记录 |
| 安全 | 高压/大电流系统要处理隔离、浪涌和 shunt 发热 |
