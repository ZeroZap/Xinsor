# INA3221 三通道电流电压传感器

> **一句话描述:** TI 三通道 I2C 电流/电压监测器，适合多电源轨板卡遥测、SBC 功耗分解和系统健康监控  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**INA3221** 是 TI 三通道电流/电压监测器候选，可同时监测多路电源轨的总线电压和分流电压，适合嵌入式板卡、SBC、电机控制板和多路负载功耗拆分。它比 INA219/INA226 更适合多路遥测，比 PAC1934 通道少但 TI 生态资料更常见。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 多通道电源监测 |
| 测量对象 | 3 路总线电压、分流电压、电流趋势 | 电流由分流电阻换算 |
| 典型应用 | 多电源轨遥测、SBC 功耗、系统健康监控 | 三通道候选 |
| 关键特性 | 多通道采样、告警阈值、连续/单次测量 | 需要每路 Kelvin 连接 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 一颗芯片监测 3 路电源轨，做功耗分解和过流告警 |
| 不适合场景 | 单节电池 SOC、多串 BMS、高精度能量累计 |
| 主要优势 | 三通道集成、I2C 简单，适合板卡级遥测 |
| 主要风险 | 每路 shunt 阻值、热漂移和布线误差都要单独校准 |
| 替代型号 | PAC1934、MAX34407、INA226、INA228 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 manufacturer/die ID，确认 I2C 地址 |
| 配置 | 设置通道使能、平均次数、转换时间和告警阈值 |
| 读取 | 输出每通道 bus/shunt voltage、current 和状态位 |
| 校准 | 每通道记录 shunt 阻值、量程、方向和负载名称 |
| 告警 | critical/warning 阈值需要映射为统一 power event |
