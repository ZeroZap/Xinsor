# LC709203F 电量计

> **一句话描述:** onsemi 单节锂电池电量计，I2C 接口，适合低功耗便携设备的 SOC 估算和低电告警  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/onsemi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**LC709203F** 是 onsemi 的单节锂电池电量计，常用于小型电池设备的 SOC 估算。它不需要外部分流电阻，接入成本低，适合作为 MAX17048、BQ27441 之外的低功耗电量计候选。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见电量计接口 |
| 测量对象 | 电池电压、SOC、状态 | 单节锂电池 |
| 典型应用 | 可穿戴、无线节点、便携设备 | 低功耗电量显示 |
| 关键特性 | 无 shunt、低功耗、低电告警 | 精度依赖电池曲线匹配 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要简单 SOC 显示、低功耗和较少外围器件的单节电池设备 |
| 不适合场景 | 多串电池、需要电流/功率统计、复杂 BMS |
| 主要优势 | 外围简单、休眠功耗低、适合小型设备 |
| 主要风险 | 电池类型配置和温度变化会影响 SOC 准确性 |
| 替代型号 | MAX17048、MAX17260、BQ27441、BQ27421 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C ACK，读取版本/状态类寄存器 |
| 配置 | 设置电池类型、容量相关参数和告警阈值 |
| 读取 | 周期读取 cell voltage、RSOC 和状态标志 |
| 告警 | 低电量阈值需要和系统关机策略联动 |
| 验证 | 用完整充放电曲线对比 SOC 与实际容量变化 |
