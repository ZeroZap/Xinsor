# BQ27421 电量计

> **一句话描述:** TI 单节锂电池 Impedance Track 电量计，I2C 接口，适合便携设备的 SOC、容量和电池状态估算  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**BQ27421** 是 TI 面向单节锂电池的电量计，常作为 BQ27441 同类候选。它适合需要 SOC、剩余容量、满充容量和状态标志的便携设备，但 bring-up 需要认真处理配置更新和电池参数。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | TI gauge 常见接口 |
| 测量对象 | 电压、SOC、容量、状态 | 单节锂电池 |
| 典型应用 | 可穿戴、便携仪表、无线节点 | 需要比电压估算更稳定的 SOC |
| 关键特性 | Impedance Track、容量估算、状态输出 | 需配置电池参数 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | TI 生态项目、需要较完整电池状态字段的单节电池设备 |
| 不适合场景 | 极简电量显示、多串电池、高精度实时功耗计量 |
| 主要优势 | 资料和软件生态成熟、状态字段丰富、适合产品化电量管理 |
| 主要风险 | 设计容量、终止电压、化学 ID 和学习状态不正确会导致 SOC 偏差 |
| 替代型号 | BQ27441、MAX17048、MAX17260、LC709203F |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 control/status 和 device type，确认是否 sealed |
| 配置 | 处理 config update 流程，写入容量、电压和充电终止参数 |
| 读取 | 输出 voltage、soc、remaining capacity、full charge capacity、flags |
| 状态机 | 关注 sealed/unsealed、sleep、充放电标志和低电量告警 |
| 验证 | 用完整充放电循环校验 SOC 曲线、容量收敛和低电关机点 |
