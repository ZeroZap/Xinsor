# MAX34407 多通道电流电压传感器

> **一句话描述:** Maxim/ADI 四通道 SMBus 电流/电压监测器，适合多路电源轨遥测、板卡功耗分解和上电状态监控  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MAX34407** 是 Maxim/ADI 的多通道电源监测候选，可通过 SMBus/I2C 采集多路电源轨电压和电流趋势。它适合需要板卡级电源遥测、负载分解和上电状态监控的系统。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SMBus/I2C | 与 I2C 驱动模型接近 |
| 测量对象 | 多路电压、电流趋势 | 具体通道和量程以 datasheet 为准 |
| 典型应用 | 多电源轨板卡、服务器/网络设备、嵌入式功耗监控 | 多通道遥测 |
| 关键特性 | 多通道采样、阈值告警、电源轨状态监控 | 需要外部分流和布局配合 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 多路电源轨电流/电压遥测、板卡功耗分解、设备健康监控 |
| 不适合场景 | 单节电池 SOC、极低成本单路电流表、计量级电能表 |
| 主要优势 | 多通道集成，适合系统级监控而不是单点测量 |
| 主要风险 | 需要确认供货、SMBus 时序、告警策略和每通道量程匹配 |
| 替代型号 | PAC1934、INA3221、INA226、INA238 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 SMBus/I2C 地址、设备 ID 和通道能力 |
| 配置 | 建立通道表，配置阈值、采样周期和告警掩码 |
| 读取 | 输出每通道电压、电流 raw/工程值，并带上通道名 |
| 告警 | 过流、欠压和电源轨异常需映射到统一 power event |
| 验证 | 多路负载阶跃和上电/掉电过程要单独采样确认 |
