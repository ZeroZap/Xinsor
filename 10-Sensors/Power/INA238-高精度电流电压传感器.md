# INA238 高精度电流电压传感器

> **一句话描述:** TI 高精度数字功率监测器，I2C/SPI 接口，适合高速功耗分析、电源保护和工业电源监控  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#protocol/spi` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**INA238** 是 TI 高精度数字功率监测器，可用于高精度电流、电压、功率采样。相对 INA226，它更偏向高性能监测和更复杂电源系统；相对 INA228，它可作为接口/性能取舍候选。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / SPI | 具体接口按型号/封装确认 |
| 测量对象 | 分流电压、总线电压、电流、功率 | 外接 shunt |
| 典型应用 | 电源保护、功耗分析、工业电源监控 | 高性能候选 |
| 关键配置 | ADC range、averaging、alert 阈值 | 适合保护联动 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 工业/电源模块监控、需要 alert 阈值和高精度采样的系统 |
| 不适合场景 | 简单低成本电流表、无需分流电阻的场景 |
| 主要优势 | 高精度、配置灵活、适合保护和统计 |
| 主要风险 | 接口、寄存器位宽和比例系数需严格按 datasheet 实现 |
| 替代型号 | INA226、INA228、INA219、INA260 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认总线接口和设备 ID/默认寄存器 |
| 校准 | 明确 shunt_cal、current_lsb 和功率换算 |
| 配置 | 设置转换时间、平均次数、ADC range 和模式 |
| Alert | 配置过流、过压、欠压等阈值输出 |
| 验证 | 使用电子负载扫电流，检查线性度和阈值触发 |
