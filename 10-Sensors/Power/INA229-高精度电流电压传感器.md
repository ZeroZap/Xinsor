# INA229 高精度电流电压传感器

> **一句话描述:** TI SPI 高精度功率/能量/电荷监测器候选，适合高速电源遥测和高精度能量统计  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/spi` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**INA229** 是 TI 高精度功率监测候选，定位接近 INA228，但偏 SPI 接口场景，可用于高精度电压、电流、功率、能量和电荷统计。它适合需要更高总线带宽或隔离 SPI 架构的系统。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 与 INA228 的 I2C 路线区分 |
| 测量对象 | 电压、电流、功率、能量、电荷 | 依赖 shunt 与校准 |
| 典型应用 | 高精度功耗统计、电池测试、工业电源遥测 | SPI 高精度候选 |
| 关键特性 | 高精度 ADC、能量/电荷累计、告警 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 SPI、高精度能量/电荷累计和快速电源遥测的系统 |
| 不适合场景 | 低成本 I2C 单路功耗、单节电池 SOC 算法、电源轨很多的板卡 |
| 主要优势 | SPI 带宽和高精度统计能力适合实验/工业电源监测 |
| 主要风险 | 寄存器配置复杂，校准、溢出和时间戳需要严格处理 |
| 替代型号 | INA228、INA238、INA237、LTC2947 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/诊断寄存器，确认 SPI 模式和复位 |
| 配置 | 设置量程、ADC、平均、shunt temp/补偿和告警 |
| 读取 | 输出电压、电流、功率、能量、电荷和累计时间 |
| 校准 | 处理 calibration、energy_lsb、charge_lsb 和溢出 |
| 可靠性 | SPI CRC/错误码、溢出和断电恢复策略要明确 |
