# MAX17262 电量计

> **一句话描述:** Maxim/ADI 低功耗电量计候选，适合单节锂电池 SOC、容量估算和 MAX17260 相邻型号评估  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MAX17262** 是 Maxim/ADI MAX1726x 系列电量计候选，可用于单节锂电池 SOC、剩余容量、低电告警和便携设备电池状态估算。它适合作为 MAX17260 的相邻型号补齐。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | MAX1726x 系列接口 |
| 测量对象 | 电压、SOC、容量、状态 | 具体能力以 datasheet 为准 |
| 典型应用 | 可穿戴、便携设备、无线节点 | 单节电量计候选 |
| 关键特性 | ModelGauge、低功耗、告警 | 配置流程需验证 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已评估 MAX17260，想补齐 MAX1726x 系列相邻型号的项目 |
| 不适合场景 | 多串电池、外部分流高精度功耗统计、极简低成本电压百分比 |
| 主要优势 | 与 MAX17260 生态相近，适合驱动能力表复用 |
| 主要风险 | 电池 profile、容量配置、封装和供货差异需确认 |
| 替代型号 | MAX17260、MAX17263、MAX17055、BQ27421 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/status，确认型号和寄存器能力 |
| 配置 | 设置容量、电压阈值、温度策略和告警 |
| 读取 | 输出 SOC、电压、剩余容量、状态和告警位 |
| 兼容 | MAX17260/MAX17262/MAX17263 共用驱动时保留能力表 |
| 验证 | 做完整充放电循环，记录 SOC 跳变和低电告警 |
