# INA260 电流电压传感器

> **一句话描述:** TI 内置分流电阻的 I2C 电流/电压/功率监测器，适合板卡功耗监测和快速原型验证  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**INA260** 是 TI 的数字电流、电压和功率监测器，特点是内部集成精密分流电阻，减少外部 shunt 选型和 Kelvin 布线复杂度。它适合板卡功耗监测、实验室原型和中等电流电源路径监控。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 地址配置能力以 datasheet 为准 |
| 测量对象 | 电流、总线电压、功率 | 内置 shunt |
| 典型应用 | 板卡功耗监测、原型调试、电源路径监控 | 降低硬件设计门槛 |
| 关键特性 | 集成分流电阻、校准简化、告警输出 | 电流范围受器件限制 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 不想自行选择 shunt、需要快速得到电流/电压/功率数据的板卡 |
| 不适合场景 | 大电流路径、极低压降需求、需要自定义 shunt 阻值的系统 |
| 主要优势 | 硬件接入简单、误差来源少、驱动换算比外置 shunt 方案简单 |
| 主要风险 | 内置 shunt 的压降、发热和量程需要提前核对 |
| 替代型号 | INA219、INA226、INA228、INA238 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 manufacturer/device ID 或默认寄存器确认通信 |
| 配置 | 设置转换时间、平均次数、工作模式和告警阈值 |
| 读取 | 输出 current_a、bus_voltage_v、power_w |
| 保护 | 检查过流告警、功耗温升和 PCB 散热条件 |
| 验证 | 用电子负载扫电流，确认内置 shunt 压降和读数线性 |
