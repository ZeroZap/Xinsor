# INA228 高精度电流电压传感器

> **一句话描述:** TI 高精度功率/能量/电荷监测器，I2C 接口，适合高精度功耗分析、电池系统和大电流电源监控  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**INA228** 是 TI 高精度电流/电压/功率监测器，支持更高分辨率的数据采集，并可用于能量和电荷累计。它适合功耗分析、电池设备、电源模块和需要高精度统计的系统。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 高精度监测器 |
| 测量对象 | 电压、电流、功率、能量、电荷 | 外接 shunt |
| 典型应用 | 功耗分析、电池系统、大电流电源监控 | 高端 INA 系列候选 |
| 关键配置 | ADC range、shunt、校准、累计策略 | 需严谨 bring-up |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要高分辨率功耗统计、能量/电荷累计和大范围电源监控 |
| 不适合场景 | 只需简单板卡电流显示的低成本项目 |
| 主要优势 | 高精度、数据类型丰富、能量/电荷累计、TI 资料完整 |
| 主要风险 | 寄存器和缩放复杂度高，shunt 热漂和布局误差会限制实际精度 |
| 替代型号 | INA226、INA238、INA219、INA229 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID 或默认配置，确认 I2C 通信 |
| 校准 | 计算 shunt_cal，明确 current_lsb 和 energy_lsb |
| 配置 | 设置 ADC range、conversion time、averaging 和模式 |
| 读取 | 支持电压、电流、功率、温度、能量和电荷字段 |
| 安全 | 验证过流/过压阈值和 shunt 功耗余量 |
