# INA230 电流电压传感器

> **一句话描述:** TI I2C 电流/电压/功率监测器，定位接近 INA226，适合板卡电源轨功耗监测和电池路径遥测  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**INA230** 是 TI 的数字电流、电压和功率监测器，常作为 INA226 相邻型号纳入选型池。它通过外部分流电阻测量电流，并读取总线电压用于功率估算，适合需要 I2C 遥测但不想引入复杂电源管理芯片的板卡。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 地址和寄存器细节以 datasheet 为准 |
| 测量对象 | 分流电压、总线电压、电流、功率 | 需外接 shunt |
| 典型应用 | 板卡功耗、电池路径、电源轨遥测 | INA226 相邻候选 |
| 关键配置 | shunt 阻值、转换时间、平均次数、校准寄存器 | 精度依赖硬件和配置 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 I2C 电源遥测、板级功耗统计和电流阈值监测 |
| 不适合场景 | 隔离高压测量、无需串 shunt 的极简系统、交流功率计量 |
| 主要优势 | TI 生态成熟、与 INA226 类驱动模型接近、软件复用度高 |
| 主要风险 | shunt 发热、Kelvin 走线和校准参数错误会直接影响读数 |
| 替代型号 | INA226、INA231、INA237、INA260、INA228 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、ID/默认寄存器和告警脚连接 |
| 校准 | 根据 shunt resistor、current_lsb 和最大电流计算校准值 |
| 配置 | 设置 bus/shunt 转换时间、平均次数和连续/触发模式 |
| 读取 | 输出 bus voltage、shunt voltage、current、power，并保留原始值便于校准 |
| 验证 | 用电子负载和万用表覆盖小电流、额定电流和过流阈值 |
