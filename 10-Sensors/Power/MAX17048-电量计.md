# MAX17048 电量计

> **一句话描述:** Maxim/ADI 低功耗锂电池电量计，I2C 接口，适合单节锂电池 SOC 估算和低功耗设备  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**MAX17048** 是常见单节锂电池电量计，使用 ModelGauge 类算法估算 SOC，不需要外部分流电阻。它适合小型低功耗设备、无线节点和可穿戴设备的电量显示。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见电量计接口 |
| 测量对象 | 电池电压、SOC、变化率 | 单节锂电池 |
| 典型应用 | 可穿戴、IoT 节点、便携设备 | 低功耗电量显示 |
| 关键特性 | 无 shunt、低功耗、快速 SOC 估算 | 不直接测电流 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 单节锂电池设备、电量显示、低功耗无线节点 |
| 不适合场景 | 多串电池、需要精确电流/功耗统计、复杂 BMS |
| 主要优势 | 无需分流电阻、低功耗、接入简单、模组常见 |
| 主要风险 | SOC 是算法估算，电池型号、温度和负载变化会影响准确性 |
| 替代型号 | MAX17043、MAX17260、BQ27441、LC709203F |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 version/status 或确认 I2C ACK |
| 读取 | 获取 VCELL、SOC、crate 等寄存器 |
| 配置 | 设置 alert 阈值、休眠策略和 quick start 策略 |
| 校准 | 和实际充放电曲线对比，记录不同电池表现 |
| 低功耗 | 睡眠/唤醒策略不能影响 SOC 连续性判断 |
