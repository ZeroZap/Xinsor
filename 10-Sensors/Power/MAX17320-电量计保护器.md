# MAX17320 电量计保护器

> **一句话描述:** ADI/Maxim 集成电量计和电池保护功能的器件，适合单节锂电池包安全监测和产品化电源管理  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protection` `#protocol/i2c` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MAX17320** 面向单节锂电池保护与电量估算场景，适合需要 SOC、容量、温度、保护阈值和安全状态统一管理的产品。它不只是读电量的传感器，硬件保护、FET 控制和参数配置需要和电池包设计一起评估。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SMBus | 具体寄存器和安全配置以 datasheet 为准 |
| 测量对象 | 电压、电流、SOC、容量、温度、保护状态 | 面向单节电池包 |
| 典型应用 | 便携设备、电池包、可穿戴、备电模块 | 电量计 + 保护 |
| 关键配置 | 保护阈值、FET 控制、电池模型、容量参数 | 需要严谨验证 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 产品化单节锂电池包，需要电量估算和保护状态统一管理 |
| 不适合场景 | 只想快速显示电池百分比的低成本原型 |
| 主要优势 | 集成度高、保护状态丰富、适合电池包安全设计 |
| 主要风险 | 配置错误可能影响充放电保护策略，必须结合电芯和法规要求验证 |
| 替代型号 | MAX17201、MAX17260、MAX17055、BQ34Z100-G1、BQ27441 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 安全 | 先明确保护阈值、FET 控制权限和恢复策略，避免软件误操作 |
| 配置 | 电池容量、温度阈值、过流/欠压/过压参数必须版本化记录 |
| 读取 | 将 fuel gauge 数据和 protection status 分开上报 |
| 告警 | 低电、过温、过流、短路等事件需要上层电源策略处理 |
| 验证 | 保护功能需在受控负载和电池包安全条件下分阶段验证 |
