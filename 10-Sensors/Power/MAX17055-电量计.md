# MAX17055 电量计

> **一句话描述:** Maxim/ADI ModelGauge m5 单节/小型电池电量计候选，适合产品化 SOC、低电告警和便携设备  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**MAX17055** 是 Maxim/ADI 的 ModelGauge m5 电量计候选，可用于便携设备、可穿戴、单节锂电池设备和需要较完整 SOC/容量估算的产品。它比 MAX17048 配置更复杂，也更适合产品化电池状态管理。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | Maxim fuel gauge 常见接口 |
| 测量对象 | 电压、SOC、容量、电流/状态 | 具体能力以 datasheet 为准 |
| 典型应用 | 便携设备、可穿戴、IoT 电池节点 | 产品化电量计候选 |
| 关键特性 | ModelGauge、低电告警、容量估算 | 需要电池模型/配置 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 MAX17048 更完整 SOC/容量状态的单节电池设备 |
| 不适合场景 | 多串 BMS、仅需电压百分比、需要板卡功耗统计 |
| 主要优势 | 算法和状态字段更完整，适合产品电量显示 |
| 主要风险 | 电池配置、温度、老化和休眠策略会影响 SOC 准确度 |
| 替代型号 | MAX17048、MAX17260、MAX17262、BQ27441 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device name/version/status，确认 I2C 地址 |
| 配置 | 设置设计容量、终止电压、低电阈值和电池 profile |
| 读取 | 输出 SOC、电压、容量、健康状态和告警 |
| 低功耗 | 休眠/唤醒不能破坏 SOC 连续性和告警逻辑 |
| 验证 | 完整充放电循环对比真实容量和显示误差 |
