# INA239 高精度电流电压传感器

> **一句话描述:** TI SPI 数字功率监测器候选，适合 INA238 的 SPI 对照、高速电源轨遥测和工业板卡监控  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/spi` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**INA239** 是 TI INA23x 系列 SPI 功率监测候选，可用于高精度分流电压、总线电压、电流和功率监控。它适合作为 INA238 的 SPI 路线对照，也适合需要更高通信确定性的工业板卡。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | SPI | 高速/隔离架构友好 |
| 测量对象 | 分流电压、总线电压、电流、功率 | 依赖 shunt 配置 |
| 典型应用 | 工业电源、板卡遥测、电机/负载监控 | 单通道 SPI 候选 |
| 关键特性 | 高精度 ADC、告警、诊断 | 以 datasheet 为准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要 SPI 接口、单通道高精度功率监测和告警的设备 |
| 不适合场景 | I2C 多设备总线、单节电池电量显示、多通道电源树 |
| 主要优势 | SPI 接口便于隔离和高速轮询，适合工业遥测 |
| 主要风险 | SPI 模式、CRC/诊断和校准参数错误会直接影响功率结果 |
| 替代型号 | INA238、INA237、INA229、INA226 |

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 ID/诊断寄存器，确认 SPI 模式和片选时序 |
| 配置 | 设置转换时间、平均次数、量程和告警阈值 |
| 读取 | 输出 bus/shunt voltage、current、power 和状态 |
| 校准 | current_lsb、shunt 阻值和方向需要持久化记录 |
| 兼容 | 与 INA238 共用模型时按接口和寄存器差异分层 |
