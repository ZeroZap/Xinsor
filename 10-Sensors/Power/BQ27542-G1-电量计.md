# BQ27542-G1 电量计

> **一句话描述:** TI Impedance Track 单节锂电池电量计，I2C/HDQ 接口，适合需要较完整 SOC、容量和健康状态估算的便携设备  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**BQ27542-G1** 是 TI 面向单节锂电池的电量计候选，适合需要比简单电压百分比更可靠 SOC、剩余容量、满充容量和健康状态估算的设备。它与 BQ27441、BQ27421、BQ27220 属于相近方向，但配置和学习流程需要更认真管理。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C / HDQ | 实际项目常优先 I2C |
| 测量对象 | 电压、SOC、容量、状态、健康趋势 | 单节锂电池 |
| 典型应用 | 便携设备、可穿戴、工业手持、电池节点 | TI gauge 候选 |
| 关键配置 | 电池容量、电化学 ID、终止电压、学习周期 | 需结合电芯验证 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 产品化单节锂电设备，需要比 MAX17048 更完整的电池状态 |
| 不适合场景 | 快速原型、无需电池模型的简单电压百分比显示、多串电池包 |
| 主要优势 | TI Impedance Track 生态、状态字段丰富、适合电池平台化管理 |
| 主要风险 | 配置、学习周期、电芯匹配和 sealed/unsealed 状态机会增加 bring-up 难度 |
| 替代型号 | BQ27441、BQ27421、BQ27220、MAX17201、MAX17055 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device type、firmware version、control/status |
| 配置 | 设计容量、终止电压、化学 ID 和保护阈值需版本化保存 |
| 读取 | 输出 voltage、soc、remaining capacity、full charge capacity、status、health |
| 状态 | 处理 sealed/unsealed、config update、learning 和 reset 状态 |
| 验证 | 完整充放电循环对比电子负载/库仑计，检查 SOC 跳变和低电告警 |
