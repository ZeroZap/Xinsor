# BQ27441 电量计

> **一句话描述:** TI 单节锂电池电量计，I2C 接口，适合便携设备、可穿戴和需要更完整电池状态的低功耗系统  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**BQ27441** 是 TI 面向单节锂电池的电量计，可输出电压、SOC、剩余容量、电流/功率相关估算和状态信息。相对 MAX17048，它配置项更多，也更适合需要完整电池状态管理的设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | TI gauge 常见接口 |
| 测量对象 | 电压、SOC、容量、状态 | 单节锂电池 |
| 典型应用 | 便携设备、可穿戴、电池节点 | 需要配置设计容量 |
| 关键特性 | fuel gauge、容量估算、低功耗 | 配置流程比 MAX17048 复杂 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要较完整电池状态、容量估算和 TI 生态支持的单节锂电设备 |
| 不适合场景 | 极简电量显示、多串 BMS、高精度功耗分析 |
| 主要优势 | 状态字段丰富、TI 资料完整、适合产品化电池设备 |
| 主要风险 | 需要正确配置设计容量、终止电压和电池参数，否则 SOC 会偏差 |
| 替代型号 | MAX17048、MAX17260、BQ27421、LC709203F |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device type 或 control/status |
| 配置 | 设置 design capacity、terminate voltage、taper rate 等参数 |
| 读取 | 输出 voltage、soc、remaining capacity、full charge capacity、status |
| 状态 | 处理 sealed/unsealed、config update 等状态机 |
| 验证 | 完整充放电循环对比 SOC、容量和低电告警 |
