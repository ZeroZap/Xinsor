# MAX9938 电流检测放大器

> **一句话描述:** ADI/Maxim 高边电流检测放大器，模拟输出，适合低功耗电池路径、电源轨趋势和 MCU ADC 采样  
> **标签:** `#sensor/power` `#sensor/current` `#analog` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MAX9938** 是高边电流检测放大器候选，不是数字 I2C/SPI 传感器。它适合将分流电阻上的小电压放大后送入 MCU ADC，用于低功耗电池路径、电源轨趋势、过流检测和成本敏感的模拟电流采样。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | Analog | 输出接 MCU ADC/比较器 |
| 测量对象 | 分流电阻电流趋势 | 高边检测放大 |
| 典型应用 | 电池路径、电机/负载电流、电源轨趋势、过流检测 | 模拟前端 |
| 关键配置 | shunt 阻值、增益、ADC 量程、带宽和滤波 | 系统级误差主导 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | MCU 已有 ADC，需要低成本模拟高边电流趋势检测 |
| 不适合场景 | 需要数字功率/能量寄存器、多电源轨遥测、隔离高压测量 |
| 主要优势 | 简单、低功耗、模拟链路灵活，适合替代数字 INA 的低成本方案 |
| 主要风险 | ADC 精度、参考电压、offset、shunt 热漂和布局会决定总误差 |
| 替代型号 | INA219、INA226、INA260、MAX34407、PAC1934 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 硬件 | 确认 shunt 阻值、增益、共模范围、ADC 量程和输入滤波 |
| 采样 | ADC 采样需做 offset 校准、参考电压补偿和平均滤波 |
| 换算 | 电流 = ADC 电压 / 增益 / shunt，需保留校准系数 |
| 告警 | 过流可用 ADC 阈值或比较器，但要考虑瞬态滤波和延迟 |
| 验证 | 用电子负载覆盖小电流、额定电流、温升和反向/瞬态工况 |
