# LTC2944 电量计

> **一句话描述:** ADI/Linear Technology 宽电压 I2C 电量计/库仑计，适合多节电池包电压、电流、充放电量和温度趋势监测  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**LTC2944** 是 ADI/Linear Technology 的电池电量监测候选，面向需要库仑计数、电池电压和温度趋势的多节电池系统。相比 MAX17048/BQ27441 这类单节锂电 gauge，它更适合较高电压电池包、工业节点和需要电荷累计的项目。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见电源监测接口 |
| 测量对象 | 电压、电流/电荷、温度 | 具体量程以 datasheet 和分流电阻为准 |
| 典型应用 | 多节电池包、工业节点、备电系统 | 适合库仑计数 |
| 关键特性 | 宽电压电池监测、累计电荷、告警阈值 | 需要外部分流/采样设计配合 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 多节电池、需要充放电量累计、需要比单节 gauge 更宽电压的设备 |
| 不适合场景 | 极低成本单节电量显示、完整 BMS 均衡保护、只需要板卡电流采样 |
| 主要优势 | 电池包电压覆盖更宽，可做电荷累计和低电告警 |
| 主要风险 | SOC 需要结合电池容量、效率和充放电曲线做系统级校准 |
| 替代型号 | LTC2943、MAX17260、BQ27441、INA228 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、状态位和告警寄存器默认值 |
| 配置 | 设置 prescaler、告警阈值、电压/电流/温度采样策略 |
| 读取 | 输出电压、电流、累计电荷和温度 raw/工程值 |
| 校准 | 分流电阻、公差、容量标称值和充放电效率需要统一记录 |
| 低功耗 | 休眠期间是否持续累计电荷要在 bring-up 中验证 |
