# PAC1934 多通道功率监测传感器

> **一句话描述:** Microchip 四通道 I2C/SMBus 电源监测器，适合多路电源轨电压、电流、功率和能量趋势采集  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/microchip`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**PAC1934** 是 Microchip PAC193x 系列四通道功率监测候选，适合需要同时观察多路电源轨的嵌入式板卡、Linux SBC、工业控制板和电池设备。它比单通道 INA219/INA226 更适合系统级功耗拆分。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SMBus | 多通道电源遥测 |
| 测量对象 | 多路总线电压、分流电压、电流、功率、能量 | 具体通道数以型号为准 |
| 典型应用 | 多电源轨板卡、低功耗分析、系统遥测 | 四通道候选 |
| 关键特性 | 多通道采样、功率/能量累计、采样率配置 | 需要每路分流设计 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 一颗芯片监测多路电源轨、做系统功耗剖析和长期能量统计 |
| 不适合场景 | 单路极低成本采样、高压隔离测量、只需要电池 SOC 显示 |
| 主要优势 | 四通道集成度高，适合板卡级电源树遥测 |
| 主要风险 | 多路分流布局、采样同步、量程配置和热影响需要验证 |
| 替代型号 | PAC1932、INA3221、INA228、MAX34407 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 product ID/revision，确认通道数和 I2C 地址 |
| 配置 | 设置采样率、通道使能、刷新策略和分流阻值表 |
| 读取 | 输出每通道电压、电流、功率和累计能量 |
| 同步 | 多通道数据需要 timestamp，避免功耗分解时混用不同采样周期 |
| 校准 | 每路 shunt 阻值、公差和 PCB 温升都应单独记录 |
