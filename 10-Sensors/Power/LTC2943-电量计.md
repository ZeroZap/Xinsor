# LTC2943 电量计

> **一句话描述:** ADI/LTC 宽电压电池电量计/库仑计数器，I2C 接口，适合多节电池、备电系统和电荷累计趋势监测  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#sensor/coulomb-counter` `#battery` `#protocol/i2c` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**LTC2943** 是 ADI/LTC 的电池电量计/库仑计数方向候选，适合宽电压电池系统、备电模块和需要电荷累计的设备。相对 MAX17048 这类模型电量计，它更偏向计量电荷、电压和温度，需要上层处理容量估算和校准。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 电量/电压/温度读取 |
| 测量对象 | 电荷、电压、温度、电流趋势 | 具体能力以 datasheet 为准 |
| 典型应用 | 多节电池、备电系统、工业电源、容量趋势 | 宽电压库仑计数 |
| 关键配置 | 分流/感测路径、预分频、容量换算、告警阈值 | 需系统校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 宽电压电池和备电系统需要库仑计数、电压和告警趋势 |
| 不适合场景 | 需要自动电池模型 SOC 的单节消费电子、无校准能力的原型 |
| 主要优势 | 宽电压方向、库仑计数直观、适合 LTC2944 相邻评估 |
| 主要风险 | 容量换算、初始 SOC、积分漂移和电流路径校准会影响长期准确性 |
| 替代型号 | LTC2944、LTC2945、BQ34Z100-G1、MAX17201 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 确认 I2C 地址、状态寄存器和告警标志 |
| 配置 | 设置 prescaler、告警阈值和工作模式 |
| 读取 | 分别输出 charge、voltage、temperature、status，保留 raw 计数 |
| 校准 | 建立电池容量、初始 SOC、分流/计数换算和漂移补偿策略 |
| 验证 | 用电子负载做充放电积分对比，检查长时间漂移 |
