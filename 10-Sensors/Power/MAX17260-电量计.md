# MAX17260 电量计

> **一句话描述:** Maxim/ADI ModelGauge m5 单节锂电池电量计，I2C 接口，适合需要更完整电池状态、低功耗和长期 SOC 估算的便携设备  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/maxim`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-05

---

## 概述

**MAX17260** 是 Maxim/ADI 的低功耗锂电池电量计，面向单节电池 SOC、容量、健康状态和告警监测。相对 MAX17048，它配置能力和状态字段更完整，适合从简单电量显示升级到产品化电池管理的设备。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 常见电量计接口 |
| 测量对象 | 电池电压、SOC、容量、状态、温度相关补偿 | 以 datasheet 和具体封装为准 |
| 典型应用 | 可穿戴、IoT 节点、便携仪表 | 低功耗电池设备 |
| 关键特性 | ModelGauge m5、低静态电流、告警输出 | 配置比 MAX17048 更复杂 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 单节锂电池产品、需要 SOC/容量/健康状态和低电告警的设备 |
| 不适合场景 | 多串 BMS、只需要极简电压估算、需要高精度瞬时功耗统计 |
| 主要优势 | 状态字段完整、低功耗、适合产品化电量显示和告警策略 |
| 主要风险 | 电池模型、温度补偿和学习过程会影响 SOC 可信度 |
| 替代型号 | MAX17048、BQ27441、BQ27421、LC709203F |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 IC version/status，确认 I2C 地址和告警脚状态 |
| 配置 | 写入设计容量、终止电压、告警阈值和温度来源 |
| 读取 | 输出 voltage、soc、remaining capacity、full capacity、status |
| 学习 | 记录完整充放电循环，观察 SOC 跳变和容量收敛 |
| 低功耗 | 睡眠/唤醒期间保持采样连续性，避免频繁复位 gauge |
