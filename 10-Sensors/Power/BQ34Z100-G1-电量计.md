# BQ34Z100-G1 电量计

> **一句话描述:** TI 多化学体系电池电量计候选，适合铅酸/锂电等较大电池包 SOC、容量和状态估算  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-06

---

## 概述

**BQ34Z100-G1** 是 TI 面向多化学体系电池的电量计候选，适合铅酸、锂电、较大容量电池包和备电系统的 SOC/容量估算。它比单节 gauge 复杂，适合需要更完整电池模型的系统。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SMBus | TI gauge 生态 |
| 测量对象 | 电压、电流、SOC、容量、状态 | 依赖外部采样和电池模型 |
| 典型应用 | 备电、电池包、铅酸/锂电系统 | 多化学体系 gauge |
| 关键特性 | Impedance Track 思路、多化学体系、容量学习 | 配置复杂 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 大容量电池包、备电系统、多化学体系和需要学习算法的项目 |
| 不适合场景 | 小型单节锂电、极简电量显示、板级功耗遥测 |
| 主要优势 | 能覆盖单节 gauge 之外的大电池和多化学体系场景 |
| 主要风险 | 配置、学习周期、生产校准和 TI 工具链依赖较重 |
| 替代型号 | BQ27441、BQ27220、LTC2944、MAX17260 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 device type、control/status 和 data flash 状态 |
| 配置 | 设置化学体系、容量、分流、保护阈值和学习参数 |
| 读取 | 输出 SOC、SOH、电压、电流、温度、容量和 flags |
| 生产 | 需要明确 golden image、校准流程和 sealing 策略 |
| 验证 | 学习周期、温度、老化和大负载阶跃都要覆盖 |
