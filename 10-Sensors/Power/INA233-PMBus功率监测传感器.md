# INA233 PMBus功率监测传感器

> **一句话描述:** TI PMBus/I2C 数字功率监测器，适合服务器、工业电源和需要标准电源遥测命令的系统  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/pmbus` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**INA233** 面向 PMBus 电源遥测场景，可测量电压、电流、功率并通过 PMBus 命令访问。相对 INA226/INA231，它更适合已经采用 PMBus 管理栈的服务器、通信和工业电源系统。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | PMBus/I2C | 软件栈需支持 PMBus 命令模型 |
| 测量对象 | 电压、电流、功率 | 外接 shunt |
| 典型应用 | 服务器电源、工业电源、板卡遥测 | 偏系统电源管理 |
| 关键配置 | 校准、PMBus 命令、告警阈值、数据格式 | 需和上层电源管理一致 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 已有 PMBus 管理需求、需要标准化电源遥测和告警的系统 |
| 不适合场景 | 简单 MCU 项目、只需要低成本 I2C 电流读数的节点 |
| 主要优势 | PMBus 生态、遥测字段标准化、适合电源管理框架接入 |
| 主要风险 | PMBus 数据格式、页/命令支持和告警策略比普通 INA 驱动复杂 |
| 替代型号 | INA226、INA231、LTC2945、LTC2947、PAC1934 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 协议 | 先确认 SMBus/PMBus 时序、PEC 需求和命令集支持范围 |
| 校准 | shunt 和 current_lsb 需要映射到 PMBus 读数格式 |
| 读取 | 处理 voltage/current/power 的线性格式和符号扩展 |
| 告警 | 将过流、过压、功率阈值映射到 PMBus status 寄存器 |
| 集成 | Linux/RTOS 中可优先评估 PMBus/HWMON 抽象，而不是自定义 ABI |
