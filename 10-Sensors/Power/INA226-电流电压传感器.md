# INA226 电流电压传感器

> **一句话描述:** TI 高精度 I2C 电流/电压/功率监测器，适合板卡功耗监测、电源管理和电池系统  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-05-23

---

## 概述

**INA226** 是 TI 的数字电流、电压和功率监测器，常作为 INA219 的高精度升级候选。它通过外部分流电阻测量电流，同时读取总线电压并计算功率，适合板卡功耗分析和电源监控。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 地址可配置 |
| 测量对象 | 分流电压、总线电压、电流、功率 | 外接 shunt |
| 典型应用 | 板卡功耗、电池路径、电源管理 | INA219 升级候选 |
| 关键配置 | shunt 阻值、平均次数、转换时间、校准寄存器 | 精度依赖配置 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 INA219 更高精度和更灵活采样配置的功率监测 |
| 不适合场景 | 无法串入分流电阻、高压隔离测量、极低成本项目 |
| 主要优势 | 精度高、I2C、平均/转换时间可配、TI 生态成熟 |
| 主要风险 | shunt 选型、Kelvin 连接和校准寄存器计算必须正确 |
| 替代型号 | INA219、INA228、INA238、INA260 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取 manufacturer/device ID 或确认寄存器默认值 |
| 校准 | 根据 shunt resistor 和 current_lsb 计算 calibration |
| 配置 | 设置 bus/shunt conversion time、averaging 和 mode |
| 读取 | 输出 bus_voltage_v、shunt_voltage_mv、current_a、power_w |
| 验证 | 用万用表/电子负载校验电压、电流和功率误差 |
