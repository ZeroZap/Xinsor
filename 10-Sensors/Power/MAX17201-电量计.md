# MAX17201 电量计

> **一句话描述:** ADI/Maxim ModelGauge m5 系列单节/多节电池电量计，适合需要较完整 SOC、容量和健康状态估算的电池设备  
> **标签:** `#sensor/power` `#sensor/fuel-gauge` `#battery` `#protocol/i2c` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**MAX17201** 属于 ADI/Maxim ModelGauge m5 电量计方向，面向需要更完整电池状态估算的产品。相对 MAX17048 这类极简电量计，它的配置、保护和状态字段更多，适合产品化电池平台评估。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C/SMBus | 具体封装和配置以 datasheet 为准 |
| 测量对象 | 电压、SOC、容量、状态、健康趋势 | 电池模型相关 |
| 典型应用 | 便携设备、工业电池包、备电系统 | 高阶 fuel gauge 候选 |
| 关键配置 | 电池容量、终止电压、充放电参数、学习状态 | 需结合电芯验证 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要比 MAX17048 更完整 SOC/容量/健康状态的电池产品 |
| 不适合场景 | 一次性原型、无需电池模型的简单电压百分比显示 |
| 主要优势 | ModelGauge 系列生态、状态字段丰富、适合产品化电池管理 |
| 主要风险 | 配置参数、学习周期和电芯差异会影响 SOC 可信度 |
| 替代型号 | MAX17055、MAX17260、MAX17262、MAX17320、BQ27441 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取版本/状态寄存器，确认电池插入和上电状态 |
| 配置 | 设置设计容量、终止电压、充电参数和温度相关参数 |
| 读取 | 输出 voltage、soc、remaining/full capacity、current、temperature 和 status |
| 状态机 | 关注 reset、hibernate、learned config 和 alert 状态 |
| 验证 | 至少做一次完整充放电曲线，对比库仑计或电子负载数据 |
