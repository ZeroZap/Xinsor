# ADM1191 热插拔电流监测传感器

> **一句话描述:** ADI 热插拔控制/电流电压监测候选，I2C 接口，适合服务器、电源插拔保护和板卡输入电源遥测  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#hot-swap` `#protocol/i2c` `#vendor/adi`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**ADM1191** 是 ADI 面向热插拔和电源输入监控的器件候选，兼具电源路径保护和数字遥测思路。它适合服务器、通信板卡、背板插拔和工业电源输入保护，不应只按普通 INA 电流传感器理解。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 电源遥测和状态读取 |
| 测量对象 | 输入电压、电流趋势、故障状态 | 需外部分流/功率路径设计 |
| 典型应用 | 热插拔、服务器电源、板卡输入保护、遥测 | 电源路径保护 + 监测 |
| 关键配置 | 限流、故障、FET/电源路径、告警阈值 | 硬件设计决定行为 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 需要热插拔保护、电源输入状态和 I2C 遥测的板卡系统 |
| 不适合场景 | 简单低成本电流读数、低压电池 SOC 估算、隔离电流测量 |
| 主要优势 | 电源保护和遥测结合，适合系统电源管理框架 |
| 主要风险 | 限流、FET、热设计和故障恢复策略错误会影响供电可靠性 |
| 替代型号 | LTC2945、MAX34407、INA233、PAC1934、INA226 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 探测 | 读取状态/告警寄存器，确认 I2C 地址和电源路径状态 |
| 读取 | 上报输入电压、电流趋势、fault、power-good 等状态 |
| 告警 | 过流、欠压、过温或 FET 故障需要映射到电源管理策略 |
| 控制 | 如涉及开关/重试命令，必须设置权限和防误操作保护 |
| 验证 | 热插拔浪涌、电子负载阶跃、故障恢复和温升要硬件实测 |
