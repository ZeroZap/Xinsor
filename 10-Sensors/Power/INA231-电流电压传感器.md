# INA231 电流电压传感器

> **一句话描述:** TI I2C 电流/电压/功率监测器，适合需要告警阈值和板级电源轨遥测的嵌入式系统  
> **标签:** `#sensor/power` `#sensor/current` `#sensor/voltage` `#protocol/i2c` `#vendor/ti`  
> **状态:** 选型骨架，待硬件验证  
> **最后更新:** 2026-06-21

---

## 概述

**INA231** 是 TI INA23x 系列电流/电压/功率监测器，可作为 INA226、INA230 的相邻选型。它适合在 MCU、网关、工业控制板上做电源轨电流趋势监测和阈值告警。

---

## 快速参数

| 参数 | 值 | 备注 |
|------|----|------|
| 接口 | I2C | 具体地址选项以 datasheet 为准 |
| 测量对象 | 分流电压、总线电压、电流、功率 | 外部分流电阻 |
| 典型应用 | 电源轨遥测、过流告警、板卡功耗分析 | 与 INA226 类似应用层 |
| 关键配置 | shunt、转换时间、平均次数、alert 阈值 | 需要系统级校准 |

---

## 选型结论

| 维度 | 结论 |
|------|------|
| 适合场景 | 多电源轨需要统一 I2C 遥测和阈值告警的项目 |
| 不适合场景 | 无法接受 shunt 压降、需要隔离采样或高侧超高压测量 |
| 主要优势 | TI 资料体系完整、驱动结构可复用、适合批量电源轨监控 |
| 主要风险 | alert 极性/锁存配置和校准寄存器容易在 bring-up 阶段出错 |
| 替代型号 | INA226、INA230、INA237、INA3221、PAC1934 |

---

## 驱动关注点

| 阶段 | 要点 |
|------|------|
| 初始化 | 配置 averaging、bus/shunt conversion time 和 operating mode |
| 校准 | current_lsb 应覆盖最大电流并保留足够分辨率 |
| 告警 | 确认 alert function、mask/enable 和锁存行为 |
| 读取 | 统一输出电压、电流、功率和告警状态，便于上层电源树显示 |
| 硬件 | shunt Kelvin 连接和高电流铜箔温升需要一起评估 |
