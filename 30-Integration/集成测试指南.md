## 3. 测试用例

### 3.1 功能测试

#### TC-001: 传感器初始化

```javascript
describe('传感器初始化测试', () => {
  it('应成功初始化传感器', async () => {
    const sensor = new SensorAgent(config);
    const result = await sensor.init();
    expect(result).toBe(true);
  });
  
  it('应检测传感器连接状态', async () => {
    const sensor = new SensorAgent(config);
    const connected = await sensor.isConnected();
    expect(connected).toBe(true);
  });
});
```

#### TC-002: 数据读取

```javascript
describe('数据读取测试', () => {
  it('应读取有效数据', async () => {
    const data = await sensor.readData();
    expect(data).toHaveProperty('timestamp');
    expect(data).toHaveProperty('values');
  });
  
  it('数据应在合理范围内', async () => {
    const data = await sensor.readData();
    expect(data.temperature).toBeWithinRange(-40, 85);
  });
});
```

### 3.2 性能测试

#### TC-101: 采样率测试

```javascript
describe('采样率测试', () => {
  it('应达到配置的采样率', async () => {
    const samples = await collectSamples(1000);
    const actualRate = calculateRate(samples);
    expect(actualRate).toBeWithinRange(config.rate * 0.95, config.rate * 1.05);
  });
});
```

#### TC-102: 延迟测试

```javascript
describe('延迟测试', () => {
  it('数据延迟应小于阈值', async () => {
    const latency = await measureLatency();
    expect(latency).toBeLessThan(100); // ms
  });
});
```

### 5.4 BMP280 Bring-up Checklist

| 阶段 | 检查项 | 通过标准 |
|------|--------|----------|
| 电源 | VDD/VDDIO 稳定，去耦电容就近放置 | 上电无异常发热，电压满足 datasheet |
| 总线 | I2C/SPI 引脚连接正确 | I2C 可扫描到 `0x76` 或 `0x77` |
| 身份识别 | 读取 `chip_id` | 返回 `0x58` |
| 校准参数 | 读取温度/气压补偿参数 | 非全 `0x00` 或全 `0xFF` |
| 基础配置 | 写入 oversampling、filter、mode | 配置后可正常触发测量 |
| 原始数据 | 读取 raw temperature / raw pressure | 原始值有变化，不固定为 0 或满量程 |
| 补偿计算 | 输出温度和气压 | 温度在环境合理范围，气压约 `300~1100 hPa` |
| 模式切换 | forced / normal / sleep | forced 单次测量可完成，sleep 后功耗下降 |
| 异常恢复 | 模拟读写失败后重新初始化 | 驱动能返回错误并恢复通信 |
| 长期运行 | 连续采样 1-24 小时 | 无崩溃、无明显内存增长、数据无异常跳变 |

### 5.5 MPU6050 IMU Bring-up Checklist

| 阶段 | 检查项 | 通过标准 |
|------|--------|----------|
| 电源 | VDD/VLOGIC/REGOUT 和去耦电容 | 电压稳定，REGOUT 电容按 datasheet 放置 |
| 总线 | I2C 引脚、上拉和 AD0 地址脚 | I2C 可扫描到 `0x68` 或 `0x69` |
| 身份识别 | 读取 `WHO_AM_I` | 返回 `0x68` |
| 唤醒 | 清除 `PWR_MGMT_1.SLEEP` | 数据寄存器开始变化 |
| 基础配置 | 设置 clock、DLPF、ODR、accel/gyro range | 配置后可连续读取 14 字节数据 |
| 静态读数 | 平放静止读取 accel/gyro | 加速度模长约 `1g`，陀螺仪接近 `0 dps` |
| 量程切换 | 切换 ±2/4/8/16g 和 ±250/500/1000/2000dps | 灵敏度换算随配置变化 |
| 零偏校准 | 静止采样计算 offset | 校准后 gyro 零偏降低，accel Z 轴接近 1g |
| 中断 | 配置 data ready 或 motion detect | INT 引脚可触发 MCU 事件 |
| 低功耗 | sleep/cycle mode | 可进入低功耗并恢复正常读取 |
| 异常恢复 | 模拟 I2C 失败或设备 sleep | 驱动返回错误并可重新初始化 |
