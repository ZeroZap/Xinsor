# 传感器Bring-up最小闭环

> **一句话描述:** 用最短路径证明传感器硬件、总线、驱动和数据链路基本成立  
> **标签:** `#ESE` `#Maker` `#Bring-up` `#调试`  
> **状态:** 提炼稿  
> **最后更新:** 2026-06-06

---

## 最小闭环定义

Bring-up 的目标不是一次写完完整驱动，而是尽快证明四件事：设备有电、总线可通信、原始数据可读、物理量合理。只有这四件事成立，后续配置、低功耗、校准和框架集成才有意义。

---

## 推荐顺序

| 顺序 | 动作 | 通过标准 |
|------|------|----------|
| 1 | 确认电源、地、上拉/片选、复位脚 | 电压稳定，无明显发热 |
| 2 | 扫描总线或发最小命令 | I2C ACK / SPI ID / UART 帧有效 |
| 3 | 读取 ID/status | 与 datasheet 或候选记录一致 |
| 4 | 复位/唤醒 | 状态位变化可解释 |
| 5 | 触发或进入默认测量 | data ready 或新数据出现 |
| 6 | 读取 raw | raw 随环境变化有趋势 |
| 7 | 换算物理量 | 单位和数量级合理 |
| 8 | 记录样本 | 能复现当前测试条件 |

---

## Maker 与 ESE 差异

| 维度 | Maker 原型 | ESE 工程 |
|------|------------|----------|
| 接线 | 杜邦线/模块 | 原理图、PCB、连接器约束 |
| 通过标准 | 串口打印有数 | 有状态、单位、误差和测试记录 |
| 异常处理 | 重新插拔/重启 | timeout、reset、bus recovery |
| 数据保存 | 临时截图 | bring-up log 和知识库回填 |

---

## 记录模板

| 字段 | 内容 |
|------|------|
| 板卡 | MCU/开发板/供电电压 |
| 传感器 | 型号、模块版本、地址/片选 |
| 总线 | I2C/SPI/UART 参数 |
| 环境 | 温度、光照、气体、压力等条件 |
| 结果 | ID、raw、物理量、status |
| 异常 | 超时、CRC、噪声、漂移 |
