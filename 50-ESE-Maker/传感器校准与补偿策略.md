# 传感器校准与补偿策略

> **一句话描述:** 区分出厂校准、驱动补偿、现场校准和业务补偿，避免把误差处理混在一起  
> **标签:** `#ESE` `#传感器` `#校准`  
> **状态:** 提炼稿  
> **最后更新:** 2026-06-06

---

## 校准分层

| 层级 | 来源 | 驱动责任 |
|------|------|----------|
| 出厂校准 | PROM/NVM/OTP | 读取、校验、参与换算 |
| 结构补偿 | 外壳、窗口、风道、热源 | 提供参数入口，不硬编码 |
| 现场校准 | 白板、洁净空气、零压、六面体 | 记录流程和结果 |
| 业务补偿 | 具体应用模型 | 放在上层算法，不放底层驱动 |

---

## 类型关注点

| 类型 | 校准重点 |
|------|----------|
| IMU | 加速度六面体、陀螺零偏、磁力计椭球拟合 |
| 压力 | PROM 系数、零点、海平面基准、水密度 |
| 光学 | 暗场、白板、窗口透过率、crosstalk |
| 气体 | baseline、温湿度补偿、ASC/FRC、预热 |
| 电源 | shunt 阻值、公差、温漂、电流方向 |
| 温湿度 | 温度偏移、通风结构、冷凝恢复 |

## 工程化记录

| 字段 | 说明 |
|------|------|
