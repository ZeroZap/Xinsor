# Maker原型到工程化迁移

> **一句话描述:** 把面包板、模块和示例代码中的经验迁移成可复现的硬件、驱动和验证流程  
> **标签:** `#Maker` `#ESE` `#工程化`  
> **状态:** 提炼稿  
> **最后更新:** 2026-06-06

---

## 核心观点

Maker 原型重在快速验证“能不能工作”，工程化重在让“别人、别的板、别的批次也能工作”。迁移时要把接线、供电、库依赖、魔法参数、异常和环境条件全部显性化。

---

## 迁移清单

| 原型信息 | 工程化表达 |
|----------|------------|
| 模块购买链接 | 芯片型号、模块版本、关键外围 |
| 杜邦线接法 | 原理图、连接器、上拉/片选/复位 |
| Arduino 示例 | 总线命令、寄存器、状态机 |
| 串口打印 | 数据结构、单位、状态、timestamp |
| 手工调参 | 配置项、默认值、调参范围 |
| 成功截图 | bring-up log、测试条件、复现步骤 |

---

## 常见坑

| 坑 | 处理 |
|----|------|
| 模块带电平转换但 PCB 直连芯片 | 分清模块电路和芯片裸用条件 |
| 示例库隐藏初始化 | 把每一步命令拆出来记录 |
| 只测一个环境点 | 至少做低/中/高或暗/亮/遮挡等变化 |
| 忽略供电纹波 | 记录电源、电流、去耦和负载状态 |
| 没有异常路径 | 主动拔线、复位、总线错误测试 |
