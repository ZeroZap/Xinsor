# 传感器验证分层

> **一句话描述:** 用 V0-V5 分层描述传感器从文档可实现到框架已集成的成熟度  
> **标签:** `#ESE` `#验证` `#传感器`  
> **状态:** 提炼稿  
> **最后更新:** 2026-06-06

---

## 分层定义

| 等级 | 目标 | 证据 |
|------|------|------|
| V0 文档可实现 | 型号笔记足以开始驱动 | 参数、接口、风险、链接齐全 |
| V1 通信通过 | 能识别设备或稳定 ACK | ID/status/log |
| V2 数据合理 | 原始值和物理量合理 | 样本数据、单位、环境条件 |
| V3 配置可控 | 量程/ODR/模式生效 | 配置切换测试 |
| V4 长稳通过 | 长时间运行无异常 | 时长、错误率、漂移记录 |
| V5 已集成 | 框架测试通过 | XinYi/Zephyr/RT-Thread 集成记录 |

---

## 状态回填

| 回填位置 | 内容 |
|----------|------|
| 型号笔记 | 验证等级、平台、样本数据、异常 |
| 分类索引 | 状态从选型骨架提升为已验证/已集成 |
| 总目录 | 文档链接和状态保持一致 |
| 集成文档 | 驱动任务、测试范围、剩余风险 |

---

## 最小验收样本

| 类型 | 样本 |
|------|------|
| 温湿度 | 室温、手握升温、呼气湿度变化 |
| IMU | 静止六面、旋转、震动 |
| 光学 | 暗场、室内光、强光/遮挡 |
| 气体 | 洁净空气、呼气/酒精/VOC 趋势 |
| 压力 | 大气、按压/高度变化、管路零点 |
| 电源 | 空载、已知负载、动态负载 |
