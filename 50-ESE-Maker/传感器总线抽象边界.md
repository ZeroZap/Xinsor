# 传感器总线抽象边界

> **一句话描述:** 明确 I2C/SPI/UART/1-Wire 适配层与传感器驱动核心之间的责任边界  
> **标签:** `#ESE` `#驱动开发` `#总线抽象`  
> **状态:** 提炼稿  
> **最后更新:** 2026-06-06

---

## 核心原则

传感器驱动核心不应该直接绑定 MCU HAL。核心层只关心寄存器、命令、状态机和数据换算；总线读写、delay、timestamp、互斥和片选控制放到 port 层。这样同一份驱动可以迁移到 XinYi、Zephyr、RT-Thread 或裸机 HAL。

---

## 分层边界

| 层 | 应放内容 | 不应放内容 |
|----|----------|------------|
| driver core | 寄存器、命令、数据换算、状态机 | HAL 句柄、GPIO 端口、RTOS API |
| port layer | read/write、delay、timestamp、lock | 传感器算法和业务阈值 |
| board config | 地址、CS、复位脚、供电控制 | 通用寄存器逻辑 |
| application | 业务策略、滤波、告警联动 | 低层总线时序 |

---

## 接口最小集

| 接口 | 说明 |
|------|------|
| `bus_read(reg, buf, len)` | 寄存器或命令读 |
| `bus_write(reg, buf, len)` | 寄存器或命令写 |
| `delay_ms/us()` | 传感器状态机等待 |
| `timestamp_ms/us()` | 数据采样时间戳 |
| `lock/unlock()` | 多任务环境总线互斥 |
| `reset/power()` | 可选，板级控制 |

---

## 类型差异

| 总线 | 关注点 | 典型传感器 |
|------|--------|------------|
| I2C | 地址冲突、上拉、clock stretch、CRC | SHT40、BMP280、VL53Lx |
| SPI | 模式、片选、burst、dummy byte | IMU、INA229 |
| UART | 帧头、长度、校验、主动/被动模式 | PMS、CO2 模块 |
| 1-Wire | 时序、强上拉、ROM 搜索、长线 | DS18B20 |
