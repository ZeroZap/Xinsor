# 传感器异常诊断与恢复

> **一句话描述:** 把传感器异常从“读数不对”拆成总线、状态、数据质量、环境和结构问题  
> **标签:** `#ESE` `#调试` `#异常恢复`  
> **状态:** 提炼稿  
> **最后更新:** 2026-06-06

---

## 异常分类

| 类别 | 表现 | 处理 |
|------|------|------|
| 总线异常 | NACK、timeout、CRC 错误 | bus reset、重试、降速 |
| 状态异常 | data not ready、stale、fault | 按状态机恢复，不直接丢弃原因 |
| 数据异常 | 饱和、突跳、全 0/全 FF | 标记 suspect/invalid |
| 环境异常 | 冷凝、强光、高湿、振动 | 记录环境条件和保护策略 |
| 结构异常 | 风道堵塞、窗口污染、管路漏气 | 引导维护或重新校准 |

---

## 恢复优先级

1. 保留错误码和现场上下文。
2. 做有限次数软恢复。
3. 复位传感器或总线。
4. 降级为无效数据，不输出伪正常值。
5. 上报上层维护事件。

---

## 诊断字段

| 字段 | 作用 |
|------|------|
| last_error | 最近驱动错误 |
| sensor_status | 芯片状态寄存器或状态帧 |
| retry_count | 总线或命令重试次数 |
| data_age_ms | 数据新鲜度 |
| quality | valid/suspect/invalid |
| maintenance_hint | 清洁、校准、检查线缆等建议 |
