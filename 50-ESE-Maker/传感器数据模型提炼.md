# 传感器数据模型提炼

> **一句话描述:** 统一传感器输出中的 raw、物理量、状态、质量和时间戳字段  
> **标签:** `#ESE` `#驱动开发` `#数据模型`  
> **状态:** 提炼稿  
> **最后更新:** 2026-06-06

---

## 核心观点

工程化传感器数据不能只返回一个 `float`。至少需要物理量、单位、timestamp、quality/status 和 raw debug 能力。这样才能支撑滤波、融合、校准、故障诊断和测试复现。

---

## 通用字段

| 字段 | 作用 | 示例 |
|------|------|------|
| `timestamp_ms` | 对齐和延迟分析 | IMU/气压融合 |
| `status` | 芯片状态或驱动错误 | CRC error、data stale |
| `quality` | 上层可用性判断 | valid/suspect/invalid |
| `raw[]` | 调试和校准复现 | ADC raw、寄存器原值 |
| physical values | 业务使用 | `temperature_c`, `pressure_hpa` |
| config echo | 解释数据上下文 | ODR、gain、range、integration time |

---

## 按类型扩展

| 类型 | 必要字段 |
|------|----------|
| 温湿度 | temperature_c, humidity_rh, heater_state |
| 气压 | pressure_hpa, temperature_c, altitude_m optional |
| IMU | accel_mps2, gyro_dps, range, odr, fifo_status |
| 光学 | raw channels, integration_ms, gain, saturation |
| 气体 | index/ppm, baseline, compensation source, warmup_state |
| 电源 | bus_v, shunt_v, current_a, power_w, energy_wh optional |

---

## 设计禁忌

| 禁忌 | 后果 |
|------|------|
| 不保留 raw | 校准和异常复现困难 |
| 无 timestamp | 多传感器融合不可控 |
| 无 status | 业务层误用无效数据 |
| 单位藏在注释里 | 接口迁移时容易误用 |
| 驱动里写业务阈值 | 复用困难，场景耦合 |
