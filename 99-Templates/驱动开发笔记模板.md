#### 建议目录结构

```text
drivers/sensors/{{sensor_name}}/
├── {{sensor_name}}.h          # 公共接口、配置和数据结构
├── {{sensor_name}}.c          # 寄存器、转换算法和状态机

├── {{sensor_name}}_port.c     # I2C/SPI/UART、delay、时间戳适配
```

#### 公共接口清单

| 接口 | 作用 | 备注 |
|------|------|------|
| `{{sensor_name}}_init(config)` | 初始化设备并验证身份 | `config` 至少包含总线、地址/片选、模式 |
| `{{sensor_name}}_read(data)` | 读取并输出物理量 | 输出字段应包含单位 |
| `{{sensor_name}}_configure(param, value)` | 修改量程、ODR、滤波、模式等参数 | 参数应可被上层组件枚举 |
| `{{sensor_name}}_self_test()` | 执行最小自检 | 至少验证通信、身份和读数范围 |
| `{{sensor_name}}_deinit()` | 释放资源或进入低功耗状态 | 可选 |

### 6.3 Bring-up Checklist

| 阶段 | 检查项 | 通过标准 |
|------|--------|----------|
| 电源 | 电压、纹波、去耦 | 上电稳定，无异常发热 |
| 总线 | I2C/SPI/UART 通信 | 能扫描或握手成功 |
| 身份识别 | chip id / status / ack | 返回值符合 datasheet 或通信预期 |
| 基础配置 | 写入默认配置 | 配置后能触发测量 |
| 原始数据 | 读取 raw data | 不固定为 0 或满量程 |
| 物理量转换 | 输出带单位数据 | 数值在环境合理范围 |
| 模式切换 | normal / forced / sleep | 行为和功耗符合预期 |
| 异常恢复 | 总线失败、超时、复位 | 能返回错误并重新初始化 |
| 长期运行 | 连续采样 | 无崩溃、无明显内存增长、数据无异常跳变 |

### 6.4 最小验收标准

| 项目 | 判定 |
|------|------|
| 通信 | 能稳定识别设备 |
| 配置 | 默认配置可正常生效 |
| 数据 | 输出物理量在合理范围内 |
| 错误处理 | 超时/通信失败能返回错误 |
| 恢复 | 重新初始化可恢复正常 |
